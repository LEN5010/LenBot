# 插件工具回放场景

`cases.json` 是脱敏的工具选择评测资料，用固定时间与真实来源关系对照提示词修改。它独立于表达回放格式：这里的重点是工具序列、参数和结果含义，不能直接传给 `lenbot-eval expression`。

在隔离实例安装本机四个独立插件，把这些虚构消息作为会话输入，使用真实模型时逐项检查 expected_tools 和 expect。初始化时间设为 2026-10-06 18:00（Asia/Shanghai），日报原文也使用虚构数据。预期区间明确写在用例中；“今天下午”在本用例指定为12:00开始，其他实际语境仍由模型判断。

账号未开启、多人请求与后发言主人、真实动态 ID 的跨工具传递、后台自行发送与指南生命周期都包含在资料中。非主人请求应被拒绝，测试中不要对真实账号执行写操作。只使用 simulated 发送和合成协议服务。

宿主 `tests/test_plugin_tool_contract.py` 验证协议、来源权限与指南生命周期。群总结的 `tests/test_incremental.py` 用公共 PluginTest 时钟及本机模型 HTTP 服务验证范围与缓存；B 站 `tests/test_content.py` 验证配置可用性和非主人来源，在联网之前拒绝。

这些协议测试已执行；当前用例用于后续模型评测，尚未用真实聊天模型运行。模型协议服务不等于真实模型理解能力；真实费用、账号操作和群发送各自明确授权后再运行。
