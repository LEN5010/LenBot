# 常见问题

## 首次配置的链接打不开

链接是 `127.0.0.1` 开头的本机地址，只能在运行 LenBot 的那台机器上打开。LenBot 装在远程服务器上时，先把终端里显示的端口转发到自己电脑，再在本机浏览器打开同一个链接：

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 测试连接读不出 Bot 账号

按顺序检查：

1. OneBot 那边 QQ 已经登录，WebSocket 已经打开。
2. 正向连接时，地址填的是 OneBot 的 WebSocket 服务端地址，以 `ws://` 开头。LenBot 在 Docker 里时，`127.0.0.1` 指的是容器自己，要换成 OneBot 的容器名或宿主机地址。
3. 反向连接时，OneBot 用的是 Universal 模式，地址和端口指向 LenBot 的监听设置。
4. 两边的访问令牌一样。

按钮下面会显示具体的错误，对着它查。连接方式的细节见[接入 QQ](./onebot)。

## 向导保存后没有跳到面板

页面停在「配置已保存」，说明面板半分钟内没有启动起来。去看终端里的输出，常见原因是面板端口已经被别的程序占用。

配置已经保存了。处理好后重新启动 LenBot 就行，不用再走一遍向导。端口要换的话，先停掉 LenBot，改 `lenbot.config.json` 里的 `panel.port`。

## Bot 在群里不说话

1. 首页看 QQ 是不是在线，这个群的聊天开关有没有打开。
2. 顶栏有「模拟发送」的话，回复只在面板里显示，没有发到 QQ。到**设置 → 连接**改成真实发送。
3. 新加的群默认只回应 @ 它或回复它的消息。想让它主动参与，到**群聊 → 设置**里关掉「只在被 @、被回复或私聊时说话」，再调活跃度和关键词。
4. 设了安静时段的话，那段时间它不主动说话。
5. **模型 → 用量与上限**里看今天的 token 是不是到了上限。
6. **日志**页找到这一轮，看有没有报错。

## 读网页、取图片总是失败

错误里有 `私有或保留地址` 的话，多半是代理软件开了 fake-ip 模式，见[可选服务](./optional-services#代理软件的-fake-ip-模式)。

## 启动时说实例锁被占用

同一个实例同一时间只能运行一个 LenBot 或维护命令，先把另一个停掉。在终端里按过 Ctrl-Z 的进程只是挂起，仍然占着锁，用 `fg` 切回来再按 Ctrl-C。

锁会在进程退出时自动释放。手动删掉锁文件可能让两个进程同时写数据，别这么做。

## 启动时说配置格式太旧

用源码运行、更新代码后没跑迁移命令就会这样。LenBot 启动时不会自己改写配置，报错里会写明现在的格式、需要的格式和该执行的命令。按[从源码运行](./install-source#更新)里的步骤执行一遍。

部署包和 Docker 用面板升级时，更新器会自己跑这些迁移。

如果报错说配置格式比程序新，说明这份配置是更新版本的 LenBot 写的。换回那个版本，或者在更新页恢复升级前的快照。

## 登录面板一直提示尝试过于频繁

同一个 IP 在 15 分钟内输错 5 次密码后，这个 IP 的登录会被暂时拒绝，密码对了也一样，等 15 分钟就好。

面板放在反向代理后面时，所有人都从代理的地址登录，一个人连续输错会让别人也暂时登不上。

## 升级失败了

打开更新与恢复页，按页面上给出的操作恢复或者重新启动，见[更新与恢复](./update#出问题时)。

## 支持别的聊天平台吗

现在只有 QQ。账号已经按 `平台:账号` 的格式设计，以后有需要再加别的平台。

## 能用语音回复吗

不能。LenBot 能把群里的语音转成文字来理解，但回复只用文字。

## token 用量怎么看

**模型 → 用量与上限**里有今天和本月的 token，按群和用途分开列。数字来自模型服务的报告，LenBot 不换算成金额，实际花了多少以服务商账单为准。
