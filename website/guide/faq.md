# 常见问题

## 首次配置的链接打不开

链接以 `127.0.0.1` 开头，是本机地址，只能在运行 LenBot 的机器上打开。LenBot 安装在远程服务器上时，先把终端中显示的端口转发到自己的电脑，再在本机浏览器中打开同一个链接。

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 测试连接时读取不到 Bot 账号

请按顺序检查以下几项。

1. OneBot 一侧的 QQ 已经登录，WebSocket 已经开启。
2. 使用正向连接时，地址填写的是 OneBot 的 WebSocket 服务端地址，以 `ws://` 开头。LenBot 运行在 Docker 中时，`127.0.0.1` 指向容器本身，需要换成 OneBot 的容器名或宿主机地址。
3. 使用反向连接时，OneBot 使用 Universal 模式，地址和端口与 LenBot 的监听设置一致。
4. 两侧的访问令牌相同。

按钮下方会显示具体的错误信息，可以据此排查。连接方式的详细说明见[接入 QQ](./onebot)。

## 向导保存后没有跳转到面板

页面停在「配置已保存」，说明面板在半分钟内没有启动。请查看终端输出，常见原因是面板端口已被其他程序占用。

此时配置已经保存。问题解决后重新启动 LenBot 即可，不需要再走一遍向导。如果要更换端口，请先停止 LenBot，再修改 `lenbot.config.json` 中的 `panel.port`。

## Bot 在群里不说话

1. 在首页查看 QQ 是否在线，以及这个群的聊天开关是否打开。
2. 顶栏显示「模拟发送」时，回复只显示在面板里，不会发送到 QQ。请在**设置 → 连接**中改为真实发送。
3. 新添加的群默认只回应 @ Bot 或回复 Bot 的消息。如果希望 Bot 主动参与聊天，请在**群聊 → 设置**中关闭「只在被 @、被回复或私聊时说话」，再调整活跃度和关键词。
4. 设置了安静时段时，Bot 在这段时间内不主动发言。
5. 在**模型 → 用量与上限**中查看今天的 token 用量是否已达到上限。
6. 在**日志**页找到这一轮回复，查看是否有报错。

## 读取网页或获取图片总是失败

如果错误信息中有 `私有或保留地址`，通常是因为代理软件开启了 fake-ip 模式，见[可选服务](./optional-services#代理软件的-fake-ip-模式)。

## 启动时提示实例锁被占用

同一个实例在同一时间只能运行一个 LenBot 或一条维护命令，请先停止另一个。在终端中按过 Ctrl-Z 的进程只是被挂起，仍然占用着锁。请用 `fg` 切换回这个进程，再按 Ctrl-C。

进程退出时会自动释放锁。手动删除锁文件可能导致两个进程同时写入数据，请不要这样做。

## 启动时提示配置格式过旧

从源码运行时，如果更新代码后没有执行迁移命令，就会出现这个提示。LenBot 启动时不会自动改写配置。报错信息中会写明当前格式和所需格式，并给出应该执行的命令。请按[从源码运行](./install-source#更新)中的步骤执行一遍。

使用部署包和 Docker 时，通过面板升级，更新器会自动执行这些迁移。

如果报错说配置格式比程序新，说明这份配置是由更新的 LenBot 版本写入的。请换回那个版本，或者在更新页恢复升级前的快照。

## 登录面板时一直提示尝试过于频繁

同一个 IP 在 15 分钟内输错 5 次密码后，这个 IP 的登录会被暂时拒绝，即使输入正确的密码也一样。等待 15 分钟后即可恢复。

面板部署在反向代理后面时，所有人都从代理的地址登录。一个人连续输错密码，其他人也会暂时无法登录。

## 升级失败

打开更新与恢复页，按页面上给出的操作恢复或重新启动，见[更新与恢复](./update#出问题时)。

## 是否支持其他聊天平台

目前只支持 QQ。账号已经按 `平台:账号` 的格式设计，以后有需要时再添加其他平台。

## 能否用语音回复

不能。LenBot 可以把群里的语音转写成文字来理解，但只用文字回复。

## 如何查看 token 用量

**模型 → 用量与上限**中显示今天和本月的 token 用量，按群和用途分别列出。数字来自模型服务的报告，LenBot 不换算成金额，实际费用以服务商的账单为准。
