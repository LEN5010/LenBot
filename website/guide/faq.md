# 常见问题

## 首次配置的链接打不开

链接是 `127.0.0.1` 开头的本机地址，只能在运行 LenBot 的那台机器上打开。装在远程服务器上时，先用 SSH 把终端里显示的端口转发到本机，再在本机浏览器打开同一个链接：

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 测试连接读不出 Bot 账号

- 先确认 OneBot 那边 QQ 已经登录，WebSocket 已经打开。
- 正向连接：地址要写 OneBot 的 WebSocket 服务端地址，`ws://` 开头。LenBot 在 Docker 里时，`127.0.0.1` 指的是容器自己。
- 反向连接：OneBot 要用 Universal 模式，地址和端口与 LenBot 的监听设置一致，两边访问令牌相同。
- 错误信息原样显示在按钮下面，对着它查。见[接入 QQ](./onebot)。

## Bot 在群里不说话

- 首页看 OneBot 连接状态，以及这个群的聊天开关是不是开着。
- 发送方式是不是还在模拟发送。模拟发送时回复只记在本地。
- 新加的群默认只回应 @ 它或回复它的消息。想让它主动参与，在**群聊 → 设置**里关掉「只在被 @、被回复或私聊时说话」，再调活跃度和关键词。
- 群里设了安静时段的话，那段时间它不主动说话。
- **模型**页看今天的 token 是否到了上限，**日志**页看这一轮有没有报错。

## 读网页、取图片总是失败

错误里有 `私有或保留地址` 的话，多半是代理软件开了 fake-ip，见[可选服务](./optional-services#代理软件的-fake-ip-模式)。

## 启动时说实例锁被占用

同一个实例同时只能有一个 LenBot 或维护命令在运行。先停掉另一个。在终端里按过 Ctrl-Z 挂起的进程也占着锁，用 `fg` 恢复后再 Ctrl-C。不要手动删锁文件。

## 升级失败了

打开更新与恢复页，按页面上给出的操作恢复或启动，见[更新与恢复](./update#出问题时)。

## 支持别的聊天平台吗

目前只有 OneBot（QQ）。账号格式已经按 `平台:账号` 设计，其他平台以后按需求再加。

## 能用语音回复吗

不能。LenBot 能转写群里的语音，但不做语音合成（TTS）。

## 模型怎么计费

LenBot 不算钱，只统计模型服务报告的 token，实际费用以服务商账单为准。模拟发送、对话测试和首次配置里的模型测试都会真实调用模型。
