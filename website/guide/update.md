# 更新与恢复

部署包和 Docker 安装都带一个**更新器**。它和 LenBot 分开运行，所以 LenBot 停机升级时，更新页仍然能打开；升级失败也能从这里恢复。

源码运行不走更新器，见[从源码运行](./install-source#更新)。

## 新版本检查

面板启动 60 秒后查一次有没有新版本，之后每 24 小时查一次。部署包和 Docker 问自己的更新器，源码运行直接查 GitHub Releases。只查询，不下载、不安装，升级仍然要你在更新页确认。查询失败只在运行日志里记一条警告（事件名 `release_check`），不影响聊天。

不想让它定期访问 GitHub，停机后在 `lenbot.config.json` 的 `panel` 里加上 `"update_check": false`。这只关掉后台的定期检查，手动检查照常可用。

目前面板界面还没有显示后台检查的结果。要看有没有新版本，在**设置 → 版本与更新**里点「检查发行版本」，列表从新到旧排；源码运行也能用。

## 在面板里更新

1. 面板 → 设置 → 版本与更新，点**打开更新与恢复页**。
2. 点检查发行版本，选一个版本。默认只显示正式版，勾上显示预发布版本才能看到候选版。
3. 点**准备更新**。更新器下载新版本（Docker 拉取新镜像），装好新的程序环境，检查已启用的插件是否兼容。这一步 LenBot 照常运行。
4. 准备好后确认**停机、备份并升级**。更新器依次：停止 LenBot，给实例做完整快照，执行数据迁移并检查实例，切到新版本，启动并等它就绪。

做快照前会先估算大小。磁盘放不下快照外加 256 MiB 余量时直接停下，程序和数据都不动，清出空间后再升级就行。迁移后的检查（和 `doctor` 命令相同）没通过，也算升级失败，可以从快照恢复。

升级期间聊天和后台任务会停下。进行中的任务标为中断，保留会话和文件，之后可以续接。

### 插件不兼容

准备阶段发现已启用的插件不支持新版本时，会列出这些插件并停止准备。先升级这些插件，或者在插件页停用它们，再重新准备。停用的插件保留源码、参数和数据。

### 后台任务镜像

用的是官方任务镜像 `lenbot-worker` 时，准备阶段会提前拉取同版本的任务镜像，升级时一起切换。自己构建的任务镜像不会改动，需要时自己重建再改配置。

## 出问题时

更新器不会自动重试，也不会自动回退。每一步失败后，更新页都会告诉你能做什么：

| 在哪一步失败 | LenBot 的状态 | 能做的事 |
|---|---|---|
| 准备（下载、装环境、兼容检查） | 照常运行 | 处理问题后重新准备 |
| 已停机，快照还没做完 | 停着，程序和数据都没动 | 启动原来的版本 |
| 快照完成之后（迁移、切换、新版本启动） | 停着 | 恢复升级前的程序和数据 |

**恢复**会把程序和实例数据都换回升级前的快照，升级之后产生的聊天记录和修改会丢失。恢复完成后点启动。

恢复前会逐个核对快照里每个文件的长度和 SHA-256，有缺失或损坏就停下。核对通过后先把快照完整复制到实例旁边的临时位置，复制中途出错（比如磁盘满）同样不动当前实例，全部复制完才替换。

升级成功之后，在准备下一次更新之前，也可以随时从更新页恢复到升级前。

### 打开更新页

面板还能用时，从设置里进入。面板打不开时：

- **部署包**：`run` 启动时打印的那行「更新与恢复」链接；用服务运行时在服务日志里找。
- **Docker**：`docker compose -p lenbot logs lenbot-updater`，日志里有带会话令牌的链接，默认端口 11308。

## 离线升级（部署包）

不经过面板也可以升级：停掉 LenBot，在新版本的部署包目录里执行

```sh
./install.sh upgrade "$HOME/lenbot"
```

它和面板升级做同样的事：检查插件、备份快照、迁移数据、切换版本，最后不启动，由你自己启动。之后同样可以在更新页恢复到升级前。上一次升级失败还没恢复时，离线升级会拒绝执行，先去更新页恢复。

## 更新器自己的升级

更新器不会替换自己。新版本要求更新的更新器时，更新页不会继续准备，而是直接给出命令：

- **部署包**：用新版部署包执行离线升级（上面的 `install.sh upgrade`），会同时更新程序和更新器。
- **Docker**：用新版更新器镜像执行一次 `init.py --updater-only`，再 `docker compose up -d` 换上新的更新器，然后回到更新页继续。

## 版本规则

- `0.2.0` 这样的是正式版；带 `rc`、`b`、`a` 后缀的是预发布。
- 补丁版本（`0.2.1`）保持插件接口和数据格式兼容；不兼容的变化会升次版本（`0.3.0`）。
- 发布过的版本不会被覆盖。每个版本的说明在 [changelogs](https://github.com/lendevs/LenBot/tree/master/changelogs)。
