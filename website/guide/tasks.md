# 后台任务

写报告、整理资料、做网页这类要花几分钟到几十分钟的活，Bot 可以交给后台任务。任务在独立的 Docker 容器里由 Pi 执行，聊天照常进行，不用等它做完。

比如在群里说「帮我把这周群里聊到的游戏整理成一页表格」，Bot 可以把它交给一个任务，做完后把文件发回群里。

## 启用

需要一台能跑 Docker 的机器。Windows 上请用 [Docker 安装](./install-docker)或 WSL2。

1. **准备任务镜像**：用官方的 `ghcr.io/lendevs/lenbot-worker:<版本>`，或者用仓库里的 `docker/next-worker/Dockerfile` 自己构建。
2. **配置任务环境**：在**能力 → 独立任务**里填 Docker 命令的绝对路径、Docker socket、工作目录、运行目录和交付目录。三个目录要分开，Docker 能访问，容器的 `uid/gid` 能读写。
3. **绑定模型**：在**模型**页给 `worker` 用途绑一个模型。
4. **按群打开**：在**群聊 → 设置**里打开「允许委托任务」，在**群聊 → 权限**里设定谁能委托任务。
5. **角色许可**：角色的工具许可里要有 `delegate`、`task` 和 `tool_search`；任务要用某个技能时，角色的技能许可里也要有它。

任务容器没有网络，模型和公网请求都经 LenBot 转发，真实密钥不进容器。Docker 安装时的挂载方式见 [Docker](./install-docker#后台任务)。

## 使用

- **资料**：资源页可以上传本群的共享资料。新建任务时可以从共享资料、其他任务的文件和交付里选，最多 16 份，任务拿到的是只读副本。
- **追问和续接**：任务可以反过来问发起人，等回答时不占执行名额。任务结束后可以明确续接，沿用原来的会话和文件。失败不会自动重试。
- **产物**：生成文件、登记为交付、发到 QQ 是三件事，各有记录。在任务详情里可以预览、下载、登记和发送。
- **清理**：「清理临时文件」保留会话、输入和产物；「释放环境」删除整个工作区，之后不能再续接，已登记的交付和共享资料保留。
- **渲染**：任务镜像自带 `lenbot-render`，能把 HTML 渲染成 PDF 和截图。

## 发到 QQ

OneBot 要能读到交付目录：把交付目录只读挂给 OneBot，再把 `onebot.upload_visible_root` 设成 OneBot 那边看到的路径（**设置 → 连接**的高级选项）。

面板显示「已登记」不代表 QQ 已经收到，实际上传结果另有记录。

## 重启和升级时

重启或升级会中断正在执行的任务。任务标为中断，会话和文件保留，之后可以续接；排队中的任务继续排队。

用官方任务镜像时，部署包和 Docker 的面板升级会顺带换成同版本的任务镜像；自己构建的镜像要自己重建、改配置。
