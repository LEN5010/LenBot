# 后台任务

有些工作需要几分钟到几十分钟才能完成，例如写报告或整理资料，也可以是制作一个网页。Bot 可以把这类工作交给后台任务。每个任务在单独的 Docker 容器中运行，由容器里的编程助手 Pi 执行。任务运行期间，群里照常聊天，不需要等待任务完成。

例如在群里说「帮我把这周群里聊到的游戏整理成一页表格」，Bot 可以把这件事交给一个任务，完成后把文件发回群里。

## 启用

需要一台能运行 Docker 的机器。在 Windows 上请使用 [Docker 安装](./install-docker)或 WSL2。

1. **准备任务镜像**。使用官方的 `ghcr.io/lendevs/lenbot-worker:<版本>`，或者用仓库里的 `docker/next-worker/Dockerfile` 自行构建。
2. **配置任务环境**。在**能力 → 独立任务**中填写以下内容。
   - Docker 命令的绝对路径
   - Docker socket
   - 工作目录
   - 运行目录
   - 交付目录

   这三个目录必须互相分开，Docker 能够访问，并且容器的 `uid/gid` 有读写权限。
3. **选择模型**。在**模型 → 用途**中打开「任务」，选择一个模型。
4. **按群启用**。在**群聊 → 设置**中打开「允许委托任务」，在**群聊 → 权限**中设定谁可以委托任务。
5. **角色许可**。角色的工具许可中需要有 `delegate`、`task` 和 `tool_search`。任务需要使用某个技能时，角色的技能许可中也要包含这个技能。

任务容器没有网络。模型请求和公网请求都由 LenBot 转发，真实密钥不会进入容器。Docker 安装时的挂载方式见 [Docker](./install-docker#后台任务)。

## 使用

### 资料

在资源页可以上传本群的共享资料。新建任务时，可以从共享资料中选择，也可以选择其他任务的文件和交付，最多 16 份。任务得到的是只读副本。

### 追问和续接

任务可以向发起人提问，等待回答期间不占用执行名额。任务结束后，可以明确要求续接，续接时沿用原来的会话和文件。任务失败后不会自动重试。

### 产物

文件生成以后，登记为交付和发送到 QQ 各是一个独立的步骤，每一步都有记录。在任务详情中可以预览和下载文件，也可以登记和发送。

### 清理

- 「清理临时文件」不影响会话和输入，产物也会保留。
- 「释放环境」会删除整个工作区，之后无法再续接。已登记的交付和共享资料会保留。

### 渲染

任务镜像自带 `lenbot-render`，可以把 HTML 渲染成 PDF 和截图。

## 发到 QQ

OneBot 必须能读取交付目录。设置方法分两步。

1. 把交付目录以只读方式挂载给 OneBot。
2. 在**设置 → 连接**的高级选项中，把 `onebot.upload_visible_root` 设为 OneBot 一侧看到的路径。

登记为交付和发送到 QQ 是两个步骤。发送是否成功，请查看任务详情中的发送记录。

## 重启和升级时

重启或升级会中断正在执行的任务。这些任务会被标记为中断，会话和文件保留，之后可以续接。排队中的任务继续排队。

使用官方任务镜像时，部署包和 Docker 通过面板升级，会一并换成同版本的任务镜像。自行构建的镜像需要自己重新构建，并修改配置。
