# 插件

插件给 Bot 加命令、定时推送、工具和技能。LenBot 本身不带业务插件，下面这些都单独安装、单独更新：

| 插件 | 做什么 |
|---|---|
| [群聊总结](https://github.com/lendevs/lenbot-plugin-group-digest) | `/群日报` 把过去一段时间的聊天做成总结卡片，也可以每天定时发；`/群总结` 出文字总结，`/群工作` 把长工作交给后台任务；Bot 也能在聊天里自己调用 |
| [GSUID Core 桥接](https://github.com/lendevs/lenbot-plugin-gscore-adapter) | `/gs` 把命令转给独立运行的 GSUID Core，图文由 LenBot 发出 |
| [A-SOUL 日程与动态](https://github.com/lendevs/lenbot-plugin-asoul) | `/日程` 发日程卡片，也能查动态和二创并发卡片 |
| [哔哩哔哩](https://github.com/lendevs/lenbot-plugin-bilibili) | 查视频、搜索，推送直播和关注的更新；配置主人账号后可以读取、点赞和收藏 |

这几个插件还没有正式版本，安装的是和当前 LenBot 一起测试过的提交。

## 安装

在**插件 → 发现插件**里从目录选，或者填 Git 仓库地址、上传 ZIP。安装分两步：

1. **准备**：下载或解包，读清单，检查 LenBot 版本、Python 版本和系统是否兼容。这一步不执行插件代码，也不影响正在运行的版本。
2. **应用**：填好必填参数后点应用。依赖没变的插件直接重载；依赖变了，或者插件声明需要重启的，等下次重启时在停机阶段装好依赖再切换。

装好后插件默认不在任何群生效。打开插件详情里的「在哪些群使用」，点群名开启或关闭，立即生效，只重载这个插件，聊天不中断。

用 Git 安装插件时，系统里要有 `git`。

## 更新和回退

- Git 安装可以指定分支、标签或提交，更新时沿用原来的选择。ZIP 安装的插件，更新就是再导入一次新包。
- 新版本的参数单独保存，真正应用新版本时才生效；取消更新则保留旧版本的参数。
- 应用新版本时，旧版本的源码和参数会留一份。新版本加载、启动或数据迁移失败，LenBot 自动换回旧版本；新版本已经动过数据的话，数据也恢复成升级前的备份。
- 插件详情里可以手动「回到上一版本」一次。手动回退只换源码和参数，不动数据。
- 插件要改数据格式时，LenBot 先把插件数据备份到 `.backups`，再让插件迁移。旧版本插件读不了新格式，会拒绝启动并说明原因。

## 停用和卸载

- 停用保留参数和选群。
- 卸载删除源码和配置，保留插件数据；删除数据是单独的操作。

## 依赖和兼容

插件和 LenBot 共用一个 Python 环境。依赖冲突时直接显示原始错误，不会自动放宽版本。

LenBot 升级前会检查已启用的插件是否兼容新版本，不兼容就停在准备阶段，见[更新与恢复](./update#插件不兼容)。

## 从旧版内置插件迁移

群聊总结、GSUID Core 桥接等插件以前是内置的。更新 LenBot 后安装同名插件即可，原来的参数、选群和数据都会保留。

时间查询和 RSS 播报已经删除，旧实例要从配置里去掉 `clock`、`rss_broadcast`。Bot 每轮仍然能看到当前时间。

自己写插件见[写插件](../develop/plugins)。
