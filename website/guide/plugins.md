# 插件

插件可以为 Bot 增加命令和定时推送，也可以提供工具和技能。LenBot 本身不带业务插件，下面的官方插件都需要单独安装和更新。

| 插件 | 功能 |
|---|---|
| [群聊总结](https://github.com/lendevs/lenbot-plugin-group-digest) | `/群日报` 把一段时间内的聊天整理成总结卡片，也可以每天定时发送。`/群总结` 生成文字总结。`/群工作` 把较长的工作交给后台任务。聊天中 Bot 也可以调用这些功能 |
| [GSUID Core 桥接](https://github.com/lendevs/lenbot-plugin-gscore-adapter) | `/gs` 把命令转发给独立运行的 GSUID Core，返回的图文由 LenBot 发送 |
| [A-SOUL 日程与动态](https://github.com/lendevs/lenbot-plugin-asoul) | `/日程` 发送日程卡片。也可以查询动态和二创，并发送卡片 |
| [哔哩哔哩](https://github.com/lendevs/lenbot-plugin-bilibili) | 查询视频和搜索，推送直播和关注的更新。配置主人账号后，可以读取、点赞和收藏 |

这些插件还没有发布正式版本。安装时使用的是和当前 LenBot 一起测试过的提交。

## 安装

在**插件 → 发现插件**中安装。安装来源有三种。

- 从插件目录中选择
- 填写 Git 仓库地址
- 上传 ZIP

使用 Git 安装时，系统里需要有 `git`。

安装分为两步。

1. **准备**。下载或解包插件，读取插件清单，检查 LenBot 版本和 Python 版本是否兼容，以及系统是否支持。这一步不执行插件代码，也不影响正在运行的版本。
2. **应用**。填写必填参数后应用。依赖没有变化的插件会直接重新加载。依赖有变化，或者插件声明需要重启时，要等到下次重启，在停机阶段安装依赖后再切换。

插件安装后默认不在任何群启用。在插件详情的「在哪些群使用」中点击群名，可以开启或关闭。修改立即生效，只重新加载这个插件，聊天不会中断。

## 更新和回退

- 通过 Git 安装的插件可以指定分支、标签或提交，更新时沿用原来的选择。通过 ZIP 安装的插件，更新时重新导入新版本的包。
- 新版本的参数单独保存，应用新版本时才生效。取消更新时，旧版本的参数保持不变。
- 应用新版本时，旧版本的源码和参数会保留一份。如果新版本在加载、启动或数据迁移时失败，LenBot 会自动换回旧版本。新版本已经修改过数据时，数据也会恢复为升级前的备份。
- 在插件详情中可以手动「回到上一版本」一次。手动回退只替换源码和参数，不改动数据。
- 插件需要修改数据格式时，LenBot 先把插件数据备份到 `.backups`，再执行插件的迁移。旧版本插件无法读取新格式，会拒绝启动并说明原因。

## 停用和卸载

- 停用插件时，参数和启用的群都会保留。
- 卸载插件时，源码和配置会被删除，插件数据会保留。删除数据需要单独操作。

## 依赖和兼容

插件和 LenBot 使用同一个 Python 环境。依赖发生冲突时会直接显示原始错误，不会自动放宽版本要求。

LenBot 升级前会检查已启用的插件是否兼容新版本。有插件不兼容时，升级停在准备阶段，见[更新与恢复](./update#插件不兼容)。

## 从旧版内置插件迁移

群聊总结和 GSUID Core 桥接等插件以前内置在 LenBot 中。更新 LenBot 后安装同名插件即可，原来的参数和启用的群都会保留，插件数据也会保留。

时间查询和 RSS 播报已经删除。旧实例需要从配置中删除 `clock` 和 `rss_broadcast`。Bot 每轮回复时仍然能看到当前时间。

编写插件的方法见[写插件](../develop/plugins)。
