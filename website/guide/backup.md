# 备份

## 升级时的自动快照

使用部署包和 Docker 时，每次升级前都会停机并制作一份完整快照，存放在安装目录的 `backups/` 下。升级失败，或者升级后不满意，都可以从更新页恢复。快照不会自动删除，确认新版本运行正常后，可以手动删除旧快照。

## 手动备份

停止 LenBot 后，备份以下内容。

- **实例目录**。部署包是 `instance/`，从源码运行时是仓库根目录，Docker 是数据卷 `lenbot-data`。其中包括配置和数据库。角色和记忆，以及插件和插件数据，也都保存在这里。
- **实例以外的目录**。包括配置中指向实例以外的角色目录和插件目录，以及后台任务的工作目录、运行目录和交付目录。

数据库旁边的 `-wal` 和 `-shm` 文件也属于数据，需要和数据库一起备份。LenBot 运行期间复制数据库，得到的副本可能前后不一致，因此必须先停止 LenBot。

`lenbot.config.json` 中有模型服务和 OneBot 的密钥，也有面板的密钥。因此备份文件需要按密钥的标准保管。

Docker 数据卷可以用一个临时容器打包。

```sh
docker run --rm --mount type=volume,source=lenbot-data,target=/data,readonly \
  -v "$PWD":/backup alpine tar -czf /backup/lenbot-data.tar.gz -C /data .
```

## 恢复

把备份放回原来的位置，用备份时的同一个版本启动。旧版本的程序无法读取新版本的数据。需要回退版本时，请使用升级前的快照恢复。
