# 首次配置

LenBot 的配置和数据保存在实例目录里。实例目录中还没有配置文件 `lenbot.config.json` 时，LenBot 会先启动一个网页向导，并在终端输出它的地址。

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

使用部署包或从源码运行时，向导只监听本机，端口每次随机分配。Docker 固定使用 11307，见 [Docker](./install-docker#第一次启动)。链接里的 `token` 只在本次启动有效。

向导会把已填写的内容暂存在浏览器标签页中，刷新页面不会丢失。密码和密钥不会暂存，刷新后需要重新填写，QQ 连接和模型也要重新测试。

已经配置过的实例不会再打开向导，之后的修改都在面板里进行。

## 1. 管理员账号

这是登录面板用的用户名和密码，密码至少 8 位。每个实例只有这一个面板账号。

面板端口默认为 8088。面板只监听本机，安装在服务器上时需要用 SSH 端口转发访问，方法见本页最后一节。

## 2. 连接 QQ

连接方式有两种。

- **LenBot 连接 OneBot**（正向 WebSocket）。填写 OneBot 的 WebSocket 地址，例如 `ws://127.0.0.1:3001`。两边在同一台机器上时，这种方式最简单。
- **OneBot 连接 LenBot**（反向 WebSocket）。填写 LenBot 监听的地址和端口，再在 OneBot 中把反向连接地址指向这里。

两种方式的区别和 OneBot 一侧的设置见[接入 QQ](./onebot)。

**访问令牌**要和 OneBot 中填写的一致，OneBot 没有设置时留空。反向连接监听 `127.0.0.1` 以外的地址时，必须设置访问令牌。

填写完成后，点击「测试连接并读取 Bot 账号」。LenBot 会连接 OneBot 并读取当前登录的 QQ 号，成功时显示「连上了，Bot 的 QQ 号是 …」。测试通过后才能进入下一步。

最后选择**回复怎么发**。第一次建议选择模拟发送。这时 Bot 照常接收消息并生成回复，但回复只显示在面板里。确认没有问题后，再到**设置 → 连接**改为真实发送到 QQ。

## 3. 主人

填写自己的 QQ 号。主人是这个 Bot 权限最高的用户，其他主人可以之后在面板里添加。

时区默认为 `Asia/Shanghai`。提醒和安静时段按这个时区计算，面板里显示的时间也是。

## 4. 选择模型

这一步配置的是聊天使用的模型。看图和整理记忆可以使用别的模型，后台任务也一样。这些用途进入面板后再配置，见[可选服务](./optional-services#模型用途)。

1. **模型协议**。按服务商提供的协议选择 OpenAI 兼容接口、OpenAI Responses、Anthropic 或 Gemini。切换协议时会填入该协议的默认地址，使用第三方服务时改成服务商给出的地址。
2. **接口地址和 API Key**。按服务商提供的信息填写。如果访问服务商需要代理，填写一个 HTTP 或 HTTPS 代理地址。
3. **聊天模型**。点击「读取模型列表」后从下拉列表中选择。读取不到列表时，直接填写模型名。
4. **上下文窗口**。按服务商文档填写。「更多模型选项」里的输入压缩阈值和输出上限都有默认值，一般不需要修改。

最后点击「测试模型」。「只测文本」调用一次模型。「测工具调用」调用两次，检查模型能否正确调用工具。显示「通过」后才能进入下一步。

## 5. 角色和第一个群

角色默认使用**小然**。小然的设定是群里的一位老朋友，喜欢吃东西和画画。这个角色的设定和说话方式都已写好，资料和表情也已备齐，之后可以在面板里修改。

如果想从头编写角色，选择「自己写一个」，然后填写文件夹名和名字，再描述这个角色的性格和说话方式。底线可以先不填。

接着填写第一个群的群号。也可以选择私聊，填写对方的 QQ 号。在群里，Bot 一开始只回应 @ 它或回复它的消息；私聊中每条消息都会回复。其他群之后在面板里添加。

## 6. 官方插件

这一步列出官方插件，例如群聊总结和哔哩哔哩。勾选的插件会在保存时下载，所需的 Python 依赖也会一起安装。进入面板后再启用插件和修改设置，并选择在哪些群使用。GSUID Core 桥接插件还需要另外运行 GSUID Core。

不需要插件时，点击「跳过插件，直接保存」。之后可以随时在插件页安装。

插件安装失败时，账号和配置都还没有保存，已经装好的插件会保留。可以重试，或者取消勾选失败的插件。

## 保存之后

LenBot 按新配置启动，页面显示「正在启动 LenBot」。面板启动后，页面自动跳转到登录页。

页面上还会显示面板地址。通过 SSH 端口转发或反向代理访问时，本机看到的端口可能不同，请先改成实际访问的地址，再点击「打开面板」。

如果半分钟后面板仍然没有响应，页面会提示「配置已保存」。这时请查看终端输出，常见原因是面板端口已被占用。配置已经写入，问题解决后重新启动 LenBot 即可，不需要再走一遍向导。

## 之后修改设置

所有设置都保存在实例目录的 `lenbot.config.json` 中，LenBot 只读取这一个文件。文件里有 API Key 和密码哈希，不要提交到 Git。

平时在面板里修改设置。有些设置需要重启才能生效，保存后顶栏会提示。点击重启之前，面板会列出受影响的设置和正在进行的工作。如果要手动编辑这个文件，请先停止 LenBot。

## 从其他机器打开面板

面板默认只监听本机。需要从其他机器访问时，可以使用 SSH 端口转发。

```sh
ssh -L 8088:127.0.0.1:8088 你的服务器
```

然后在自己的电脑上打开 `http://127.0.0.1:8088`。如果要长期从外网访问，请在面板前面配置 HTTPS 反向代理。
