# 首次配置

实例里还没有配置时，启动会打印一个链接，例如：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

链接里带一次性令牌，只在这台机器上能打开。Docker 安装固定使用面板端口，见 [Docker](./install-docker#第一次启动)。

向导分五部分：

1. **连接 QQ**：选 OneBot 连接方式（见[接入 QQ](./onebot)），点测试连接读出 Bot 的 QQ 号。在这里选发送方式，刚开始建议选模拟发送。
2. **主人**：你自己的 QQ 号。主人能在群里让 Bot 改设置，更多主人之后在面板里加。
3. **模型**：兼容 OpenAI 聊天接口的地址、API Key、模型名和上下文窗口。窗口大小照服务商文档填。保存前会真实调用一次，确认能用。
4. **角色与第一个场景**：角色叫什么、是什么样的人、怎么说话、底线；先在哪个群或私聊里聊。在群里，默认只回应 @ 它或回复它的消息；私聊每条都回。
5. **面板登录**：用户名、至少 8 位的密码和面板端口。面板默认只能在本机打开。

保存后向导关闭，程序在同一个进程里继续启动，打开面板登录就行。

## 之后改设置

所有设置都写在实例目录的 `lenbot.config.json` 里，这是唯一的运行配置，含密钥，不要提交到 Git 或发给别人。

运行中在面板里改。需要重启才生效的修改，顶栏会提示，点重启时会列出受影响的设置和正在进行的工作。要手工编辑这个文件，先停机。

## 从别的机器打开面板

面板只监听本机地址。要从别的机器访问，用 SSH 端口转发，或者自己配 HTTPS 反向代理；不要直接把监听地址改成公网。
