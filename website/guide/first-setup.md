# 首次配置

实例里还没有配置时，启动会打印一个链接，例如：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

链接里带本次启动的初始化令牌，默认只监听本机。刷新页面保留令牌和非敏感草稿，密钥与密码需要重新填写；QQ 和模型也需重新测试。Docker 安装固定使用面板端口，见 [Docker](./install-docker#第一次启动)。

向导分六部分：

1. **创建管理员账号**：本实例的面板用户名、至少 8 位的密码、重复密码与面板端口。这不是公开注册系统。
2. **连接 QQ**：选 OneBot 连接方式（见[接入 QQ](./onebot)），点测试连接读出 Bot 的 QQ 号。刚开始可选模拟发送；模型照常调用并可能计费，回复不发到 QQ。
3. **主人**：你自己的 QQ 号，更多主人之后在面板里加。
4. **模型**：选择 OpenAI 兼容、Responses、Anthropic 或 Gemini，填写对应 API 根地址与密钥；可读取模型列表，也可手动填写。上下文窗口照服务商文档填，压缩阈值随窗口计算，也可调整。文本测试调用一次，工具续接测试调用两次，都可能计费，不向 QQ 发消息；普通文本成功不代表工具或图片可用。
5. **角色与第一个场景**：角色叫什么、是什么样的人、怎么说话、底线；先在哪个群或私聊里聊。在群里，默认只回应 @ 它或回复它的消息；私聊每条都回。

6. **官方插件（可跳过）**：可选择 lendevs 的群聊总结、GSUID Core 桥接、A-SOUL 或哔哩哔哩插件。默认不选；保存时安装目录锁定的开发提交和声明的 Python 依赖，插件先保持停用。进入插件页配置、启用和选择群；GSUID Core 服务仍需单独部署。安装失败会保留填写内容与已下载的插件，可重试或取消失败项继续。

保存后向导关闭，程序继续启动并跳到面板登录。普通聊天无需先部署任务容器或账号浏览。QQ／模型测试失败时填写内容保留，按错误修改后重试；保存失败也不会重置表单。已有根配置不能重复初始化。

远程访问使用当前浏览器的主机名；如果 SSH 转发或反向代理的端口不同，可在保存结果下调整面板地址后打开。启动失败或迟迟未就绪时检查终端日志，已保存的配置无需再次初始化。

## 之后改设置

所有设置都写在实例目录的 `lenbot.config.json` 里，这是唯一的运行配置，含密钥，不要提交到 Git 或发给别人。

运行中在面板里改。需要重启才生效的修改，顶栏会提示，点重启时会列出受影响的设置和正在进行的工作。要手工编辑这个文件，先停机。

## 从别的机器打开面板

面板只监听本机地址。要从别的机器访问，用 SSH 端口转发，或者自己配 HTTPS 反向代理；不要直接把监听地址改成公网。
