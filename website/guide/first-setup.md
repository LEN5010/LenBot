# 首次配置

实例目录（LenBot 存放配置和数据的目录）里还没有配置文件 `lenbot.config.json` 时，LenBot 先打开一个网页向导，终端里会打印它的地址：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
```

部署包和源码运行时，向导只监听本机，端口每次随机；Docker 固定用 11307，见 [Docker](./install-docker#第一次启动)。链接里的 `token` 只在这次启动有效。

向导会把填过的内容暂存在浏览器标签页里，刷新不会丢。密码和密钥不暂存，刷新后要重新填，QQ 和模型也要重新测试一次。

已经配置过的实例不会再打开向导，之后的修改都在面板里做。

## 1. 管理员账号

登录面板用的用户名和密码，密码至少 8 位。每个实例只有这一个面板账号。

面板端口默认 8088。面板只监听本机，装在服务器上时用 SSH 端口转发访问，见本页最后一节。

## 2. 连接 QQ

先选连接方式：

- **LenBot 去连 OneBot**（正向 WebSocket）：填 OneBot 的 WebSocket 地址，比如 `ws://127.0.0.1:3001`。两边在同一台机器上时选这个最省事。
- **OneBot 来连 LenBot**（反向 WebSocket）：填 LenBot 监听的地址和端口，再到 OneBot 里把反向连接地址指向它。

两种方式的区别和 OneBot 那边怎么设，见[接入 QQ](./onebot)。

**访问令牌**和 OneBot 里填的保持一致，没设就留空。反向连接监听的不是 `127.0.0.1` 时一定要设。

填好后点「测试连接并读取 Bot 账号」。LenBot 会连上 OneBot，读出当前登录的 QQ 号，显示「连上了，Bot 的 QQ 号是 …」。测试通过才能进下一步。

最后选**回复怎么发**。第一次建议选模拟发送：Bot 照常收消息、想回复，回复只出现在面板里。看着没问题再到**设置 → 连接**改成真实发送到 QQ。

## 3. 主人

填你自己的 QQ 号。主人是这个 Bot 权限最高的人，更多主人之后在面板里加。

时区默认 `Asia/Shanghai`，提醒、安静时段和面板里的时间都按它算。

## 4. 选择模型

这一步配的是聊天用的模型。看图、整理记忆、后台任务这些用途可以换别的模型，进面板再配，见[可选服务](./optional-services#模型用途)。

1. **模型协议**：选服务商提供的那种，OpenAI 兼容接口、OpenAI Responses、Anthropic 或 Gemini。切换协议时会填上这种协议的默认地址，用第三方服务就改成它给的地址。
2. **接口地址和 API Key**：照服务商给的填。访问服务商要走代理的话，填一个 HTTP 或 HTTPS 代理地址。
3. **聊天模型**：点「读取模型列表」后从下拉里选，列表读不出来就直接填模型名。
4. **上下文窗口**：照服务商文档填。「更多模型选项」里的输入压缩阈值和输出上限有默认值，一般不用改。

最后点「测试模型」。「只测文本」调用一次模型，「测工具调用」调用两次，看看模型能不能正确调用工具。看到「通过」才能进下一步。

## 5. 角色和第一个群

角色默认用**小然**：群里爱吃、爱画画的老朋友，设定、说话方式、资料和表情都配好了。之后在面板里随时能改。

想从头写一个，就选「自己写一个」，填文件夹名、名字、它是什么样的人、怎么说话，底线可以先空着。

再填第一个群的群号，或者选私聊、填对方的 QQ 号。在群里它先只回应 @ 它或回复它的消息，私聊每条都回。更多群之后在面板里加。

## 6. 官方插件

列出的是官方插件，比如群聊总结、哔哩哔哩。勾选的插件会在保存时下载，连同它需要的 Python 依赖一起装好，进面板后再启用、配置和选群。GSUID Core 桥接还需要你另外运行 GSUID Core。

不需要的话点「跳过插件，直接保存」，以后在插件页随时能装。

插件装失败时，账号和配置都还没有保存，已经装好的插件会留着。可以再试一次，或者取消勾选失败的那个。

## 保存之后

LenBot 按新配置启动，页面显示「正在启动 LenBot」，面板启动好后自动跳到登录页。

页面上同时给出面板地址。用 SSH 端口转发或反向代理访问时，本机看到的端口可能不一样，改成你实际访问的地址再点「打开面板」。

半分钟后面板还没响应，页面会提示「配置已保存」。这时去看终端里的输出，常见原因是面板端口被占用了。配置已经写好，处理好后重新启动 LenBot 就行，不用再走一遍向导。

## 之后改设置

所有设置都存在实例目录的 `lenbot.config.json` 里，LenBot 只读这一个文件。里面有 API Key 和密码哈希，别提交到 Git。

平时在面板里改。有些设置要重启才生效，保存后顶栏会提示，点重启前会列出受影响的设置和正在进行的工作。要手工编辑这个文件的话，先停掉 LenBot。

## 从别的机器打开面板

面板默认只监听本机。从别的机器访问，可以用 SSH 端口转发：

```sh
ssh -L 8088:127.0.0.1:8088 你的服务器
```

然后在自己电脑上打开 `http://127.0.0.1:8088`。要长期从外网访问，就在前面配一个 HTTPS 反向代理。
