# 面板一览

面板左侧按用途分组：

| 页面 | 管什么 |
|---|---|
| 首页 | 连接状态、各群今天的情况、最近的错误 |
| 对话测试 | 用当前角色和模型试聊，不发到 QQ |
| 日志 | 每轮回复的经过、模型调用和运行日志 |
| 群聊 | 每个群的消息记录、回复设置、权限、关系说明和学习 |
| 角色 | 设定、说话方式、样例、知识、表情、头像，草稿试聊 |
| 记忆 | 浏览、修改、删除和遗忘长期记忆 |
| 任务、资源 | 后台任务、提醒、主动话题，任务文件和共享资料 |
| 插件 | 安装、配置插件，选在哪些群启用 |
| 能力 | 工具和技能、MCP 服务、网页服务、后台任务环境 |
| 模型 | 服务商、各用途绑定的模型、token 上限 |
| 设置 | 连接、面板账号、数据保留、版本与更新 |

## 账号和群的写法

面板里填主人、管理员、白名单和关系说明时，账号写成 `平台:账号`，群写成 `平台:group:群号`，私聊写成 `平台:private:账号`。目前只有 OneBot 一个平台：

```text
onebot:90001          Bot 自己
onebot:70001          主人
onebot:group:80001    群
onebot:private:70001  和主人的私聊
```

## 权限

**群聊 → 权限**里分两部分：上面的管理员、白名单、黑名单所有群通用；下面可以给本群另加名单，并按群设定谁能委托任务、定提醒、让 Bot 暂时安静。主人在**设置 → 连接**里改。

## 首页快捷操作

- **群聊开关**：群卡片右侧的开关。关掉后这个群的消息照常记录，但 Bot 不回复、不主动发言，被 @ 也不回，插件也不在这个群响应。重新打开后从新消息开始，不补回关闭期间的话。
- **断开 QQ**：立刻关闭 OneBot 连接，正在进行的回复和后台任务会中断，面板照常可用。要重新连上，在右上角账号菜单里点重启。
- **手动连接 QQ**：只在启动时第一次连接失败后出现。修好 OneBot 再点它；运行中断线会自动重连，用不到这个按钮，见[断线以后](./onebot#断线以后)。

## 保存与重启

插件参数和插件的选群保存后只重载这个插件，聊天不中断。其他需要重启的设置，保存后顶栏会提示有待应用的修改。

点重启会先列出受影响的设置和正在进行的工作。确认后：

- 不再接新消息和新工作，正在回复的这一轮说完再停；
- 后台任务中断，会话和文件保留，之后可以续接；
- 账号浏览会话关闭，试聊停止；
- 新进程起来后要重新登录面板。

LenBot 异常退出后不会自己拉起，去看终端、服务日志或容器日志找原因。

## 在群里改设置

给角色的工具许可加上 `host_manage` 和 `tool_search` 并重启后，主人和全局管理员可以直接在群里让 Bot 改设置，比如「把本群改成只回应 @ 吧」「改完重启一下」。

能改的：各群的聊天开关、聊天和学习参数、提醒、任务、角色绑定、网页、记忆参数、模型的生成参数、预算、数据保留，以及已安装插件的启停、普通参数和选群。

不能改的：密钥、身份授权、连接方式，以及需要停机转换的设置。

Bot 默认只保存修改，你明确说要重启它才会重启。

## 用量与上限

LenBot 只统计模型服务报告的 token，不折算金额，实际费用以服务商账单为准。每天的 token 上限在**模型**页设置，首页显示同一个数。

有的服务不报告 token，这类调用单独计数。设了上限之后，一旦出现这种调用，当天的模型调用就会暂停，因为没法确认有没有超限。
