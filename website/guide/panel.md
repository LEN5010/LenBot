# 面板一览

面板左侧的导航按用途分成四组。各页面的用途如下。

| 页面 | 用途 |
|---|---|
| 首页 | 连接状态、各群今天的情况、最近的错误 |
| 对话测试 | 用某个群的角色和模型试聊，回复只显示在页面上 |
| 日志 | 每轮回复的经过、模型调用记录和运行日志 |
| 群聊 | 每个群的消息记录、回复设置、权限、会话和学习 |
| 角色 | 设定、说话方式、样例、资料、表情和头像。修改后可以先试聊 |
| 记忆 | 浏览、修改、删除和遗忘长期记忆 |
| 任务、资源 | 后台任务、提醒和主动话题，以及任务文件和共享资料 |
| 插件 | 安装和配置插件，选择在哪些群启用 |
| 能力 | 工具和技能、MCP 服务、网页服务、后台任务环境 |
| 模型 | 服务商、各用途和向量模型、token 上限 |
| 设置 | 连接、群聊发言上限、面板账号、数据保留、版本与更新 |

![群聊页：左侧选择群，右侧是消息、设置、权限、会话和学习](/screenshots/scenes.png)

## 账号和群的写法

在面板中填写账号时（例如主人和白名单），账号写成 `平台:账号`，群写成 `平台:group:群号`，私聊写成 `平台:private:账号`。目前只有 OneBot 一个平台。

```text
onebot:90001          Bot 自己
onebot:70001          主人
onebot:group:80001    群
onebot:private:70001  和主人的私聊
```

## 权限

**群聊 → 权限**分为两部分。

- 上半部分是管理员、白名单和黑名单，对所有群生效。
- 下半部分可以为本群另外添加名单，并按群设定谁可以委托任务和设置提醒，谁可以让 Bot 暂时安静。

主人在**设置 → 连接**中修改。

## 首页的快捷操作

### 群聊开关

群卡片右侧的开关。关闭后，这个群的消息照常记录，但 Bot 不回复也不主动发言，被 @ 时同样不回复，插件也不在这个群响应。重新打开后，Bot 从新消息开始处理，不会补回关闭期间的消息。

### 断开 QQ

立即关闭 OneBot 连接。正在进行的回复和后台任务会中断，面板仍然可以使用。需要重新连接时，在右上角的账号菜单中点击重启。

### 手动连接 QQ

只在启动时第一次连接失败后出现。修复 OneBot 的问题后点击这个按钮。运行期间断线时 LenBot 会自动重连，不需要这个按钮，见[断线以后](./onebot#断线以后)。

## 保存与重启

插件参数和插件启用的群保存后，只重新加载这个插件，聊天不会中断。其他需要重启才能生效的设置，保存后顶栏会提示有待应用的修改。

聊天模型、协议和服务商名称可以直接修改并保存。更换向量地址、模型或维数时，已有索引需要[重建索引](./memory#重建索引)。

点击重启时，面板会先列出受影响的设置和正在进行的工作。确认重启后会发生以下变化。

- LenBot 不再接收新消息和新工作。正在进行的这一轮回复完成后才停止。
- 后台任务中断，但会话和文件保留，之后可以继续。
- 账号浏览会话关闭，试聊停止。
- 新进程启动后，需要重新登录面板。

LenBot 异常退出后不会自动重新启动，请查看日志找出原因。在终端运行时查看终端输出，作为服务运行时查看服务日志，使用 Docker 时查看容器日志。

## 框架提示词

**设置 → 高级 → 框架提示词**可以修改 LenBot 自带的提示词，例如怎样判断要不要回复、怎样用工具。改动对所有群生效，重启后应用。改错可能让 Bot 不再回复或用错工具，不确定时点**恢复默认**。

带 `$` 的占位符（如 `$name`）由 LenBot 在运行时填入，修改后必须保留与默认内容相同的一组占位符，否则无法保存。正文里要写字面的 `$` 时写成 `$$`。

修改保存在实例目录的 `state/prompts/` 中。升级到新版本时，默认把这些修改移到 `state/prompts/.replaced/`，改用新版本自带的提示词；勾选**更新 LenBot 后保留这些修改**后，升级会继续使用这些修改，面板会提示它们基于哪个旧版本。

## 在群里修改设置

给角色的工具许可加上 `host_manage` 和 `tool_search` 并重启后，主人和全局管理员可以在群里直接让 Bot 修改设置，例如「把本群改成只回应 @ 吧」或「改完重启一下」。

可以修改的设置包括：

- 各群的聊天开关，以及聊天和学习参数
- 提醒和任务，以及角色绑定
- 网页和记忆参数
- 模型的生成参数和预算
- 数据保留
- 已安装插件的启用和停用，以及插件的普通参数和启用的群

不能修改密钥和身份授权，也不能修改连接方式和需要停机转换的设置。

默认情况下 Bot 只保存修改。只有明确要求重启时，Bot 才会重启。

## 用量与上限

**模型 → 用量与上限**中显示今天和本月使用的 token 数量，也可以设置每天的 token 上限。首页显示的是同一个数字。数字来自模型服务的报告，LenBot 不换算成金额。

同一页的**叫醒与发言**按群、日期和唤醒方式列出叫醒次数、发言次数、发言率、主脑输入 token 和缓存命中 token，可以筛选群聊。一次轮次只算一次叫醒，一轮成功说话、发独立表情或给消息贴表情都算一次发言。输入 token 包含缓存命中；缓存命中列是其中的一部分。日期按实例时区划分，轮次中的所有主脑请求计入开轮那一天，其他模型用途仍在上方用量表查看。旧轮次没有保留唤醒标记时显示为历史未记录。

有些服务不报告 token 用量，这类调用单独计数。设置上限以后，只要当天出现这类调用，LenBot 就无法确认是否超出上限，因此会暂停当天的模型调用。

## 每小时发言上限

为了避免 Bot 在一个群里说个不停，LenBot 会统计每个群最近 60 分钟内的发言次数。全局默认值在**设置 → 群聊**中修改，默认每个群每小时 60 条。单个群在**群聊 → 设置 → 什么时候说话**里选择跟随全局、自定义条数或不限。私聊不受这个上限限制。

计数规则如下。

- 一次发言算一条。一句话被拆成几条消息发出，或者文字带着表情，都只算一条。单独发一个表情也算一条，给消息贴表情不算。
- 插件发送的内容（例如日报卡片）不计数，也不会被这个上限拦下。
- 安静时段的固定回复和下面说的固定回复也不计数。

到达上限后，Bot 不再主动插话或开话题，被 @、被回复和到点的提醒仍然可以再说几条，默认 5 条，在**设置 → 群聊**中修改。余量也用完后，这个群暂停发言，等最早的一次发言超过 60 分钟后自动恢复。未读消息会保留，恢复后一起处理。快到上限时，Bot 在回复前会看到本群还剩几条。

到上限后默认不在群里说明。需要的话，打开**全部用完后被 @，回一句固定的话**并填写内容，Bot 会原样发送，每次暂停最多发一次。

**群聊 → 设置**会显示本群最近一小时说了几条。到上限时，首页的待处理事项会列出这个群，点**本小时临时放开**可以清零本群的计数。发言上限的修改保存后立即生效，不需要重启。
