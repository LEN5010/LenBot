# 面板一览

| 页面 | 做什么 |
|---|---|
| 首页 | 连接状态、各群今天的情况、最近的错误 |
| 对话测试 | 用当前角色和模型试聊，不发到 QQ |
| 日志 | 每轮回复的经过、模型调用和宿主日志 |
| 群聊 | 消息记录、参与节奏、学习、关系说明、本群权限 |
| 角色 | 设定、说话方式、样例、知识、表情、头像，草稿试聊 |
| 记忆 | 浏览、修改、删除和遗忘长期记忆 |
| 任务、资源 | 后台任务、提醒、主动话题，任务文件和共享资料 |
| 插件、能力 | 插件安装和配置；工具、技能、MCP、网页和任务环境 |
| 模型、设置 | 服务商和用途、token 与发言上限；连接、权限、面板、版本与更新 |

## 账号和群的写法

账号写成 `平台:账号`，群写成 `平台:group:群号`，私聊写成 `平台:private:账号`。目前只有 OneBot，例如 Bot 是 `onebot:90001`，主人是 `onebot:70001`，群是 `onebot:group:80001`。面板里填主人、管理员、白名单和关系说明时都用这种写法。

## 首页快捷操作

- **群聊开关**：群卡片右侧的开关。关掉后这个群的消息照常记录，但 Bot 不回复、不主动发言，被 @ 也不回，插件也不在这个群响应；重新打开后从新消息开始，不补回关闭期间的话。
- **断开 QQ**：立刻关闭 OneBot 连接，正在进行的回复和后台任务会中断，面板继续可用。要重新连上，点顶栏的重启。

## 保存与重启

插件参数和插件的选群保存后只重载这个插件，聊天不中断。其他需要重启的设置，保存后顶栏会提示有待应用的修改。

点重启会先列出受影响的设置和正在进行的工作。确认后：

- 不再接新消息和新工作，正在回复的这一轮说完再停；
- 后台任务中断，保留会话和文件，之后可以续接；
- 账号浏览会话关闭，试聊停止；
- 新进程启动后需要重新登录面板。

异常退出不会自动重启，去看终端、服务日志或容器日志找原因。

## 在群里改设置

在角色的工具许可里打开 `host_manage` 和 `tool_search` 并重启后，主人和全局管理员可以在群里直接让 Bot 改设置，比如「把本群改成只回应 @ 吧」「改完重启一下」。

能改的有：各群的聊天开关、聊天和学习参数、提醒、任务、角色绑定、网页、记忆参数、模型的生成参数、预算、数据保留，以及已安装插件的启停、普通参数和选群。密钥、身份授权、连接方式和需要停机转换的设置不能在群里改。默认只保存，明确要求才重启。

## 用量与上限

LenBot 只统计模型服务报告的 token，不算金额。每天的 token 上限在模型页设置，首页和用量页显示同一个口径。服务没报告 token 的调用单独计数；设了上限时，出现这种调用会暂停当天的模型调用，因为没法确认有没有超限。
