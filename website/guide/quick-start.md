# 快速开始

跟着这一页，你会装好 LenBot，填完首次配置，先在面板里和它聊几句，再让它进群说话。

::: tip 0.2.0 还没有发布
部署包和 Docker 镜像要等 0.2.0 发布后才能下载，在那之前请[从源码运行](./install-source)。除了安装命令，下面的步骤都一样。
:::

## 准备

开始之前，先把这三样准备好：

1. **一台一直开着的机器**。Linux、macOS、Windows 都行，也可以是装了 Docker 的服务器或 NAS。
2. **一个已经登录 QQ 的 OneBot 实现**，比如 [NapCat](https://github.com/NapNeko/NapCatQQ)。LenBot 自己不登录 QQ，靠它收发消息。首次配置时要连上它读出 Bot 的 QQ 号，所以先把它跑起来，打开 WebSocket。怎么连见[接入 QQ](./onebot)。
3. **一个模型服务**：接口地址、API Key 和模型名。OpenAI 兼容接口、OpenAI Responses、Anthropic 和 Gemini 都能用。

## 1. 安装

三种安装方式跑的是同一个程序：

| 方式 | 适合 |
|---|---|
| [部署包](./install-package) | 在自己的电脑或 Linux 服务器上长期运行，只需要 uv |
| [Docker](./install-docker) | 服务器、NAS；在 Windows 上想用后台任务也选它 |
| [源码](./install-source) | 想改代码，或者想跟着开发版走，需要 uv 和 Node.js 22 |

拿不准就选部署包，它能在面板里升级，升级失败还能恢复。源码运行要自己 `git pull` 更新。

从源码运行是这样：

```sh
git clone https://github.com/lendevs/LenBot.git
cd LenBot
./scripts/install.sh
uv run --no-sync len-bot
```

## 2. 打开首次配置

第一次启动时还没有配置，终端会打印一个链接：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
保存后直接启动，按新配置连接 OneBot 并打开面板。
```

在同一台机器的浏览器里打开它。端口每次随机，Docker 固定用 11307。链接里的 `token` 只在这次启动有效，重启后会换一个新的。

LenBot 装在远程服务器上的话，先在自己电脑上开一个 SSH 端口转发，再在本机浏览器打开同一个链接：

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 3. 填向导

向导一共六步，左边能看到进度。每一项的意思见[首次配置](./first-setup)，第一次可以这样填：

1. **管理员账号**：之后登录面板用的用户名和密码。
2. **连接 QQ**：填 OneBot 的地址，点「测试连接并读取 Bot 账号」，看到「连上了，Bot 的 QQ 号是 …」就对了。「回复怎么发」选**模拟发送**，Bot 照常收消息、想回复，回复只出现在面板里。
3. **主人**：填你自己的 QQ 号。
4. **选择模型**：填接口地址和 API Key，点「读取模型列表」选一个模型，再点「测试模型」，看到「通过」就行。
5. **角色和第一个群**：角色用默认的小然，再填一个群号。
6. **官方插件**：先跳过，以后在面板里装。

点「保存并进入面板」后，LenBot 按新配置启动，页面会自动跳到面板的登录页。

## 4. 聊第一句

登录面板，打开**对话测试**，选刚才的群，点「开始聊」，像群友一样跟小然说句话。这里的回复只在页面上显示。

聊得满意了：

1. 到**设置 → 连接**，把发送方式改成「真实发送到 QQ」，保存后按提示重启。
2. 在群里 @ 它一下，它应该会回你。
3. 新加的群默认只回应 @ 它或回复它的消息。想让它更活跃，到**群聊 → 设置**里关掉「只在被 @、被回复或私聊时说话」，再调一调活跃度。
