# 快速开始

这一页带你把 LenBot 装好、填完首次配置，先在面板里试聊，再让它进群说话。

::: warning 0.2.0 还没有发布
部署包和 Docker 镜像要等 0.2.0 发布后才能下载。在那之前请[从源码运行](./install-source)，下面的步骤除了安装命令都一样。
:::

## 准备

- **一台常开的机器**：Linux、macOS 或 Windows x64，或者装了 Docker 的服务器、NAS。
- **一个已登录 QQ 的 OneBot v11 实现**，比如 NapCat。LenBot 自己不登录 QQ，靠它收发消息；首次配置时要从它读出 Bot 的 QQ 号，所以先把它跑起来。见[接入 QQ](./onebot)。
- **一个模型服务**：接口地址、API Key 和模型名。支持 OpenAI 兼容的 Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 四种协议。模型按调用计费。

## 1. 安装

| 方式 | 适合 | 需要 |
|---|---|---|
| [部署包](./install-package) | 自己的电脑或 Linux 服务器，日常使用 | [uv](https://docs.astral.sh/uv/) |
| [Docker](./install-docker) | 服务器、NAS；Windows 上要用后台任务时 | Docker 和 Compose |
| [源码](./install-source) | 开发，或想跟着主线走 | uv 和 Node.js 22 |

三种方式运行的是同一个程序。部署包和 Docker 自带更新器，可以在面板里升级，失败了能恢复；源码运行要自己 `git pull`。拿不准就选部署包。

以源码为例：

```sh
git clone https://github.com/lendevs/LenBot.git
cd LenBot
./scripts/install.sh
uv run --no-sync len-bot
```

## 2. 打开首次配置

第一次启动时还没有配置，终端会打印一个本机链接：

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
保存后直接启动，按新配置连接 OneBot 并打开面板。
```

端口每次随机（Docker 用面板端口，默认 11307），链接里的 `token` 是这次启动的一次性令牌。在同一台机器的浏览器里打开它。装在远程服务器上的话，先用 SSH 把端口转发到本机：

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 3. 填向导

向导一共六步：面板账号、连接 QQ、主人、模型、角色和第一个群、官方插件。每一项的含义见[首次配置](./first-setup)，第一次可以这样填：

- **连接 QQ** 填好 OneBot 地址后点「测试连接并读取 Bot 账号」。**回复怎么发**选**模拟发送**：Bot 照常收群消息、想好回复，但不会真的发到 QQ。
- **模型**点一次「测试模型连接」，确认地址和密钥没填错。
- **角色**用默认的小然。
- **官方插件**先跳过。

保存后程序按新配置继续启动，点页面上的「打开面板登录」进入面板。

## 4. 聊第一句

登录面板，打开**对话测试**，用小然和你填的模型聊几句。这里的消息不会发到 QQ。

觉得可以了：

1. 在**设置 → 连接**里把发送方式改成「真实发送到 QQ」，保存后按提示重启。
2. 在群里 @ 它一下。新加的群默认只回应 @ 它或回复它的消息，想让它多说话，到**群聊 → 设置**里关掉「只在被 @、被回复或私聊时说话」并调活跃度。
3. 在**群聊**里加更多群，在**角色**里慢慢调设定和说话方式。
