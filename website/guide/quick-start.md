# 快速开始

LenBot 长期运行在一台电脑或服务器上，通过 OneBot 收发 QQ 消息，用你填的模型服务说话。

::: warning 还没有发布
首个公开版本 0.2.0 还在准备。下文的部署包和 Docker 镜像要等发布后才能下载，现在请[从源码运行](./install-source)。
:::

## 需要准备

- **一台常开的机器**：Linux、macOS 或 Windows x64，也可以是装了 Docker 的服务器或 NAS。
- **一个已登录 QQ 的 OneBot v11 实现**：LenBot 自己不登录 QQ，只通过 OneBot 的 WebSocket 收发消息，见[接入 QQ](./onebot)。
- **一个兼容 OpenAI 聊天接口的模型服务**：接口地址、API Key 和模型名。模型按调用计费。

只想先看看效果的话，OneBot 可以晚点再接：首次配置时选**模拟发送**，Bot 照常处理消息但不发到 QQ，可以在面板里试聊。

## 选安装方式

三种方式跑的是同一个程序，读的也是同一种实例目录。

| 方式 | 适合 | 需要 |
|---|---|---|
| [部署包](./install-package) | 自己的电脑、Linux 服务器日常使用 | [uv](https://docs.astral.sh/uv/) |
| [Docker](./install-docker) | 服务器、NAS | Docker 和 Compose |
| [源码](./install-source) | 开发、跟着主线走 | uv 和 Node.js 22 |

部署包和 Docker 都能在面板里检查新版本、一键升级，升级前自动备份，出问题可以恢复。

## 第一次启动

第一次启动没有配置，会打印一个本机网页链接，打开后按[首次配置](./first-setup)填五部分：连接 QQ、主人、模型、角色和第一个群、面板登录。保存后自动进入面板。

接下来：

1. 在面板的**对话测试**里聊几句，看角色说话对不对味。
2. 接好 OneBot，在设置里把发送方式改成真的发到 QQ。
3. 在**群聊**里加更多群，在**角色**里慢慢调设定和样例。
