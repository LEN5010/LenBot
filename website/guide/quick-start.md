# 快速开始

这一页从安装讲到首次配置。配置完成后，先在面板里和 Bot 试聊，确认效果后再让它在群里发言。

::: tip 0.2.0 尚未发布
部署包和 Docker 镜像要等 0.2.0 发布后才能下载，在此之前请[从源码运行](./install-source)。除了安装命令不同，后面的步骤都一样。
:::

## 准备

开始之前需要准备三样东西。

1. **一台长期开机的机器**。Linux、macOS 和 Windows 都可以，也可以是装了 Docker 的服务器或 NAS。
2. **一个已经登录 QQ 的 OneBot 实现**，例如 [NapCat](https://github.com/NapNeko/NapCatQQ)。LenBot 本身不登录 QQ，消息都经由它收发。首次配置时要连上它读取 Bot 的 QQ 号，所以请先启动它，并打开 WebSocket。连接方法见[接入 QQ](./onebot)。
3. **一个模型服务**，包括接口地址、API Key 和模型名。支持 OpenAI 兼容接口、OpenAI Responses、Anthropic 和 Gemini。

## 1. 安装

三种安装方式运行的是同一个程序。

| 方式 | 适用情况 |
|---|---|
| [部署包](./install-package) | 在自己的电脑或 Linux 服务器上长期运行，只依赖 uv |
| [Docker](./install-docker) | 服务器和 NAS。在 Windows 上需要后台任务时也用这种方式 |
| [源码](./install-source) | 需要修改代码，或者想使用开发版。依赖 uv 和 Node.js 22 |

不确定选哪种时，推荐部署包。部署包可以在面板中升级，升级失败时可以恢复。从源码运行则需要自己用 `git pull` 更新。

从源码运行的命令如下。

```sh
git clone https://github.com/lendevs/LenBot.git
cd LenBot
./scripts/install.sh
uv run --no-sync len-bot
```

## 2. 打开首次配置

第一次启动时还没有配置文件，终端会输出一个链接。

```text
尚无根配置。请打开 http://127.0.0.1:52811/#token=...
保存后直接启动，按新配置连接 OneBot 并打开面板。
```

请在同一台机器的浏览器中打开这个链接。端口每次启动随机分配，Docker 固定使用 11307。链接里的 `token` 只在本次启动有效，重启后会换成新的。

如果 LenBot 安装在远程服务器上，先在自己的电脑上建立 SSH 端口转发，再在本机浏览器中打开同一个链接。

```sh
ssh -L 52811:127.0.0.1:52811 你的服务器
```

## 3. 填写向导

向导共七步，左侧显示进度。各项的含义见[首次配置](./first-setup)。第一次可以按下面的方式填写。

1. **管理员账号**。以后登录面板时使用的用户名和密码。
2. **连接 QQ**。填写 OneBot 的地址，点击「测试连接并读取 Bot 账号」。页面显示「连上了，Bot 的 QQ 号是 …」即表示连接成功。「回复怎么发」请选择**模拟发送**。这时 Bot 照常接收消息并生成回复，但回复只显示在面板里。
3. **主人**。填写自己的 QQ 号。
4. **选择模型**。填写接口地址和 API Key，点击「读取模型列表」并选择一个模型，再点击「测试模型」。显示「通过」即可。
5. **向量模型**。可以选择向量服务和模型，也可以点击「跳过向量模型」使用全文检索。
6. **角色和第一个群**。角色使用默认的小然，再填写一个群号。
7. **官方插件**。可以先跳过，以后在面板中安装。

点击「保存并进入面板」后，LenBot 会按新配置启动，页面自动跳转到面板的登录页。

## 4. 试聊

登录面板后打开**对话测试**页，选择刚才填写的群，点击「开始聊」，以群友的身份和小然说几句话。这里的回复只显示在页面上。

试聊效果满意后，按下面的步骤让 Bot 在群里发言。

1. 到**设置 → 连接**，把发送方式改为「真实发送到 QQ」。保存后按提示重启。
2. 在群里 @ Bot，它应该会回复。
3. 新加入的群默认只回应 @ Bot 或回复 Bot 的消息。如果希望它更主动，到**群聊 → 设置**关闭「只在被 @、被回复或私聊时说话」，再调整活跃度。
