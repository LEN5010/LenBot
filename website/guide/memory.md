# 记忆

记忆以 Markdown 文件的形式保存在本地，按群分开存放在实例目录中。人物画像存放在 `people/<完整账号>/`。

Bot 在聊天时按需检索记忆。后台会定期从聊天记录中整理出值得记住的内容，写入记忆。

- 默认使用全文检索，不需要额外的服务。如果需要按语义检索，可以接入向量服务，见[可选服务](./optional-services#向量检索)。
- 向量配置与旧索引不匹配，或查询向量接口失败时，召回改用全文检索，保留人物画像和记忆正文。错误记录在运行日志中。
- 停用向量后，记忆继续使用全文检索并允许编辑；首次修改正文时清除已停用的向量索引。
- 在记忆页可以浏览和修改记忆，也可以删除。普通删除会保留修改历史。
- 插件发出的推送和卡片不会被整理进记忆，插件生成的总结也不会。
- **遗忘**会清除这个文件的正文和索引，以及旧版本和摘要。遗忘时还可以选择部分原话，不再从中重新学习。原始聊天记录和模型请求记录不受影响，自行制作的外部备份也不受影响。

## 重建索引

手动修改了记忆文件，或者更换了向量服务地址、模型或维数后，需要重建索引。普通重启不会重建索引。仅修改服务商名称无需重建。停止 LenBot 后，在实例目录中执行下面的命令。

记忆页会显示索引不匹配的状态，点击「重建索引」可查看已有索引、当前配置和重建命令。复制的命令使用当前安装的 Python 和实例目录。重建前可以继续全文检索；向量模式下写入记忆仍需要索引与当前模型一致。

```sh
python -m len_bot.next.maintenance.memory_reindex
```

正文和修改历史会保留，目录摘要会被清除，之后整理记忆时按新的正文重新生成。

使用部署包时，用 `releases/<版本>/.venv` 中的 python 执行。从源码运行时，写成 `uv run --no-sync python -m ...`。

更换群内说法学习的向量配置后，旧索引暂停检索，聊天和面板继续运行。学习页提供重建命令，停机执行后重算已采纳说法的向量。Docker 在挂载同一实例目录和 Python 环境的维护容器内执行命令。
