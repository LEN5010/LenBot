# 记忆

记忆是本地的 Markdown 文件，按群分开存在实例目录里，人物画像在 `people/<完整账号>/`。Bot 在聊天中按需检索；后台会定期从聊天记录里整理出值得记住的事，写进记忆。

- 默认用全文检索，不需要额外服务。想要按意思检索，可以接一个向量服务，见[可选服务](./optional-services#向量检索)。
- 记忆页可以浏览、修改和删除。普通删除会保留修改历史。
- 插件发出的推送、卡片和总结不会被整理进记忆。
- **遗忘**会清掉这个文件的正文、索引、旧版本和摘要，还可以选择不再从某些原话里重新学习。原始聊天记录、模型请求记录和你自己做的外部备份不受影响。

## 重建索引

手工改了记忆文件，或者换了向量模型，停机后在实例目录执行：

```sh
python -m len_bot.next.maintenance.memory_reindex
```

正文和修改历史保留，目录摘要会清掉，之后整理时按新正文重新生成。部署包用 `releases/<版本>/.venv` 里的 python；源码运行写成 `uv run --no-sync python -m ...`。
