# 群聊表达材料

普通聊天由同一个 `mind` 模型根据完整有效上下文判断回应对象、态度、工具和实际台词。`say.content` 就是最终正文，`react` 可以独立完成回应，宿主负责引用、提及、素材匹配和实际发送回执。`voice.md` 是人工角色口吻文件，已退役的表达模型用途与它无关。

现行人物和表达原则以 2026-10-04 实群反馈及七个脱敏坏例为修订依据。原 research 的人格与局面判断、非敌意独立判断和长度随语境变化保留直接引用；其余结合实群坏例整理成群聊材料，减少叙事设定与重复说明；完整预设不随程序分发。`next_response_choice.md` 管判断，`next_expression_principles.md` 管表达，`next_react.md` 与 `next_chat_examples.md` 明确标注工具和反馈情境的设计示范，`next_direct.md` 只说明实际正文参数。共用示范不写具体角色的台词或梗，情境也避开回放用例的原句，角色专属说法放在角色包样例里。

角色身份、关系、边界和原人工样例仍来自角色包。原话、人工样例、学习参考与实际已发送记录分别标明来源。表达参考不表示本次真人请求，也不表示模型实际采用了它。当前本机只修订原角色的固定字数、默认文字和默认嫌弃倾向，保留身份、核心行为与四个人工样例。

学习开启时，一轮开始根据近期真实对话选择最多五条已采用材料，和风格一起放入宿主参考；不再按最近三次“提供过”轮换排除，也不把提供等同使用。明确配置的其他 Bot 来源不参与选材，原库保留，采用管理仍可人工处理旧噪声。`learning: null` 时不检索、不提取，原人工样例和角色表情仍独立可用。

已有失败原文及本次回放位置见本机 `docs/iteration.md`，未完成工作只在 `docs/next.md` 维护。

react 常驻说明提供 query 素材检索，准确 emotion 标签仍可使用；完整的情绪词目录不再常驻主脑请求，也不作为文字态度菜单。实际素材与匹配规则保留。

本次修订后七个坏例和四个正例各一次隔离回放，反馈回应缓和、未知课表保持未知、正常斗嘴与独立表情保留；追加两个不同措辞反馈及两个正例也完成。但部分回应接近设计示范，不能把同题命中写成普遍自然表达。原四条人工样例仍偏吐槽，口吻文件仍有较长禁令清单；后续材料应补足亲近、倾听、认真回答和温和不同意的语境，先保留评测材料再决定采用，不继续叠固定台词或配额。

2026-10-05 按实群深夜记录补充活人感原则：被 @ 不必逐条回，几个人起哄可以一句接；关心落在具体事情上，不管作息，被说管太多后放下；对方真恼时先站对方那边；被认真问是不是 AI 时照实说是 Bot；标点平实，结尾不布置下一步；文字说事、表情带情绪，配图后不在字里重复情绪。say 的引用和 @ 默认不填，只在会认错对象时使用。记忆抽取把群友对相处方式的明确要求记为本人偏好，不把 Bot 一次的口吻整理成性格。七例隔离回放的标点、引用、身份与反馈承接改善，凌晨起哄仍常提夜深，结论见本机 `docs/iteration.md`。
