# 插件开发

当前公开接口：**interface = 1**，导入入口 `len_bot.next.plugin`。接口版本不匹配直接报错，不加载兼容运行层。

从 [计数插件](examples/counter/) 复制一个目录即可开始；完整约定见 [接口 v1 指南](plugins-v1.md)。插件是同进程可信 Python，安装者应能信任其源码；插件数据与源码分开保存。

这套接口适合精确命令、规则接管、后台监测和专用工具。需要容器完成的长工作属于工作任务，`start_task` 只是插件自己的 asyncio 后台资源。

开发文档随代码版本一起发布。这里不需要读取维护者的本机 `docs/`、个人角色或真实配置。
