# 计数插件

无需第三方依赖或模型。将整个 `counter` 目录复制到一个插件父目录，例如 `plugins/counter`。在面板「能力 → 插件 → 插件目录」登记父目录 `plugins`，加载 `counter`、保存参数，再为目标群启用；当前保存后需重启，单插件重载交付后将直接应用。

- `/计数`：查看本群计数。
- `计数加一`：增加配置的 `step`，直接回复。
- `/计数清零`：删除本群计数。本示例允许群内使用，不额外要求主人权限。
- `counter_read`：大脑可通过工具发现找到的只读工具，使用它的聊天轮本身会调用模型；工具函数不调用模型。

KV 文件位于配置数据根下的 `counter/kv.sqlite3`，源码更新不应删除它。计数以 `ctx.scene` 为 key，群之间不共用计数。返回字符串只是工具／处理器结果，真正发消息使用 `ctx.reply`。

复制后若改插件名，同时改目录名、清单 name、命令和工具名，避免与其他插件冲突。发布自己的版本时填写自己的 authors、license、repository 和 homepage。
