# 计数插件模板

[English](README.en.md)

这份目录是独立 GitHub 模板仓库的发布准备件，尚未创建公开模板仓库。复制本目录的内容作为仓库根，填写自己的清单 name、authors、license 和版本；改名时也改命令、工具名，避免冲突。示例当前采用 AGPL-3.0-only，使用前核对你的发行许可。

无需模型或第三方服务：`/计数` 读当前场景计数，`计数加一` 按 step 增加，`/计数清零` 清零。只读工具 counter_read 返回当前场景计数。KV 按场景分开，源码更新保留它。

安装宿主和测试依赖后，在插件仓库根运行：

```sh
uv run --no-sync pytest -q tests
```

CI 从宿主仓库指定修订安装 len-bot，再运行实际 PluginTest。示例测试只捕获 simulated 发送，未接 QQ、未调用模型。依赖服务的插件须自行增加实际服务测试。宿主的插件指南解释公开接口、配置和生命周期，地址从你安装的宿主仓库 developer/plugins-v1.md 查阅。

宿主面板可以直接安装这个独立仓库的 Git URL，先准备候选、填写参数并应用，再启用和选群。标签 v* 的发布工作流生成根含清单及入口的 ZIP 并挂到 Release，面板支持直接导入；目录不包含聊天、角色或实例数据。

发布前将 CI 中的宿主修订更新到你实际验证的固定版本，提交清单版本后再打对应标签。配置或数据格式变化在 README 写明；回退源码不自动回退业务数据。

当前 CI 固定到本轮已测试宿主提交；公开模板前须先把该宿主提交推送到 CI 使用的仓库，远端工作流尚未执行。
