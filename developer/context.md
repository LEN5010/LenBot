# 上下文、压缩与模型输入

主脑继续使用原 `mind_entries`、`mind_sessions` 和 `model_calls`，不另建会话、缓存或工具注册框架。

## 主脑请求

请求顺序是稳定角色／能力 system、已保存回想与原生历史、当次参考。群概览在每次请求边界读取并放入参考，不修改 system；本轮开始时间固定，后到批次和 wait 结果提供新的真实时间依据。任务快照只列活动身份、状态与待答问题，长结果由实际结束事件或 task 工具读取。

临时召回不写入原生历史，也不作为旧段摘要源。执行记忆工具前撤下旧召回；群概览下一请求重新读取，包括工具部分完成后报错的情况。配置和能力确实改变时允许前缀变化，不为缓存保留已停用权限。

## 群聊与工具

- 新到消息按批次共享场景、日期和时区头，保留原 QQ、平台 ID、秒级时间、正文、回复、提及、媒体序号及撤回／发送状态。同日 UTC 偏移改变时另起头。
- 长批次只在完整消息之间分组；单条过大不截断，交给明确预算错误处理。同批引用不重复摘录，批次外摘录标为节选。原始平台记录和已保存历史呈现不重写。
- 自有参数 schema 仅移除 schema 节点的自动 title；业务属性、默认值、约束及引用保留。插件／MCP 定义原样使用，装配顺序按名称稳定。
- tool_search 返回名称、简短用途和下一请求生效说明；完整 schema 只在请求 tools 中出现。已发现集合持续到正常压缩重置，停用立即撤下。
- task 模型视图不再复用完整面板 DTO；保留任务目标、实际状态、待答问题、结果与错误，文件保留原 ID、存在性、登记和上传回执状态。send_file 返回可操作的回执及原事件 ID，完整平台原帧留在既有事件中。没有“已上传即客户端已收到”的转换。
- 原生工具调用 ID、参数、完整结果组和不透明续接字段保持。只精简首次入史的宿主呈现，外部工具文本不猜字段或裁剪。

## 预算与压缩

触发口径仍是输入估算＋输出额度超过 `floor(context_window_tokens * trigger_ratio)`。缓存输入仍占窗口，不扣减 cached_tokens。最新成功主脑请求有实际 prompt_tokens，且绑定、tools 和持久前缀一致时，以该值加减变动材料估算；否则使用 UTF-8 字节估算。调用记录明确区分 `usage_assisted`、`utf8_bytes_estimate` 和图像成本未知，不将估算称为实测。

`keep_recent_tokens` 是近期原文的目标，不是最少必须保留量。切点不拆原生工具组，允许切开长交互的两个完整工具组；摘要在六节回想中交接原请求、更正、已做和未做、原任务／资源 ID。一次摘要只读旧回想和将移出的旧段，不再带整个人格、tools 和保留段。人工压缩也计入当前参考预算。

摘要成功、非空并满足空间后，沿原事务移动起点和重置发现集合。失败保留旧回想与原始记录，不重试。最新不可拆单位或摘要输入过大时，错误给出估算、预留和窗口，不缩参或丢工具结果。end_turn 成功完成的轮次不额外发起摘要。

## 临时请求

voice 不持有第二份长会话。按 `voice_context_tokens` 和实际剩余窗口，先保留最近已消费真人原话、显式提及／引用及其直接引用背景，再按入库顺序补近期完整消息；必要材料放不下直接报错。角色人工样例不删，较早事实由主脑在 say 意图中交接。

vision／ASR 只处理本次媒体；插件 generate 只用插件明确提供的 system 与 prompt；学习和记忆抽取沿各自原游标、真实样本和原记录表，不复制主脑历史。它们使用所属绑定的输出额度，recap 独立使用 `compaction.max_output_tokens`，不增加多余汇总调用。

Pi 代理校验请求的 `max_completion_tokens` 是正整数且不超过宿主上限，合法值原样贯穿预算、转发和记录；缺省才用宿主值。未知字段仍报错，`cacheRetention` 不作为通用协议字段发送。既有 Pi 重试关闭、缓存保温关闭，不按提供方域名猜测控制参数。

配置更新和回退顺序见[运行手册](../deploy/current/operations.md#上下文-token-预算升级)。这次不改数据库格式；先停机人工选定预算，不把旧条数自动换算成 token。
