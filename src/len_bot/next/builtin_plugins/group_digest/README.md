# group_digest

把群里的明确整理请求交给一次模型生成或独立工作。在「能力 → 插件」配置并选择使用场景。

```json
{"message_limit": 50, "model_role": "mind"}
```

- `/群总结 只列已经决定的安排`：读取本群近期消息，使用指定用途绑定生成一次，再直接回复。`message_limit` 默认 50，可填 1–100；`model_role` 可选 `mind` 或 `learner`，使用该场景已有绑定。
- `/群工作 把刚才的活动安排做成 CSV`：以真实发送者的权限委派任务，近期消息作为工作背景。需要 worker、场景任务能力及发送者任务权限；后续在任务页查看进度、文件和登记结果。
- 命令本身不另起主脑聊天轮；单次生成不改角色材料，任务结束事件进入后续群会话。

附带只读 `group-digest` 技能。插件在该场景启用、角色允许此技能后，工作任务可读取它。生成文件、登记交付和平台上传是不同结果，任务页分别展示。
