# rss_broadcast

在指定时刻直接播报 RSS 2.0，不调用模型或工作容器。在「能力 → 插件」填写订阅、保存，并为订阅的目标场景启用插件。

```json
{
  "subscriptions": [{
    "name": "项目更新",
    "url": "https://example.com/feed.xml",
    "scenes": ["group:10001"],
    "cron": "0 8 * * *",
    "timezone": "Asia/Shanghai",
    "limit": 3
  }]
}
```

- `name` 在同一场景内唯一；`scenes` 使用 `group:<群号>` 或 `private:<QQ号>`。
- 五段 `cron` 按所填 IANA 时区执行。默认每日 08:00、Asia/Shanghai、最多 3 条；`limit` 可填 1–10。
- `/订阅播报` 检查本群全部订阅；`/订阅播报 项目更新` 检查指定订阅。
- 首次到点发送当时最新条目，加载时不立即发送。条目使用实际标题与链接；无新条目不发言。
- 已发链接按场景与订阅名保存在插件 KV：保留最近 100 条，以及当前订阅源中仍存在的其余已发链接。长订阅源的未发条目仍按每次上限分批播报，发完后不因历史淘汰反复播报。记录最多为当前源的不同链接数加 100；离开订阅源且不在最近 100 条中的历史会淘汰。重启重新登记日程，不补发离线期间的时刻。卸载源码保留这些数据。

输入是带 `title`／`link` 的 RSS 2.0；HTTP、XML 与发送错误显示在插件页。发送结果按实际回执记录，单次回执未知不会直接重发。
