# 媒体分析

先明确要回答的问题与媒体来源。任务模型实际支持图像时可以查看本地图片；只有链接、文件名、视频简介或字幕时，输出相应来源的分析，不称为看过整个视频或听过录音。

- QQ语音：`recall_chat`定位本场景实际消息，再用已装配的`transcribe(message=<平台消息ID>, audio=1)`。段序号按原消息record段排列，不把搜索record位置当平台ID。识别失败会返回原错；`refresh=true`只明确重识别已经缓存的音频，不改语言或换服务。未装配transcribe时缺少该能力，不能从宿主密钥或数据库绕取。
- 本地视频：用`ffprobe`取实际时长和流信息，围绕问题选择时段；用`ffmpeg`提取代表帧到`/workspace/out`，保留每帧对应时间。需要覆盖整段时先粗采样，再精查相关片段，而不是抽几帧声称覆盖每一秒。图像模型不可用时只提供媒体参数和实际可读字幕，不做像素判断。
- 已取得字幕：保留语言、时间戳与缺失时段。字幕是文字轨，可能与配音、画面或说话者不一致；关键结论区分字幕所说与画面实际可见内容。
- 只有外部媒体URL时，用当前任务可用的公共网络下载能力取得文件；遇到登录要求交回具备账号能力的任务，不从其他任务借登录态。已配置的ASR只识别上述场景语音，当前不提供任意本地音视频上传转写。

将结论、依据时刻、实际覆盖范围和未确认部分写在同一份报告里。需要改格式、裁剪或合成时使用现有FFmpeg方法；最终`deliver_file`登记报告或帧图，只表示文件已复制到宿主，平台交付由大脑另行执行。
