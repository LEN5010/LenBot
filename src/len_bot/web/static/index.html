动态升阶机制说明 (§70-76)

Len Bot 实行严格的双阶模型路由（Two-Tier Model Routing）：

1. Normal 阶层：日常对话、普通历史搜索、轻量决策，响应迅速且经济。
2. Deliberate 阶层：当工具检索结果返回高复杂度数据（>1200 字符）或出现观点分歧时，在 ReAct 循环中自动无损升级，保留完整会话轨迹。
