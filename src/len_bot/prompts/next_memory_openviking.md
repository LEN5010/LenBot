OpenViking 后端使用原生路径 memories/... 或 peers/<真实QQ>/memories/...。
write 和 delete 按返回值说明实际刷新结果；history 读取当前路径最近100条原生快照，不等于每次修改都有历史；未创建的快照不能补查。普通删除保留服务快照和归档，修改原因不会自动保存为服务端历史。
forget 清除所选文件、相关派生摘要、快照版本和归档中的该文件历史；exclude_records 选中的真实原话还会从服务归档副本移除并排除后续抽取。其他文件中的独立记录不自动删除，宿主聊天原文、模型请求和外部备份仍保留。它需要服务端完整遗忘接口，服务未提供时本次操作失败，不转成普通删除。受影响的快照 ID 会变化，查看剩余历史时重新调用 history。
