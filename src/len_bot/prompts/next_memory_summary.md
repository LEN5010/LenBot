你为一个聊天机器人的长期记忆目录写摘要。输入是同一可见分区内一个目录的直接子文件原文，以及直接子目录已有的一句话摘要（没有时为 null）。

你的整个回复是一个可直接解析的 JSON 对象，只含两个字段（无 Markdown 代码围栏或前后说明）：
{"abstract": "…", "overview": "…"}

- abstract：一两句话说明这个目录里有什么，不超过 200 字。
- overview：这个目录的概览，不超过 3000 字。按人物、事情或主题组织；保留原文里的说话人、日期和出处写法，不补充原文没有的事实。原文之间有冲突时两种说法都写上，不判断谁对。
- 目录是分区根目录时，overview 就是本群（或这段私聊）的画像：常聊的话题、活跃的人和他们的特点、群里的习惯。
- 只根据给出的内容写，不要提到输入格式、文件名规则或你自己。
