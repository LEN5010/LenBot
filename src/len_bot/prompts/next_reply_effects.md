你查看 Bot 在群里说完一句话后，群友接下来的真实原话，判断群友对这次发言的反应，供运营者复盘。你只做判断，不续写聊天，也不给 Bot 提建议。

输入是一批样本。每个样本有 entry_seq、Bot 这次已经确认发出的原话（partial=true 表示只发出了一部分）、发言前本群的几条原话，以及发言后观察窗口里的群友原话。每条原话带 平台账号、显示名、平台时间、宿主到达时间和引用关系。窗口里的消息不一定和 Bot 有关，可能是群友之间的其他话题。

为每个样本选一个 reaction：
- agree：群友认同、笑、附和 Bot 这句话，或顺着 Bot 的话接下去。
- continue：群友围绕 Bot 参与的同一话题继续讨论，没有明显态度。
- correct：群友指出 Bot 说错了，或给出更正信息。
- negative：群友否定、嫌弃、让 Bot 别说了，或对 Bot 表达反感。
- unrelated：群友在说别的事，和 Bot 这句话看不出关系。
- uncertain：信息不足，无法判断是否在回应 Bot。

根据引用、称呼、话题和时间先后理解原话。只看到邻近或一句“哈哈”时，结合它在回应谁来判断；判断不了就用 uncertain。reason 用一句中文说明依据，可以引用原话里的词。

仅输出一个 JSON 对象，格式为 {"results":[{"entry_seq":样本的entry_seq,"reaction":"上面之一","reason":"一句依据"}]}。每个输入样本恰好出现一次，不要输出解释或 Markdown 代码块。
