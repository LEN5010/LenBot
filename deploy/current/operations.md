# 使用与离线维护

安装、启动和外部服务见[部署说明](README.md)。运行中通过面板保存配置；手工修改根 `lenbot.config.json` 或执行离线维护前先停机。数据清理遵循当次授权，不能因导入命令结束就认定全部原件已迁移。

## 角色与日常管理

- 首页显示连接与错误；群聊页管理消息和场景；能力页装配工具、插件、MCP与浏览器；模型页分别绑定用途。配置保存不等于运行进程已采用，按面板提示重启。
- 角色 ZIP 的四个设定文件须直接位于根目录，可含知识和表情。导入到新的 `personas/<目录名>`，不覆盖、不自动切换角色；在场景页明确采用。下载只含已保存包，不含编辑草稿。
- 四文件草稿可创建独立试聊；知识／表情取创建时已保存包，场景／模型取运行快照，出口始终模拟。创建本身不调用模型，虚拟发言才调用；离页不自动结束，统一试聊页管理活动实例。
- `knowledge/` 管理单个 Markdown（含 YAML 标签头）：新建不覆盖，编辑不隐式创建，保存核对共用场景依赖，运行内容到重启才更新。知识草稿不随 ZIP 导出或草稿试聊自动保存。
- 表情先保存 `stickers/index.yaml`（首次可为 `[]`），上传原件，再登记索引。上传不覆盖或自动注册；只可删除保存索引未引用的文件。保存索引、运行已加载和 QQ 实际送达分别确认。
- 账号浏览须有真实专用守护进程和扩展；CLI/home/socket 属于同一进程。主人完成扩展配对后读取实际 ID、保存并重启；生成链接、已配对和目标网站已登录是不同状态。

## 任务资料与环境

普通任务最多明确选取本场景 16 份共享资料，空选集不选；宿主按 `worker.max_file_bytes` 复制私有快照，容器以 `/inputs` 只读访问。续接不重新取共享目录；快照缺失、权限或读取失败直接结束。启动探针仅确认字节可读，不证明任务实际采用内容。账号浏览不继承普通资料或旧任务家目录，只接受主人明确选定的输入。

任务页可将已登记交付副本采用为普通共享文件，并列出、下载和选取。文件已生成／登记／挂载不等于平台已收到。目录用量仅为当时元数据，不是原子快照、硬配额或实际可释放空间。

终态任务且容器／账号会话已关闭时，填写实际操作者 QQ，明确“放弃环境”可清理工作区、家目录、原生会话与输入快照。受理后不能续接，即使删除随后失败；交付副本、共享采用原件与执行记录保留。失败核对部分结果，不自动重试、回滚或安全擦除。

停机后可设置 `task_archive: {"destination":".backups/task-originals", "scenes":["group:80001"]}`，执行 `uv run --no-sync python -m len_bot.next.archive_tasks`。归档终态任务原始行与工作区/runtime/交付原件；目标新建，链接不跟随，特殊节点只记元数据，失败保留部分结果，不删源、不恢复环境或续跑。

`task.events/read_event` 读取本任务过程，须带真实操作者 QQ：普通任务限本人或任务管理者，账号浏览限根主人，黑名单／Bot不开放。普通失败公告可附过程预览，账号浏览不自动公开；投影省略已识别音视频与 base64 定位，隐藏当前已知凭据，但不保证未知历史凭据已清除。读取不重发任务。

可选 `worker.mcp` 默认关闭；启用后仅开放启动时实际运行且本场景角色允许的 MCP 工具，密钥不进容器。断线或定义改变结束调用，保存后须重启并使用包含当前扩展的任务镜像。

## 升级与文件锁

先停实例、试聊与相关外部写者，按迁移范围备份业务／记忆处理库及引用目录；SQLite 有内容的 WAL 也属于数据，不能只复制主文件。本地开发清理或免备份按当次明确授权处理。从实例根执行（分离安装时使用安装目录的 Python）：

```sh
uv run --no-sync python -m len_bot.next.migrate
uv run --no-sync python -m len_bot.next.migrate_memory_jobs
```

业务库格式为 35、记忆处理库格式为 5。两者独立迁移，保留原消息与身份；迁移步骤生成原格式副本，不覆盖已有备份，当前格式无需转换。升级代码不会自动迁移活动实例。

运行与离线入口持有非阻塞 `.lenbot-instance.lock`，迁移也取得所涉试聊锁；占用直接报错，不等待或终止其他进程。锁文件没有 PID，存在不代表活跃，禁止删除／替换它解锁。锁不覆盖外部写者；不同实例根仍不得共用业务库或重复运行同一 QQ 场景。

## 历史提醒与媒体

以下均在停机后显式配置并执行，不启动历史运行时，不连接平台或自动启用历史业务：

| 根配置／入口 | 必填范围与行为 |
|---|---|
| `reminder_import`／`len_bot.next.import_reminders` | `source`、`backup`、`scenes`、`timezone`；仅移交未到期、未领取、无条件触发的真人一次性提醒，其余报告原状态 |
| `media_import`／`len_bot.next.import_media` | `source` 库快照、`directory` 原件副本、`original_directory` 原绝对 POSIX 目录、`backup`、`scenes`；将图片挂到已导入原话的真实位置 |
| `media_archive`／`len_bot.next.archive_legacy_media` | `source`、`directory`、`original_directory`、根 `.backups/` 内不存在的 `destination`、`scenes`、`include_public`；保全所选资产行与真实原件，不限图片或精选素材 |

命令形式为 `uv run --no-sync python -m <入口>`。图片导入不联网补图、生成描述或启用停用／公共素材；不支持的资料报告原因，原资产行保留在消息 raw。它不涵盖语音、视频和任务文件的全部迁移。

媒体归档只有 `include_public:true` 才含历史 `global-safe`；manifest 保留原状态／身份，result 分开记录已复制文件与原本无路径的行。缺文件、链接或路径冲突直接失败，保留已写部分；不覆盖、不自动续跑、不登记成当前素材。未登记文件和任务目录仍需单独处理，不能凭归档成功删除全部原库或原件。

## 记忆后端转换与记录

在停机实例中设置目标 `memory` 与 `memory_transfer`：`source` 为原后端完整配置，`archive` 为实例根内新目录，`scenes` 为真实场景，`public_scene` 为其中一个公共目录访问身份。原生源须停止其他写者并处理未完成抽取；目标本地目录全新为空，目标原生用户／公共目录已准备且无正文。

1. `operation: "export"`，执行 `uv run --no-sync python -m len_bot.next.transfer_memory`。保留业务库、处理库与本地源目录；原生源只导出可浏览的 Markdown 正文，服务历史留在源端。
2. 核对 `manifest.json`、`export-result.json`，不改原话、抽取游标和排除记录。改为 `operation: "import"` 后执行同一命令，保留原文和分区并重建目标索引；配置本地向量时会真实调用 embedding。
3. 核对 `import-result.json` 的实际回执。失败保留源和部分目标，无回执的写入结果未知；重复导入被拒绝，先明确处理目标与失败归档，结束前不启动宿主。

本地人物路径映射到原生 `peers/<QQ>/memories/`，其他场景到 `memories/`，公共分区保持独立。待确认 `legacy-import/` 不升级为正式记忆；源历史、摘要和向量不冒充目标历史或有效画像。正文迁移不等于服务全量备份、完整遗忘或语义等价。[原生分类模板](memory-templates.md)另行装配。

记忆页可只读已保存的向量用量、费用与错误；开发者模式按需显示实际输入／价目。停用记忆后可读取本根现有处理库，不创建、升级或重算；文件操作仍要求后端可用。缺费用保持未知，旧公共标签不证明输入公开；详情不是匿名导出或完整数值向量。用量汇总含本实例公共与已移除场景，不含独立试聊；预算另计试聊，范围不同。

## 无 QQ 的开发输入

在独立实例设置 `onebot:null`、`delivery:"simulated"`、`panel:null`，仍用 `len-bot`，stdin 每行输入原生 OneBot JSON。没有 QQ 连接，但模型、明确启用的普通任务和公共出网仍真实执行；EOF 结束宿主并中断任务。此模式不支持插件／MCP／账号浏览／实时原生记忆或自动 ASR；复制库残留容器／账号会话时拒绝启动，不据其定位清理外部实例。

场景 `replay_web/replay_images` 可指定根内固定资料；缺项报错、不补网，未配置的场景和任务公共出网仍正常访问网络。原生记忆可用根 `replay_memory` 指定服务 HTTP 录制，服务、账号和全部场景身份须匹配且 `memory.ingest` 关闭；按实际请求消费并用 `consumption.json` 续读，不真实写服务或抽取。这些输入模式不代表模型回答、全部网络和端到端行为已受控。
