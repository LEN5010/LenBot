# 使用与离线维护

安装与启动只见[部署说明](README.md)。运行中从面板保存根配置；手工修改或离线维护前先停机。

## 角色与日常管理

- 首页看连接与错误；群聊页管理消息、参与节奏和学习；能力页配置工具、插件与MCP；模型页绑定用途。插件参数与群启用保存即只重载涉及的插件；其余设置按页面提示重启。
- 角色包包含 `persona.yaml`、`voice.md`、`boundaries.md`、`examples.yaml`，可附知识、表情和头像。ZIP导入创建新目录，场景采用是独立操作，不覆盖现有人格。
- 角色页可导入／导出表单 JSON 草稿，载入只替换当前编辑内容，保存才采用；角色 ID、工具／技能及素材保持。草稿可创建独立模拟试聊；创建不调用模型，发消息才调用。活动试聊在对话测试页管理。
- `knowledge/` 保存Markdown资料，`stickers/index.yaml`关联真实图片。上传原件后登记索引，运行包在重启后更新。
- 黑话推断自动使用，可固定人工解释或禁用；群聊表情学习关闭后只用角色素材，历史候选仍保留。

## 保存与重启

面板顶栏「重启」或待应用状态条「重启应用」打开同一确认窗口。设置表单也可「保存并重启」：先保存，再列出本次受影响的配置、场景、角色和在途工作；选择「稍后重启」只关闭窗口，保存内容保持。

确认后停止接收新工作、收尾旧进程，再按根配置启动一次。普通任务保留 ID、会话与文件，中断后可明确续接；账号任务关闭会话，活动试聊停止。新宿主启动后重新登录。改了面板监听地址时页面提供新地址，代理或 SSH 转发同步调整目标。

使用 `len-bot` 启动器时提供此功能；直接执行 `python -m len_bot.next.host` 不管理下一次启动。普通 Ctrl-C、systemd stop 或 Docker stop 会结束整个启动器，异常退出也不自动重启。启动错误查看原终端、`journalctl -u lenbot` 或容器日志；配置已保存，停机处理后再用同一启动命令。

停止和重启会立即唤醒群聊的合并／回应间隔等待，不等普通消息的下一次开口时间，也不再开始新轮次；已接受但未消费的消息留给下次启动。终端 Ctrl-Z 会挂起进程，实例锁仍被持有；已挂起时用 `fg` 恢复后 Ctrl-C，等待进程退出再重新启动。

## 插件安装维护

仓库安装需要宿主可执行 Git 和 uv；普通聊天不依赖 Git。能力页提供静态目录，也接受完整仓库 URL，安装后直接配置并选群；依赖由 uv 按清单安装，与宿主共享环境，冲突会显示原错。未指定 ref 的更新快进当前分支，指定 ref 的更新重新获取所选标签／分支／提交，均不覆盖本地修改，重载会中断该插件自己的在途调用。全局停用保留参数与群选择；卸载移除源码和配置，但保留独立数据，删除数据需另行操作。内置插件随宿主升级，手工目录不由安装器更新或卸载。

重建 Python 环境或采用新的 Docker 发行卷后，从停止的实例根执行 `python -m len_bot.next.maintenance.plugin_dependencies`（使用目标环境解释器）。它合并已配置插件的依赖，一次解析安装；保留已安装的宿主版本、插件源码、所选 Git ref 与 KV。安装失败直接结束，处理后明确再执行。

## 任务资料与环境

在“资源”页上传本场景共享资料，或从任务工作文件、输入快照和登记交付中选择新任务资料；新建时可修改输入文件名，合计最多 16 份。容器通过 `/inputs` 读取独立快照，来源之后修改或删除不影响快照；续接仍使用同一份输入。资源页和任务详情均可预览、下载、登记成果和采用共享，写入／删除共享资料使用本场景任务管理权限。

执行结束后可以单独删除一般工作文件；输入与 Pi 会话随整个环境管理。删除登记交付只移除本地副本，登记记录和历史上传回执保留。`worker.max_calls` 按每次执行计，明确续接获得新一次调用额度；`max_cost` 仍为整个任务的累计费用上限，失败不自动重试。

文件生成、已登记、平台上传与客户端收到是不同结果。环境放弃只对已结束并关闭容器／账号会话的任务操作；放弃后不能续接，交付副本和共享资料保留。目录用量不是硬磁盘配额。

“资源”页按状态、创建时间和续接状态筛选任务，点击后计算各目录的文件数与分配字节。单项和批量均可选择“清理临时文件”或“释放环境”：前者保留 Pi 会话、输入、home 和工作成果，后者删除整个工作区与运行目录。释放前可在同一窗口浏览、下载、登记或采用产物。批量逐项显示结果；部分删除失败后，可明确再次释放剩余目录。终态任务仍持有容器或账号浏览会话时，先在空间卡片关闭遗留运行环境。

任务中断后，可让聊天用 `task.outputs` 按实际请求人权限查看原任务 `out/`：它直接列磁盘文件、大小和修改时间，并另列已登记副本，不会重新执行任务或自动登记。空的交付列表不等于文件没生成；文件存在也不证明内容合格。子目录逐层查看，不跟随符号链接。

当前任务镜像提供离线 HTML 渲染命令：`lenbot-render out/document.html --pdf out/document.pdf --screenshot out/page.png --print-preview out/print`；手机截图加 `--width 390 --height 844`，`--help` 查看用法。一次返回实际 PDF 页数、打印页面预览和屏幕截图，不借公共或账号浏览器。升级这项能力需要重建任务镜像并在停机后明确采用新标签，旧镜像不会自动补装。生成的 PDF／截图只有经过 `deliver_file` 才会出现在交付下载列表。

账号浏览需要独立守护进程、扩展和主人配对，不借用普通任务权限。任务MCP使用当前实际运行且角色允许的服务；保存后重启并使用匹配的任务镜像。

## 群聊对话管理

在面板的角色工具许可中明确允许 `host_manage` 和 `tool_search`，保存并重启后可在群聊提出管理请求。只有根 `owner_qq` 和全局 `permissions.admins` 可调用，群管理员或场景管理员身份本身不授予此权限。

例如“把本群改成只回应 @”会按需发现工具、读取场景字段并保存修改；“把本群改成只回应 @，然后重启”还会明确请求重启。默认只保存，回复待重启生效；单独说“重启机器人”会在当前轮收尾落库后交给启动器。直接运行 host 模块时报错，使用同一 `len-bot` 启动器后才具备重启能力。

工具支持聊天、学习、提醒、任务、已有角色包绑定、网页、记忆参数、已配置模型的生成参数、资源预算、保留策略与已安装插件的非秘密设置及选群。字段说明和当前值按设置块读取；不通过群聊显示或改写凭据、身份授权、连接或需要离线转换的参数。插件回执区分配置保存与实际应用，普通设置不自动重启。

## 升级与文件锁

首次初始化只生成根配置和角色，不创建业务库；这种尚未启动的实例执行迁移时会明确显示无库可迁移，不创建空数据库。已有文件的格式错误仍直接报错；若本应有历史数据，按实际配置路径和备份处理，不把“无库”当作历史数据已迁移。

停止实例、试聊及相关外部写者，按涉及范围备份配置、业务／记忆库和引用文件。SQLite的WAL也属于数据。从实例根执行：

```sh
uv run --no-sync python -m len_bot.next.maintenance.migrate
uv run --no-sync python -m len_bot.next.maintenance.migrate_memory_jobs
```

当前业务格式36、记忆处理格式5；已有当前格式不重复转换。35→36 让插件单次生成记录真实场景和插件来源，不再伪造聊天轮，旧调用从原 turn 回填场景并保留原始内容。运行与维护共用 `.lenbot-instance.lock`，占用就停止本次操作；不要删锁文件解锁。启动不会自动迁移数据。

### 上下文 token 预算升级

普通聊天改为单模型直接表达，预算采用独立输入阈值。这是显式配置更新，不改数据库格式，原消息、历史 voice 调用与记忆保留。

1. 停止实例，按运行手册备份程序、配置、角色与数据。
2. 删除 `models.roles.voice` 和场景的 `voice_context_tokens`，各场景 `voice_mode` 选 `direct`；评测 profile 同步选 direct。
3. 用 `compaction.input_tokens` 替换 `trigger_ratio`。输入包含角色、工具、原话和参考；输出另以模型 `max_output_tokens` 预留，二者之和须能放入 `context_window_tokens`。`keep_recent_tokens` 是完整近期单位的保留目标，`compaction.max_output_tokens` 是回想输出上限。不要按旧条数或比例自动换算。
4. 按实际服务核对续接协议。`history_policy` 缺省 native 保留；只有已核对由中转保持签名续接的 省去可读思考的路由才选 `omit-reasoning`，省去可读思考。其他字段仍原样续接，原始响应完整存档。
5. 从实例根执行 `uv run --no-sync python -c 'from pathlib import Path; from len_bot.next.config import load_instance_config; load_instance_config(Path.cwd()); print("配置有效")'`。这只是配置校验，之后按当前授权显式启动。

选择参数应依服务能力，较大输出额度是容量上限，不要求写满。一次性 system 与协议投影变化可能影响缓存。回退需停机恢复对应程序与配置；不要用旧数据库覆盖升级后的新聊天，也不自动回退。


升级到仅支持本地记忆的版本时，停机备份后显式删除废弃的 `memory_transfer`、`persona_memory_export`、`replay_memory` 字段（包括值为 null 的字段）。仍使用远端记忆的实例应先用原版本完成正文移交，再安装新版本；新版本不自动转换配置或数据。旧服务目录、移交归档和回执备份保留。

本地记忆正文在停机后手工修改时，从实例根执行 `uv run --no-sync python -m len_bot.next.maintenance.memory_reindex`。重建保留正文和历史，清除所有派生目录摘要（`.abstract.md`／`.overview.md`），避免旧概览继续作为当前资料；启用摘要整理后会按新正文重新生成。

## 记忆删除的范围

普通删除保留修改历史。forget 清除该文件的正文、索引、旧版本和派生摘要，并可排除指定原话再次抽取；原聊天、历史模型请求与外部备份仍保留。

## 无QQ的开发输入

独立实例配置 `onebot:null`、`delivery:"simulated"`、`panel:null`，使用同一 `len-bot` 入口，stdin逐行输入原生OneBot JSON。模型和显式开放的任务出网仍可能真实执行；不是全环境离线沙箱。

此入口不接实时插件／MCP／账号浏览／自动ASR。已有 `replay_web`、`replay_images` 只在明确准备固定材料时使用；缺材料就报错，不补联网。它们不是日常开发或发布的必选流程。

## 测试实例副本

停止源实例后复制到不存在的目标目录：

```sh
uv run python -m len_bot.next.maintenance.test_copy /实际/instance /实际/test-instance --panel-port 8089
```

命令持源实例锁，整份复制文件并保留权限和符号链接；只将发送改为 simulated、OneBot 改为 null、面板端口改为指定值。其他配置保持，配置校验失败直接报告原错。原文件和外置任务目录不会自动搬迁；绝对路径与符号链接仍指向原位置，启动副本前明确核对这些引用。副本可通过面板试聊，模型、插件和已启用的任务服务仍正常执行。
