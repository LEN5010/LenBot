# 部署导航

普通用户从[成品部署包](package/README.md)或[Docker 部署](current/docker.md)开始。唯一宿主入口为 `len-bot`，历史格式转换使用停机后的显式维护命令。

| 入口 | 用途 |
|---|---|
| [平台部署包](package/README.md) | Linux／macOS 安装、服务启停、版本化程序与升级 |
| [Docker](current/docker.md) | 离线初始化、原生卷、任务客户端和同路径挂载 |
| [可选服务](current/README.md) | OneBot、模型、记忆、语音和任务的连接说明 |
| [账号浏览成品](browser/README.md) | daemon、扩展与文件助手分别放在哪里、怎样安装 |
| [使用与维护](current/operations.md) | 角色、任务文件、离线迁移与归档 |
| [发行流程](releasing.md) | 候选产物、配套组件和版本发布，面向维护者 |
