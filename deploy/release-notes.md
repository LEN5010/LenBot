# 版本说明（草稿）

首个公开版本的说明草稿，发布时按实际构建和验证结果补全。

## 包含

- 程序：带面板的 wheel、源码包、Linux／macOS 部署包、宿主和任务 Docker 镜像、浏览器配套组件。Windows 用 WSL2 或 Docker。
- 群聊：每个场景一份持久会话，主脑直接表达，表情、引用和提及，长对话压缩成回想。
- 角色：角色包、草稿试聊、导入导出，附带一个[示例角色](../examples/personas/companion/)。
- 记忆：本地 Markdown，全文和可选向量检索，后台整理、修改历史和遗忘。
- 后台任务：独立容器里的 Pi，资料选择、追问、续接、产物登记和发送，可选存储池硬上限。
- 插件：Git 和 ZIP 安装，版本兼容检查，单插件重载，依赖变化在明确重启时应用；[插件模板仓库](https://github.com/lendevs/lenbot-plugin-template)。
- 管理：首次配置向导，面板管理模型、预算、权限和插件，主人可以在群里改设置。

## 数据格式

业务数据库为公开格式 v1，记忆处理库为格式 5。之后的版本在 v1 之上提供升级步骤，按[升级与备份](current/operations.md#升级与备份)停机执行。

## 已知限制

- 只有 OneBot（QQ）一个平台适配器；提示词和面板只有中文。
- 没有插件市场，发现插件靠静态目录或直接填仓库地址。
- 不提供 TTS，也没有原生 Windows 包。
- 账号浏览需要人工配对和登录，任务结束后不能接着用原来的浏览器环境。
- 部署包首次安装要联网下载 Python 和依赖。
- 表达效果取决于模型和角色材料，构建通过不代表回复效果已验证。
