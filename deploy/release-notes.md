# 本轮版本说明（草稿）

当前待发行能力说明，尚未公开发布。QQ 单核心版本包含带面板 wheel、源码包、Linux／macOS 部署包、宿主与任务镜像及浏览器配套包。Windows 使用 WSL2／Docker。

## 主要变化

- 文件查看、预览、共享、输入复用、独立交付和任务空间清理；可选实例存储池硬上限。
- 公共与账号浏览的文件上传／下载和截图落盘、来源与会话展示；账号浏览需要对应 BrowserSkill 扩展及文件助手。
- 静态插件目录、指定 Git ref 安装／更新、可写依赖环境和明确重启。
- 主脑直接表达、多人上下文、输入预算与压缩、角色草稿导入导出及显式收轮。
- 本地记忆的正文、检索、后台整理与遗忘；对话管理支持授权管理员保存日常设置及明确重启。
- 成品安装使用 uv，不要求 Node/npm；程序版本目录与实例数据分开。Docker 宿主提供客户端和任务挂载配方。

## 升级

先停止宿主和试聊，备份实例、外置任务目录与记忆文件，再按 [运行手册](current/operations.md#升级与文件锁)更新配置及离线数据。当前业务格式为公开基线 v1、记忆处理格式为 5。未发行的格式 36 实例须先完成维护者的一次性停机转换，旧升级链不再随程序分发。旧远端记忆用户须先用原版本完成正文移交，再安装当前版本；任务与账号浏览组件单独按对应版本升级。

## 已知边界

- 自然表达仍可能出现顶嘴式开头、重复叮嘱和任务通知冗长；角色草稿须明确试用和采用，不把构建成功当作表达效果验证。
- 当前插件只有静态目录和 Git 安装，市场发布后端、ZIP 安装与完整版本兼容尚未实现，不能按已交付能力介绍。
- 记忆整理仍取决于实际模型服务；普通删除、完整遗忘、原聊天和外部备份的范围见运行手册。
- 账号浏览依赖人工配对／登录，原任务环境续接未支持；具体浏览器操作与真实 QQ 上传依实际配置和服务状态。
- 不提供 TTS 服务、Telegram／Discord、原生 Windows 包或自动定时清理。
- 平台包首次安装会下载 Python 及依赖，不是全依赖离线包。构建平台矩阵不等同于各平台完整产品操作已验证。
