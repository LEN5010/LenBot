## 能力与默认值

工具返回类型化状态、来源/时间与持久引用，长结果分页；核心及常用网页工具直接可见，其余按需发现。同工作复用结果，独立只读调用有界并发，模型尝试与工具执行计入预算。

工作由 Social Core 提案、Gate 提交，执行器只使用只读工具。默认每群 1、全局 2，16 个模型步骤、24 次工具、300 秒、64K 上下文，修订不重置预算。结果回流后按最新语境表达，不固定播报。中断保留观察并待核对恢复。

图片按 scene 保存，vision 独立配置，未配置不猜测。表情由运营维护；消息使用文字/图片段，最多三条，后续有限等待；失败或不确定停止本组，不重试未知发送。

### 通用工具与工作

2026-09-06 的真实读取取得 Python asyncio 文档、Trafilatura API 文档和普通 GitHub issue 页面正文。首次抽测发现压缩体二次解码，已修复，没有增加站点判断。搜索结果与正文不代表模型已经正确综合。观察与待投递事件同事务保存，派生内容不能充作独立记忆证据。

工作详情 agent_jobs 与 tasks 使用同一 ID，任务表是调度/送达权威。创建、修订、取消、恢复与 Session、记忆和确认消息在 Gate 同事务提交；执行器持久保存目标版本、已消耗预算及资料引用。后台步骤不推进社会读取截点，进展和结果才回到社会理解。只有就绪结果才能关联交付，发送前检查取消和版本。

工作页查看、修订、停止、恢复及资料分页已接线，HTTP 读取经 QueryService。历史检查覆盖事务失败、旧版本结果、重复完成、在途补充/取消与重启；实际对话中的目标理解继续在群里核对。

### 媒体与表达

OneBot 原始 segments 保留，入站图片与 source Event 同事务登记为 scene-scoped media_assets。图片按需获取，限 10MB/20MP，以 Pillow 校验并哈希缓存；不读取任意本地路径。运营素材可显式选择 global-safe，群内图不自动晋升。

inspect_image 使用独立 routing.vision。视觉解释属于 model 证据，保留原图事件；动图只分析首帧并标注。视觉调用与格式修复计入认知模型额度。ActionQueue 每群保序，全局最多 4 个投递并发，后续片段按长度等待 0.6–2 秒，发送前复查资产、工作版本和 Shadow。

Social Core 加强当前目标、最新约束与来源/未知的区分，继续输出稀疏状态。diana-v3 通过已有预览流程追加四组表达样例，保留人工编辑和启停。发现最终续接工具观察未计入截点后，已修正为确认自己读过的连续观察，不能越过未读输入；这一真实修复继续保留。
