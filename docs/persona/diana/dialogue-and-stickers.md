# 嘉然表达与运营表情

2026-09-06，面向运营者。当前管线见[架构](../../architecture.md)，来源资料见[人格来源](README.md)。

嘉然角色卡保留身份、兴趣与经过核对的梗语境，相处方式和表达特点收为简短配置。角色资料帮助理解玩笑，不证明现实参与、游戏能力或群友关系。保存配置优先，启动不覆盖。

`diana-v4` 提供六条运营参考：自然接话、普通认同、接受纠正并给对话留空间、来源尚未确认时表达工作结果、庆祝单图、食物话题图文混排。参考按固定顺序提供，使用真实素材引用和与终结工具一致的 segments 结构；不包含本次糖果题的答案，也不充当群聊历史。

预设先预览后显式应用。旧预设原文只用于判断是否有人工修改，已改过的条目保留；未改的旧参考可在预览中列明停用，新六条使用独立 ID。普通手工样例不被替换。单图和混排可在设置页编辑，引用停用或越界图片的样例不会进入模型上下文。

运营库保留 115 张嘉然原图，排除“糖糖与小然熊的游园会”，按以下 20 种主情绪分类：生气、疑惑、喜欢、开心、难过、紧张、无语、调侃、观察、困倦、期待、感动、鼓励、惊讶、认同、招呼、委屈、得意、吃饭、平静。

本次目录从每类各选一张，形成固定 20 项编号总览。模型可直接选择 P01–P20，也可用 search_media 检索完整库；语义判断仍由模型完成，没有按消息关键词强制发表情的规则。素材搜索支持多词任一命中、按命中数量排序，场景和启停条件始终适用。

图片页可调整目录顺序、启停和说明。总览按场景与素材版本缓存，变更后重新生成；缩略图只用于选择，发送读取原图。Reset 保留运营库、目录设置和来源记录，清理聊天产生的图片与观察。

实群观察发现，162×162 原图按普通图片发送仍会占据较大的气泡区域。运营素材带有明确的 `表情包` 标签时，发送使用 OneBot 的 `sub_type=1` 自定义表情类型，保留原图字节；普通照片保持普通图片。标签来自运营素材资料，不由模型或消息关键词决定。[NapCat 消息格式](https://napneko.github.io/develop/msg)支持图片子类型；最终显示尺寸由 QQ 客户端决定。

图文节奏同时参考最近几次实际发言。文字已表达完整时可以直接结束；多条消息整体安排表情，通常选择最合适的一处，保留单图接话和自然混排。不按固定比例、随机数或硬性次数控制，也不把减少配图变成减少有意义的回应。

准备回答陌生对象、外部事实和当前信息时主动发起后台搜索。群史只能帮助理解群友说过什么；角色资料保留原日期与适用范围，不能直接充当当前事实。查询结果需核对对象、来源与时间，偏题或过时的结果保留未核实项。
