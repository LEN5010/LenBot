## 表情包来源

用户于 2026-09-06 从本地 `Diana/表情包` 目录提供 49 张有效图片，其中 25 张 GIF、24 张静态图，约 45.85MB。整理时记录了名称、动作、图中文字、适用语境和标签，原始索引保存在[表情包索引](sticker-pack-20260906.json)，来源与素材身份保留原记录。

最初从中选择 20 张常用图进入运营目录，覆盖问候、确认、支持、开心、好奇、无奈、晚安、撒娇、等待、吃饭与认真解释。实际目录后续可由运营编辑，当前内容以保存的资产与顺序为准。

GIF 的动作说明来自当时抽帧观察。该批源图最长边 1500，最大文件约 9.29MB；这些是素材属性，不是运行参数默认值。当前像素覆盖、表情标签及发送行为统一见[产品文档](../../product.md#图片与人格)。
