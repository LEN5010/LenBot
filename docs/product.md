# 当前产品行为

LenBot 面向群聊参与者与运营者。本文说明已有功能对用户意味着什么；实现方式见[架构](architecture.md)，操作方法见[运行手册](operations.md)，本轮未完成目标见[当前任务](iteration.md)。

日历、开播、群报告和动态卡片保留来源、时间与覆盖说明。精确命令可以直接生成卡片；普通问题继续走现有 Agent。工作空间和浏览器只在配置启用且边界满足时提供观察或处理结果，GSUID Core 只接收明确命令。

## 社会 Agent 完整计划的边界

[`LenBot 社会 Agent 完整实施计划`](LenBot_社会Agent_完整实施计划_7a4152d.md) 是分阶段目标和交付合同，不是当前能力清单。当前已实现行为仍以本文其余章节和 [`当前任务`](iteration.md) 为准；计划中的公共兴趣、心跳与睡眠、独立 Worker Gateway、B 站登录态、视频片段分析、文件上传、点赞收藏和主动聊天，必须逐阶段实现并取得人工运行证据后才能写入“已具备”。

计划对现有语义的收口如下：`proactive_chat`、`interest_share` 与 `send_file` 分别授权；GSUID Core 继续是可选能力，不是社会 Agent 第一版的前置条件；系统工作使用明确的 system/plugin 发起身份，不能伪造 QQ 请求者；30 分钟是首次开始后的绝对期限，10M 是累计模型输入与输出上限，恢复不重置；睡眠只影响普通聊天、心跳和主动发布，确定性只读卡片是否例外须按计划验收。自主网络探索首版限 B 站及经确认的必要资源域，人类明确授权的联网 Python 属于另一能力范围。


## 聊天与旁听

所有接收到的原话先保存。群是否启用、普通成员能否聊天、开放哪些插件、命令与公告，由本群设置决定；没有启用的群不产生新认知或发送。chat 关闭时，普通成员消息只保存；全局 QQ 回复白名单中的用户仍有普通互动资格。白名单不强制每条回复，也不授予管理员、跨群读取或全体提及权限。

有对话资格的输入经过实际 @、回复 Bot、呼唤昵称、连续互动和有效工作的参与者线索提供唤醒；关键词和时间窗口抽样只提供一次观察机会。获得机会后仍由对话入口决定是否参与。未唤醒的旁听不逐条调用模型，也不记成“模型决定沉默”。仅播报群不做闲聊历史维护，明确工作的压缩仍使用该工作的预算。

既有私聊继续保存与观察，沿原 Shadow 语义不实发；群设置不另行开放私聊插件或发送权限。

新的一句话不会自动替代仍在继续的前一个问题。每项明确委托保留提出它的人和原话，同一轮中的多人请求分别归属；显示上的回复引用可以与内部请求来源分开。玩笑沿前文中的具体对象继续；共同玩的设定仍是聊天语境，不能成为 Bot 真实经历或能力的证明。对明确 @、回复 Bot、受托事项或真实等待关系的送达可建立短时关注，同一参与者可以继续追问；正在处理或尚待回执的同一来源也能继续输入。仅因处于关注窗口而继续发言不续期，仅由弱关注带来的 Bot 接话也不无条件续期。

当前请求、真实引用和必要相邻原话优先装入，并按保存顺序呈现；内部待处理编号、预算与运行状态独立于作者原话。读取小工具结果不会自行清掉相邻语境，只有实际容量不足时才移出可选旧资料。装入范围与省略原因可沿 Trace 核对。

一次表达可以是文字、真实成员提及、图片、视频、音频或混排，也可以保持沉默。回应对象、请求来源、显示引用和期待回答者分别记录；文字中的 @称呼不等于真实提及，全体提及仍仅由已开放公告使用。消息数量和工具、模型预算受当前配置和终结协议约束；普通模型正文不直接发送，只有已提交的表达进入发送流程。可以一次提交后结束、在原预算继续读取，或等待实际外部回应；所有阶段累计受同一消息上限约束，入队不表示对方已经收到。参与频率和表达形式分别判断，不设固定发图比例。

指定照发时只发送要求的文字、标点和换行，不追加角色评论。实际消息使用真实换行；用户明确要求显示转义写法时才发送反斜线文本。发送层保留已提交文字，不事后猜测或替换用户可能需要的字面内容。

原话被读到与请求已经处理分别记录。回应、委托工作、等待、未完成或选择旁听分别记录，只结束本次列明来源的处理尝试；一条原话中的未完成要求仍保留。读到但尚未处理的独立请求继续保留，旁听资料不因此变成逐条回复承诺。空提交本身不会反复取得新预算。明确委托需要回答、实际委托或准确说明无法完成，不能因为回应了旁边的闲聊就算处理完。本人纠正误接或要求停止时，可以随提交撤销现有短时关注；该次确认不会重新续期。临时结束当前互动不自动变成长久群规则；之后本人重新明确发起请求时按新语境判断。

普通新输入不会取消正在等待的模型请求。在完整工具交换后，尚未提交的轮次可以在原预算中继续接收新输入。提交普通定向回应、认识修改，或控制与交付工作、提醒和等待关系时，必须读完与当前事项、请求者或实际引用有关的确定唤醒；其他人的独立请求可以继续分别处理。明确修订保留原工作，明确取消阻止旧版本继续提交，关系不清的追加由对话入口理解。因相关原话尚未读完而未提交的候选不会产生消息或任务。

## 信息工作、提醒与等待

Agent 按工作量决定在当前轮处理或交给后台工作。一两次联网读取、短计算和短资料比对可直接完成；需要长时间、多页阅读或保留进度时使用后台工作，前台聊天继续接收新话。新建、修改、停止或恢复工作都要基于实际请求与当前版本。修订保留已消耗预算和已取得资料；工作不直接发消息或写入认识，普通进展与信息结果回到对话入口，插件成品沿原工作交付。

创建确认只关联本次真实创建的对应事项，不要求同轮其他人的普通回复也带工作确认。恢复、修订、取消及认识修改的确认关联本轮对应操作，只有操作与确认在同一事务提交成功后才成立；普通引用旧结果不能借此改绑新版本。创建确认与完成后的结果交付分别记录；只有确认消息真实送达才算向用户作出承诺。

当前版本的受托工作形成完成或部分结果后，普通信息结果由原对话入口结合请求、现有要求、来源和未决项组织首次交付；插件已生成的成品由工作交付入口提交。无需用户再问一次“结果呢”。群中出现独立话题不取消原委托；不同工作可以依次交付。旧结果再次出现在资料目录时只供按需引用，已有行动或未知回执不会因此自动补发。

| 显示状态 | 含义 |
|---|---|
| 执行完成 | 工作按当前目标形成完整结果，仍需结合原问题与来源判断结论是否正确 |
| 部分完成 | 保留已取得结论及明确未决项 |
| 失败／中断 | 本次执行没有成功完成，保留原因、资料与预算；符合条件时可显式恢复 |
| 结果待回应 | 已有终态资料等待对话处理，可能包含失败说明，不代表查询成功或已送达 |
| 待核对 | 运行中断等情况需要运营或当前对话明确处置，不自动从头重做 |
| 等待送达／送达未知 | 表达已进入交付阶段；未知不能推断成功，也不能自动补发 |

完整完成或取消的工作不重新执行；完整结果发送失败也不能作为重跑工作的理由。partial 保留明确未完成范围、仍有预算且旧版交付状态已确定时，可显式继续同一工作；保留已用预算、资料和旧版回执，由新版本形成新的结果。待回执或送达未知期间不继续 partial，也不自动补跑。失败说明可以解释情况，不能冒充成功履约。恢复模型处理需要原绑定仍可用，不能改用其他型号；只剩已保存成果的本地渲染时无需新模型调用。

提醒分别保存提出者、目标对象、请求原话与触发时间，不把被提醒的人自动当作请求者。到期只证明触发发生，实际履约仍取决于交付。等待回应只在真实发送后激活，结束或过期各有明确记录。显式挂起的请求在目标账号引用原发送消息，或只有一个对应等待且实际 @Bot 时按原预算继续，等待时释放模型资源。对方没有响应就不宣称取得结果；重启后的旧挂起请求保留待核对，不从头发送。

## 原话、资料、认识与技能

当前群的按需报告先固定带时区的 `[start_at,end_at)`、请求者与数据快照。“今天”“昨天”按请求原话发生的业务自然日确定，指定日期用该日零点至次日零点；明确时段使用给定范围。插件按实际请求容量安排原话批次、保存成功分析并合并话题，最后生成结构化报告与图片。日程命令及引用评论保留，Bot 回声和内部运行事件排除；只说明 LenBot 已保存的本群记录，不能声称取得 QQ 全日全部消息。

消息数、参与人数、展示文本字符、发言时段和发言最多的账号由程序统计；金句从所选原话的字符位置提取，作者使用稳定账号身份。报告分别显示范围内消息、本工作实际提供给模型的消息、成功分析、复用分析和未完成数量。调用失败不推进成功分析位置；复用结果不算成本次重新读取。相同消息批次及相同分析要求可以复用，缩小时段时不能继承范围外的引用上下文，更不能把全天报告当作晚间原话。

结构化结果、报告图片与送达分别保存。渲染重试消费已保存 JSON，不再次分析；首次成品沿原工作交付，保留最新输入、版本、场景和回执检查，普通对话不重新改写日报。发送失败或未知不触发重新分析或自动补发。历史报告只按当前群、精确范围与工作版本查询；不默认定时生成、跨群广播，也不生成群成员的长期认识或方法技能。社会 Agent 计划中的公共兴趣属于独立、受限的 AgentInterestMemory，不能与群成员认识混用，且在相应阶段完成前不视为当前能力。

资料被取回、已保存、能定位、实际展示给模型，是不同状态。多份资料共享同一次请求的剩余容量；装不下的正文保留本地续读位置，源端下一批只表示还可以继续取得。工作目录只提供简短定位，长详情按保存正文逐页读取；若页量与请求余量无法容纳可读正文，明确说明读取没有推进，不能循环消耗步骤。已保存正文完整不表示源端全文已经取回，未展示的原话和图片不计为已读。工作结论可以关联实际读过的资料范围，来源可回查不等于结论已核实。当前工作信息仅在变化时更新，旧查询结果不会使目标版本倒退。

工具按当前群和角色的可用能力发现，中文名称、别名和自然短语用于定位。明确请求优先使用对应能力；当前群未开放、插件停用、未配置和本次调用失败分别说明，普通信息工作不替代专用群总结流程。没有匹配、输入参数错误、单次超时和当前不可用分别返回具体结果；模型可在剩余预算内调整查询、续读或说明未决项。尚未提交候选的参数、引用或未读范围错误返回具体原因后，可以在同一轮原预算内纠正；真正的版本冲突、供应商失败、非法协议和传输未知不会因此重试。发现和续读不会自动建工作或发送消息。

指定来源的检索需要实际使用该来源：群消息、网页索引和账号发布记录分别描述自己的范围。未调用或尚未读到正文只说明未完成查询，不能写成另一来源没有结果。历史动态关键词搜索在本群已开放动态插件时直接可选，工具可见不表示每条消息自动查询。

历史摘要是带原始范围的非权威缓存。摘要与来源位置帮助找原话，不能替代实际阅读，也不能独立授予认识或工作证据。维护失败不推进覆盖，未覆盖历史与失败范围继续可见。

认识保留主体、陈述、原始证据、有效期及修订链。“有人明确报告”和“从互动推断”分别显示，均不等于客观核实。当前互动优先使用有关参与者与本群的有效称呼、偏好和规则，其他认识按需查询。查询先限定主体、类型、时间与有效状态，再按文字和已知别名定位。撤销或替代保留旧陈述及理由。要求忘掉昵称时，先查看有效认识，有记录则撤销或替代；未保存为长期认识时停止采用这个称呼，不声称清空历史。账号昵称和群名片属于协议事实；偏好称呼独立保存，缺省字段不清空现值，同名不合并身份。人物定位可按本群已保存账号、昵称、群名片和明确称呼查询，来源定位不表示原话已经读过。

方法技能包含适用条件、步骤、不适用情况、来源与版本，工作首次读取后固定该版本。维护可以保存有依据的新方法或有效纠正，也可以因重复、没有新增方法价值、仅含一次性答案、来源不足或暂时故障而正常跳过，并保留原因。使用过技能和客套回应不增加可信度。自动技能限来源场景，人工内容不被自动覆盖，公开范围针对运营选定的版本。技能不授予工具权限，不自动创建工作或群消息。

## 图片与人格

当前及引用图片直接进入同一次多模态请求，按实际像素窗口记录覆盖。窗口外图片或被移出的旧图可继续读取；历史上看过不等于当前仍装入。动图向模型提供首帧，发送保留获准原文件。网页图表和 PDF 文字层分别读取，文字提取不代表图表像素已看过。

运营素材有说明、标签、启停和固定目录顺序，完整库可以检索。目录和检索候选显示本群最近真实发送窗口内的使用次数、最近发送时间和是否刚在上一条回复中使用；准备发送、Shadow 与未知回执不算使用。多个候选同样合适时减少近期重复，明确要求重复原图时允许照办。明确选定或要求重复的已登记获准素材可直接提出发送；分析画面、断言图中文字或人物、依据视觉内容选图仍须读取实际像素；运营明确标为表情包的素材使用 QQ 自定义表情类型。聊天输入图片保持所属场景；跨场景素材由运营明确发布。

视频和音频也必须先成为场景媒体资产，再由原有 ActionQueue 和 OneBot 发送适配器准备与提交。下载使用临时文件和大小限制，取消或失败不留下可复用半成品；下载完成不等于已经决定发送，未知回执不自动重发。

人格与人工表达参考影响说话方式，不构成群友事实、真实经历或实时资料。启动不会自动应用人格模板或重建已删除样例。运营可以独立维护文字、单图和混排参考，来源资料见[人格资料](persona/diana/README.md)。

## 日程、动态与开播邀请

日程使用唯一 ICS 来源，返回源事件身份、明确时间、取消状态与取得时间；缺少结束时间显示未提供，团体署名不强制展开成员。未调用只能说明尚未查询；来源返回 403 是本次访问失败，不能说官方尚未发布。成功空结果只说明该来源和范围内没有条目，日程未收录不表示确定没有直播，排期不证明实际开播。缓存到期后刷新失败就是本次失败，旧快照仅在面板标注时间查看。

本群开放的精确日程命令由日历插件直接匹配并消费，默认读取同一日程工具后生成图片；普通聊天关闭也不影响已开放的命令。原命令、实际响应和通过真实引用关系识别的评论不进入普通对话、轮中新输入或闲聊维护，送达不建立聊天关注；QQ 白名单也遵守这一归属。没有引用关系的短评不通过关键词或额外模型分类，运营用法见运行手册。图片生成或发送失败不改发文本。

动态工具读取指定站点已抓取的最新项目、搜索、历史同日与二创，明确发布时间和取得时间。续取下一批保留原成员、筛选与排序；成员无法识别时失败，不改查全员。随机二创每次独立取样，查询仍只返回资料；公开图片可继续读取像素、登记本群资产，再由正常表达链提出发送。搜索片段、已取得的源记录与真实像素分别说明；不存在的详情接口不编造，源失败不转其他来源，查询不会触发自动动态广播。

共享直播采集在第一次成功读取时建立基线。之后出现新的真实房间号与开播时间，才为订阅群建立一次公告事项。相同场次不反复生成，采集错误不视作下播。直播插件按自身配置选择既有模型路由生成邀请，再向来源群提交；共同发送队列根据插件的当前群设置添加真实全体提及。公告不激活普通聊天关注，源明确下播、订阅取消或群停用时停止旧邀请。生成失败、发送失败和未知回执均不自动改写或补发。

开播订阅可在对话中读取本群实际配置、通知开关与监测状态；保存订阅不等于已有新鲜样本或已通知。群聊没有修改全群配置的管理权限，订阅和退订由登录后的本群设置中“哔哩哔哩直播监测”的订阅字段办理；时间提醒不替代开播事件订阅，也不承诺未实现的个人私聊通知。

B 站链接由启用后的原生 link_parser 识别。纯 BV/av 视频链接或明确的“解析链接 URL”命令可确定性读取标题、作者、简介和规范链接；自然语言问题仍由普通 Agent 决定是否调用工具。解析默认只取得 metadata，视频播放地址需显式调用 download_media，下载后的媒体仍须经过原有提案、队列和真实回执链路才会发送。语义检索还需在本群设置中明确开启，关闭时不会把本群认识或摘要发送给检索供应商。

语义召回在词面和向量两条路径上使用同一人物、类别、建立时间、状态和有效期筛选；索引覆盖量只统计当前认识修订，重建清理不会删除重建期间新增的合法索引。场景关闭语义检索后，已排队但尚未发出的索引批次会在下一次并发请求边界停止，并记录中断。

历史摘要搜索保留词面与语义命中的并集，不能越过当前读取截点；摘要中的批次身份与查询观察的资料引用分开。初始插件资料在最终图片窗口装配后再次核对必需图片，无图片续读能力时缺图会明确失败。内部 audio 出站映射为 OneBot 11 的 record 段；媒体下载只有在容器内容校验通过后才登记为可发送素材。

检索 embedding 请求明确使用浮点编码；语义操作在本地调用记账等待之后、每次 embedding 和 rerank 实际外发之前再次核对场景开关。下载工具成功结果以已验证资产的 MIME 为准，HTTP 响应头只作为来源观测。历史摘要日期范围在向量 top-k 前应用，范围外摘要不会占用候选额度。

## 发送、运行状态与面板

| 发送结果 | 含义 |
|---|---|
| `sent` | 具有真实发送回执，证明实际送达 |
| `not_sent` | 已明确未发送 |
| `rejected` | 候选或发送被当前业务条件拒绝 |
| `unknown` | 结果不确定，不自动重试或更换通道 |
| Shadow／模拟 | 候选或隔离运行事实，不证明真实发送、履约或正常短时关注 |

真实发送由当前群的启用与对应 chat、command、announcement 字段和全局 Shadow 共同控制；独立实发群名单已退出。类别由实际入口绑定，模型不能自行选择。源码、型号或人格变化不重设群设置。同一发送批次中，一次失败或结果未知只停止同一请求、同一事项的后续消息，其他独立请求仍按原顺序发送。

面板从原话按真实关联展示请求者、读取和处理来源、当前工作版本、工具状态与资料范围、创建确认及最终回执。模型请求完成、工具返回错误、工作形成结果和消息送达分别呈现，缺少独立来源的旧记录显示未记录。写入等待服务端结果，不因刷新自动恢复工作、补发或发起模型请求；尚未保存的草稿与失败反馈明确显示。

提案已经保存后，调度或行动入队仍可能失败。面板保留已提交的工作、认识与处理来源，并列出发布阶段及每条行动的入队状态；入队不等于送达。这种失败不会撤销真实提交、重做事务或自动补发。

群关闭普通聊天不妨碍已登录运营者管理已有工作和提醒。面板修改、恢复或触发只提交状态操作，不伪造 QQ 白名单身份或发送资格；后续实际执行仍按原请求者和当前群设置判断。

对话、工作和维护分别配置模型。未配置对话时仍接收保存输入；其他角色未配置时对应能力明确未就绪。每个真实请求保留用途、实际绑定、usage 或未知状态；本地估算单列，失败、取消与未确认不能按零用量计算，没有价格依据时费用保持未核实。

显式 Reset 会清理会话与自动产生的资料，保留运行配置、登录、人工样例和运营素材及来源。它是单独管理动作；操作范围与授权要求见运行手册。
# 下一阶段交付契约

用户看到的日历、开播、群报告和动态卡片都保留来源、时间与覆盖说明。精确命令可以直接生成卡片；普通问题继续走现有 Agent。工作空间和浏览器只在配置启用、边界满足时提供观察或处理结果，GSUID Core 只接收明确命令。
