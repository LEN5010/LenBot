## 版本与旧入口

当前合同、教程、示例和前端对应**同一 Git 提交**，不是对所有旧部署的兼容承诺。API 世代看插件描述符 api_version，插件自身版本另看 version；不要仅改声明数字假装完成迁移。真实环境的提交／镜像与人工结果记录在当前任务或原发布观察材料。

以下为现有前端 Hash 路由的导航说明，不是服务器 API；地址位于面板 URL 的 `#` 之后：

| 旧入口 | 当前入口与保留行为 |
|---|---|
| `#/groups` | 跳转 `#/scenes` 群聊目录；保留原筛选，默认选择群聊 |
| `#/groups/:sceneId` | 跳转同一 `#/scenes/:sceneId?tab=settings` 表单，不另存一份群规则 |
| `#/settings?tab=persona`／`attention`／`time` | 跳转 `#/agent/settings` 的原对应标签；其他系统配置仍在系统设置 |
| 旧文字“场景消息”“群设置” | 从群聊工作台选择原场景，再进入设置；不要寻找第二套保存按钮 |

没有同版页面可观察时，按文字和真实路由定位，保留待验收；不生成模拟截图代替当前界面。历史截图若属于旧版本，只保留作历史依据，不作为新手操作步骤。

## 后续怎么维护

行为变化修改所属合同；任务状态只改路线入口；实际核对与未确认项写当前任务。批次结束后，将需要留存的过程移入历史记录，并在当前任务保留尚未关闭的交接项。已被当前合同取代的计划可移出工作树，同时保留明确的 Git 回查位置；真实观察、原始资料与未确认限制不能随瘦身丢失。
