## 后续怎么维护

行为变化修改所属合同；任务状态只改路线入口；实际核对与未确认项写当前任务。批次结束后，将需要留存的过程移入历史记录，并在当前任务保留尚未关闭的交接项。已有设计引用、原始资料与未确认限制随整理保留，避免通过移动文件抹掉待办或证据。
