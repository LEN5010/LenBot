面向维护者与插件作者。2026-09-23 按代码基线 `8730431`、全部内置描述符及业务时钟源码核对；本批另补面板注册声明的显示。这里记录逐插件适配事实，不维护第二套任务状态，也不表示已经发布。任务状态只见[产品路线](plan/README.md)，接口合同见[插件开发](plugins.md)，运行证据与提交见[当前任务](iteration.md)及[历史记录](history/README.md)。

## 一、统一迁移范围

当前共 13 个内置描述符，另有 local_clock 本地示例；全部声明接口世代 2。目录名不一定是插件 ID，根配置、来源及工作归属使用描述符 ID。下表自身版本来自原描述符，不因接口世代变化而重命名插件或改写原业务身份。

路线实施以来共同完成的适配：

1. 描述符必须显式写 api_version=2。省略、字符串、布尔值或其他世代均拒绝发现，停用目录也不跳过；先导入包再检查世代，不是代码隔离。
2. 专用工作的四类回调改为世代 2 的 preparation／snapshot／parameters／progress 等窄输入，只有群报告声明此类工作合同；其他插件不需要凭空补回调。旧回调不自动适配。
3. 插件工具的 ordered 默认已改为 True。表中“业务文件无须额外修改”不等于运行行为完全不变；显式 False 才允许进入原并发分支，同轮包含有序调用或提案仍整批串行。
4. Hook 逐回调核对保护字段并按插件／场景管理取消；装载、启用及配置应用的取消进入原错误边界，卸载失败不继续本次实例替换。原事件与真实回执不因卸载删除。
5. 全部当前描述符未选择 in_place，沿 PluginSpec 默认 restart_plugin 应用资源配置。根配置保存与运行应用分别确认，不根据保存成功推断插件已恢复可用。

本文的“接口适配／业务文件无须额外修改”是代码处置说明；所有条目仍有“现场待确认”部分。不得通过启用全部插件、制造假来源或运行测试补齐它们。

## 三、保留工作空间兼容身份

workspace 和 python_workspace 是同一实现的两个既有 ID，不是允许同时启用的两套执行器。configured_workspace 先取已启用且已配置的项；没有启用项时只允许唯一已配置项，两份保存配置不能用顺序猜后端。工具同名注册冲突仍明确报错，不删除旧 ID 以制造“已统一”。

当前不迁移旧 ID 的数据目录、PluginOrigin、工作修订、结果或行动身份。需要改 ID 时，先按[运行手册](operations.md)停机备份，并单独决定真实存量数据的迁移方案；不能仅改配置键后宣称旧工作可按新归属恢复。代码升级与数据转换是不同操作，本批没有执行二者。

## 四、面板与同版 API 的对应

1. 目录发现、配置 Schema 和场景 Schema 都来自实际 PluginSpec；不新增中央插件清单。接口世代不匹配在发现时结束，而不是由前端忽略错误继续装载。
2. 面板列出接口世代、自身版本、来源目录、配置应用方式、运行错误、已注册工具／handler／Hook 及所属任务。全局开关、目标群开关、来源条件、能力和模型选择仍是不同边界。
3. 工具的顺序、发现展开、执行超时和展示页长从原注册定义投影；handler 的延期来源重核标志来自真实注册。它们只解释声明，不授予当前调用资格；未记录值不当作 False 或零。页长不表示原始资料被截断。
4. 资源权限标成“声明的资源权限”，不是当前人类请求者已获的 grant。执行仍沿原 has_tool、来源、工作、Gate 和回执检查；源码或面板存在入口不意味着真实使用过。
5. 配置表单仍按 Schema 生成，保存失败保留原冲突与错误，不换另一插件对象作为基线。新外部插件是否在获准环境成功发现、配置、启停，仍需同版人工记录，编译／构建不替代它。

## 五、作者迁移顺序

- 先阅读当前接口世代、工具顺序及 Hook／生命周期变化，确认自己的实际签名与调用路径；不要只改 api_version 数字。
- 保留插件自身 ID 和真实业务来源；把常见读取迁至已提供的当前调用入口。内部模块没有因为仍能 import 就自动成为公共合同。
- 只在真正需要时声明专用工作或延期重核回调。普通确定性命令不必创建工作或调用模型，取消未知不能写成远程已停止。
- 资源由插件目录、已声明配置或明确公共随包资源定位；不靠相邻插件碰巧存在，不在运行时安装依赖或复制真实配置作模板。
- 升级按[接口世代升级](operations.md#插件接口世代升级)办理。先核对代码／构建，再在获准环境观察正常业务的来源、调用、工作、资产和回执；未提供的现场项继续保留，不新增测试或假记录补齐。

本清单没有发布许可、支持期限或素材授权结论，也没有推送、合并、部署或启用任何插件。对外支持组合与首次发布范围仍由维护者决定。
