# Semantic Memory Hierarchy, Slot Superseding, and ExecutionScope Privacy Guard

In long-running social groups, the agent must accumulate stable epistemic beliefs across time and scenes while never erasing the historical trail of belief updates, hallucinating fake provenance, or leaking private conversation secrets. We decided to structure memory into L1 Episode Records and L2 Epistemic Beliefs with explicit lifecycle states (`ACTIVE`, `SUPERSEDED`, `REFUTED`, `FORGOTTEN`). New beliefs for an existing semantic slot `(subject, kind, key, scope)` supersede old records and link forward via `superseded_by`, allowing full evolutionary trajectory tracking. Privacy boundaries are enforced strictly in SQL queries (`WHERE (scope IN ({allowed_scopes}) OR visibility = 'global')`), guaranteeing that private chat secrets cannot leak to public scenes regardless of prompt injections. Finally, an exponential temporal decay sweeper discounts unused beliefs over half-life periods while access frequency reinforces enduring preferences.
