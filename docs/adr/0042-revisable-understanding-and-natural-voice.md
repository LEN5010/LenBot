# ADR-0042: 可纠正的认识与有界工具续接

Status: accepted; implemented, naturalness acceptance pending. Date: 2026-09-06.

## Context

实群运行中，Bot 口头撤销了错误身份却没有撤销记忆；账号昵称被群名片遮住后又被当成假名。默认空列表会抹掉互动反馈。ADR-0041 的最终续接禁止工具，使新到的搜索请求被直接回绝。

## Decision

Actor 记录账号昵称、群名片；认知只能提案偏好称呼及有证据的增量认识。人物、关系、自我和群身份列表使用明确的添加/移除，省略不是清空。反思与认知使用 social_revision 比较理解版本，不用消息计数代替。

记忆统一支持 upsert、refute、supersede。修订引用同群有效记忆 ID 和原始证据；修订、工作状态、提交回执和回复提案在 Gate 的同一事务提交。原记录不删除，冲突不覆盖较新的认识。工作状态携带依赖的记忆引用，历史仍按需检索。

取代 ADR-0041 的“最终续接禁止工具”：草稿之后最多吸收一次新增事件，然后固定截点，允许剩余预算内的工具循环。吸收时必须还剩至少三个模型步骤和工具额度，否则新消息留在持久游标之后。每轮仍最多五个模型步骤、六次工具执行；格式修复计入步骤。任务/OpenLoop 严格新鲜度、取消和权限不放宽；没有新工作流或自动无限交接。

嘉然以亲和自然、偶尔调皮为底色。启用的运营样例按稳定顺序直接携带，不轮换、不评审人格、不用关键词修复社交行为。显式应用新版预设保留人工编辑，启动不覆盖配置。所有外部表达仍由同一 Social Core 提案。

## Ownership and commit boundaries

SceneActor 是工作状态的唯一写入者。昵称、群名片、真实发送及事件引用随事件更新；偏好称呼、关系模式、反馈等理解由带证据的增量提案更新。模型不能改账号身份、已读游标或运行时事实。省略字段表示保持，列表只能显式添加或移除；认知不得用一份旧人物快照覆盖新到的引用。

RuntimeGate 经 EventStore 的同一写事务提交记忆修订、状态、回执及认知事件，成功后才入 ActionQueue。目标记忆在事务内按 scene、ID、active 状态核对；supersede 限同主体、同类型，合并目标必须包含占用新槽位的旧记忆。事务失败不发送关联确认。回执携带实际 ID 和被替代祖先，工作引用不能继续指向被撤销的认识。模型自己的草稿、失败发送和推断不是关于另一人物的独立事实证据。

Reflection 的长调用不持有 Actor。反思提交事务同时比较读取的 social_revision 和反思游标，冲突则整批回滚，沿用安静窗口重新读取；不是在冲突后仍写记忆、只丢弃状态补丁。成功事务保存记忆、episode、游标和待投递内部事件。若内部事件延迟送达且理解版本已改变，Actor 不应用旧摘要、补丁和记忆回执，而将其作为待核对输入交给 Social Core；旧回执不能复活已再次修订的记忆引用。

一次认知保有 scene 执行权但不阻塞新事件持久化。工具结果保留在同一回合；草稿后最多一次续接并冻结实际观察截点。之后新事件留给下一轮和重启恢复。普通聊天允许新输入领先，任务、未来唤醒和 OpenLoop 仍要求最新输入；不会为让 Gate 通过而清空 mailbox。人格和表达样例在回合启动时固定；配置应用先原子落库，再热更新。

## Migration

既有记忆和历史不删除。启动只一次性从原始事件恢复 nickname/card，不猜偏好称呼。新版嘉然预设必须显式预览、应用；只替换仍等于旧预设的字段，保留人工编辑，停用未编辑的旧样例但不删除。预览过期须重新预览，重复应用不插入副本。

生产错误认识使用 `scripts/apply_reviewed_corrections.py` 的核对清单，经 Actor/Gate 正常提交，无聊天确认、无任务副作用，也不推进尚未理解的输入游标。该操作要求停止运行的数据库；正常启动不重复修订。

## Consequences and validation

固定截点意味着普通聊天允许交错；复杂工具仍可能耗尽预算，必须明确未完成而不是假称无能力或已完成。原始事件和旧记忆保留以供核对。用确定性链路验证纠错原子性、反馈保留、续接工具和恢复；用隔离 Shadow 对照真实模型的自然度，不能把原群友反应归因给新生成的回复。

不选择旧/新双轨、人格评审模型或关键词禁语表。它们不能修复“记忆没有修订权”和“续接不能用工具”的具体缺口，并会新增运行路径。输出自然度仍是模型行为，需要持续实群对照；本次五个固定截点不等于完整长对话验收。结果见 [2026-09-06 验收记录](../evaluation/20260906-adr0042-review.md)。
