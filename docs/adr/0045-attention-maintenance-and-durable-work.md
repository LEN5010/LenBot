# ADR-0045：持久注意力、增量维护与可继续的工作

状态：已接受，2026-09-08。根据 2026-09-07《LenBot 完整改进实施计划》，在 `659eff4d` 的原生对话与证据账本上扩展。本文替代 [ADR-0044](0044-native-conversation-and-evidence-ledger.md) 中全量输入消费、独立 work 反思和新消息取消对话的契约；事件、Actor、Gate、权限及送达底座继续使用。

## 决定

将事件保存、注意力扫描、摘要覆盖、本轮实际读取分别记录。SceneActor 在同一事务保存扫描进度与待处理唤醒来源。关键词和有新内容的固定时间窗抽样只产生观察机会，SocialCognitionCore 继续独立决定参与和沉默。没有观察机会的普通旁听只保存，不创建模型轮次，也不伪造沉默结果。

私聊、真实 @、回复 Bot、呼唤昵称、连续互动来源、有效工作参与者的新输入，以及当前工作与到期提醒等运行事件确定唤醒。抽样和关键词冷却不能抑制这些来源。真实送达才建立正常短时关注；正在处理的互动来源在送达前继续保留追问。Shadow、模拟和 unknown 不建立真实关注。

对话先读取唤醒原话与有界近期原文，再读取预算内摘要，远期原话按需查询。摘要附场景、原始位置与版本，只注册本轮来源定位；必须实际读过原文才能形成认识、工作或提醒的证据。未装入的明确来源仍在待处理集合中，扫描截点不提供证据授权。

普通新输入不取消网络请求。完整工具交换后，在原预算中吸收新增输入；终结调用先形成候选，再由 Actor 提交。普通聊天可以基于已读快照提交，控制、提醒、履约及 OpenLoop 必须读完本轮快照之后的场景输入与待处理确定唤醒。仅因晚到输入导致的拒绝可返回“未提交、无副作用”工具结果并在同一运行继续；租约、认识或工作版本失效不进入通用重试循环。

三个模型职责均显式配置：conversation 负责社会判断；work 执行获准的只读信息工作；maintenance 做历史维护、工作压缩和技能候选整理。各运行固定提供商、型号与推理强度，没有跨角色继承、自动换型或失败切换。maintenance 未配置就明确未就绪，不暗中调用其他角色。

每次真实模型请求在发送前创建唯一账目，成功、失败或取消结束同一记录。进程中断留下未确认记录；供应商 usage 缺失保留未知，本地估算单独显示。推理 token 不重复加到输出中，取消不等于停止供应商计费。费用没有价格证据就保持未核实。

历史维护只读取新增的原始范围，同一批次输出压缩摘要与稀疏认识提案。事件太长时记录字符分段，不把片段当成完整证据。摘要、认识和覆盖位置经 Actor 同事务提交；失败或版本冲突不推进覆盖，新消息不自动重试同一失败批次。升级前未摘要历史明确标记，不自动全文重读。

工作继续使用 tasks / agent_jobs。增加有来源的简短 work_state、固定模型绑定和完整原生工具交换检查点。原始资料留在工具观察中，图片仅存引用；查询接口不暴露供应商续接私有字段。修订保留已用预算和观察，旧进度注明目标版本；显式恢复使用最后完整检查点，暂停时间不算执行时间，已有结果不重做，取消/完成/partial 不自动重开。

工作有效输入预算扣除输出预留。先将已归档长结果换成可续读引用，仍超阈值时才由 maintenance 压缩确定的旧工具组，保留近期原生续接。失败、不缩小或超预算不发布新覆盖，不删原始交换，也不换型。压缩消耗同一工作的模型次数与时间预算。

程序性技能独立于社会认识，保存适用条件、步骤、验证、不适用情况、来源与版本。工作先看短目录、按需读正文，仅在自身终结或进度发现有用方法时提出候选。候选触发一次 maintenance 整理；没有候选没有学习调用。自动技能限来源场景，人工内容不能自动覆盖；运营明确发布才可跨场景。技能不授予执行权限，不触发新工作或群消息。

## 取舍与升级

接受减少普通旁听观察机会；不声称在不读所有消息时能实时理解所有话题。持续高负载若超出原预算，控制候选不提交，明确输入保留，等待后续真实输入或运营操作，不能无限自唤醒。

选择扩展现有 SQLite 与原生 AgentLoop，不增加第二套 Agent 平台、任务编排器、向量库、技能执行器或长期兼容开关。

旧数据库必须离线备份并显式转换后才能启动。转换保留原始事件、认识、任务、工作、配置、样例与媒体，将旧尚未处理输入转为待处理来源；本变更不授权 Reset。实际升级与回退步骤见[运行手册](../operations.md)，实施与验证状态见[实施记录](../implementation.md)。
