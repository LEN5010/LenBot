# Social Behavior Core via Participation Threads, Topic Drift, and Interim Context

> **Status — 2026-09-05:** Superseded by ADR-0032/ADR-0033. `ParticipationThread`, speaking-budget continuation, and `STATE_ANNOTATION` thread stepping were removed with the V3 attention module; conversational continuity is now a `SocialCognitionCore` judgement over persistent `GroupAgentSession` state. The `EpisodeMailbox` interim-cursor mechanics survive (ADR-0026).

In long-running group scenes, a persistent agent must neither remain an inert @-only tool nor devolve into an intrusive chatterbox. We decided to model conversational continuity through an explicit `ParticipationThread` within `SceneState`, reduced purely through `SceneReducer` upon events. Attention V2 checks active thread status, speaking budget, participant overlap, and immediate conversational adjacency to allow natural conversation without repeated @ mentions. When topic drifts, cognition proposes closing the thread via `state_annotations`, which is applied as an immutable `STATE_ANNOTATION` event to transition the thread to `closed`. Furthermore, `EpisodeMailbox` maintains an interim event cursor, enabling `PiAgentCore` to inject contemporaneous social updates at reasoning step boundaries so that cognition identifies semantic staleness and silences itself if another participant has already answered the query.
