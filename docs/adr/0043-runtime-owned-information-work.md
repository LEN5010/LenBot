# ADR-0043: Runtime 管理的信息型工作

- 状态：已实现；行为在真实群聊中持续核对
- 日期：2026-09-06
- 替代：已删除的 ADR-0039 草案；沿用 ADR-0040/0041/0042 权威边界

## 决策

一个 Social Core 持续理解群聊。短查询留在五步/六工具预算，长查询提出类型化工作，Gate 原子创建、修订、取消或恢复。Runtime 临时执行器复用 tasks 持久调度与认领，只能使用只读工具、记录结果，无发送、人格、记忆或 Session 写入权。

执行器上下文包含必要目标、约束、原始证据引用与已完成工具结果，prompt 不是永久状态。模型摘要不是独立证据。阶段回应由 Social Core 判断，不固定确认或播报。

修订产生版本，在步骤边界读取，旧结果不能完成新版本。普通 @ 不取消工作，目标关联由 Social Core 解释。Gate/发送队列校验版本和取消。中断保留资料并待认知核对恢复，不重放未确认发送。

默认每群一个、全局两个工作，16 步、24 工具、300 秒、64K 上下文，修订不重置预算。完成/部分/失败/中断与送达分别记录。

## 取舍与验证

工作释放社会回合，代价是持久生命周期与版本处理。不恢复 FAST/FULL，不给反思执行权，不允许执行器自行无限派生工作。已有确定性检查覆盖交错补充/取消、回滚、重复完成、预算与恢复；后续修改只做相关检查，目标理解和自然度主要在真实群聊中判断。

## 实施补充

工作详情保存在 agent_jobs，与 tasks 同 ID，后者保持调度/送达状态的唯一权威。预算预记账与待投递事件同事务，目标修订不清账。进展必须引用已取得资料，30秒记录冷却只限制系统负载，不决定是否发言。后台账目不推进社会观察截点，避免把技术步骤误作需要重新理解的群聊输入。
