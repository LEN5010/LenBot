# Control Plane Operational Cockpit, Safe Interventions, and Zero-Downtime Dynamic Configuration

Managing a persistent social agent in production requires real-time observability into scene conversations, threads, pending tasks, open loops, and cognitive beliefs, along with safe human intervention capabilities. We decided to build an integrated Cockpit API (`/api/cockpit/`) and dynamic configuration hot-reload pipeline. Administrators can inspect scene states, participant statistics, and participation threads, and inject manual events through `runtime.receive_event` to uphold the `Event -> Runtime State` invariant (Rule 1). Scheduled tasks can be cancelled or triggered immediately via `TaskScheduler`, open loops manually resolved, and incorrect memories refuted or superseded without breaking provenance. Furthermore, model endpoints, persona identity, and speaking budget thresholds hot-reload immediately in memory across `AttentionEngine`, `ActionQueue`, and `SceneManager` while persisting durably in SQLite `configs` table across restarts (Goal 8 & Goal 9).
