## 结构与功能去向

Vue Router 的 hash history 统一页面、详情、筛选与返回行为；AppShell 提供桌面导航和移动抽屉。Vuetify 管理基础控件，业务容器显式布局。列表使用有界摘要，全文进入详情；原图以 contain 保持比例，固定表情目录独立按运营顺序读取。旧手写 hash 分发、污染全局按钮与表格的样式、重复技能/调用账以及退役的 Trace/EventsLogs 页面已退出。

| 入口 | 实现去向与保留能力 |
|---|---|
| 运行概览、场景 | `#/overview`、`#/scenes`、`#/scenes/:sceneId`；真实状态采样、原话分页与定位、参与者、偏好、注意力、摘要及关联检查 |
| 工作、提醒与等待 | `#/jobs`、`#/jobs/:jobId`、`#/tasks?tab=reminders|waiting`；结果全文、资料回读、预算、检查点、压缩、修订/恢复/停止、提醒及等待干预 |
| 认识、技能、素材 | `#/memories`、`#/skills`、`#/media`；原始证据与修订、指定技能版本与候选、范围隔离、运营上传/编辑/停用及固定目录 |
| 模型、插件、设置 | `#/models?tab=roles|providers`、`#/plugins`、`#/settings?tab=persona|attention|connection|delivery|account`；现有配置和显式操作分别保存 |
| 运行记录 | `#/activity?tab=calls|turns|events|logs`；持久调用账、对话因果、原始事件、日志与资料阅读，不按时间邻近猜测关联 |

对象 ID、场景、技能版本、标签和分页保存在对应路由；表单、密钥与私人正文不进入 URL 或浏览器持久存储。场景消息与工作结果不是同一种消息，执行完成、待回应、真实送达、Shadow、模拟和未知送达分别显示。

## 读取与操作契约

读取继续经过 [RuntimeQueryService](../../src/len_bot/web/query_service.py)。管理列表统一使用 `page/page_size`，返回 `{items,total,page,page_size}`；普通管理列表每页 30 项，素材 48 项，服务端上限 100 项。筛选与总数来自同一集合。消息时间线单独使用 rowid 游标、首次 `snapshot_rowid` 和有界 `limit`，不把有限近期消息当作全量历史。素材目录接口独立返回现行最多 20 项，分页不会改变目录顺序；配置等有限目录明确完整返回。

页面按 ID 与必要场景读取详情，拒绝旧对象的迟到响应；范围或列表类型改变时清除旧列表，避免把旧场景内容显示在新筛选下。HTTP 401 进入登录并保留返回目标，其他权限、网络或服务错误如实展示。刷新失败保留旧结果时显示其读取时间。原文安全显示，媒体只经鉴权文件接口读取；私有路径、凭据和供应商续接字段不进入公共投影。

写入沿用原有受控接口，等待返回期间禁止重复提交，不自动重试。工作控制提交 `expected_revision`；技能读取精确版本，公开提交 `expected_version`，后端仍校验可发布版本与来源场景。聊天原图只读，运营素材编辑提交资产本身的范围；上传对话框单独持有明确范围，不跟随后台筛选改变。

各配置表单独立持有草稿与原始快照，刷新不覆盖未保存修改，离开会丢失的草稿时才提示。供应商空白 `api_key` 省略，OneBot 空白 `access_token` 提交 null，插件空白凭据省略；分别沿用对应接口的保留语义。插件读取只提供 `secret_fields/config_set` 和去除凭据的配置。模型能力检查需要主动确认，最多两次真实请求并提示可能费用；浏览、筛选、分页和刷新不调用模型。“保存并检查 HTTP”明确先保存并重新连接，随后检查接口。
