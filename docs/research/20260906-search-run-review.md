## 协议和展示上的助推因素

- `finish_work` 目前检查结果引用是否属于本工作，并按 `unresolved` 是否为空选择 completed/partial；不验证每个结论是否被引用来源支持。Google 正文和自己的确认均不能证明 OpenAI 未发布。
- Worker 已有“空结果不能证明不存在”“优先官方来源”“证据不足放入 unresolved”，也提供当前时间和原始问题；本次仍违反这些要求，不能把问题简单归为漏写日期或一条提示。
- AgentLoop 中工具处理函数返回即记 `completed`，即使返回体是 `unsupported` 或 `error`。Trace 页面展示该执行状态，却没有单独展示资料状态与错误码，容易误读成搜索成功。模型实际能看到返回体里的不可用状态。

4. Trace 分开记录“调用结束”和“资料成功/不可用/失败”，让具体错误与原始工具结果直接可查。
