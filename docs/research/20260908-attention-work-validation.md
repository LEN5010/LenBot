# 隔离供应商验证结果

2026-09-08（北京时间），使用用户明确授权的 BotCF / gemini-3.8-flash。维护为 low，工作为 high；生产配置只读，未启动生产调度、OneBot 或发送队列。

实际发送给供应商的资料仅为 [Python 3.13 sqlite3 官方公开中文文档](https://docs.python.org/zh-cn/3.13/library/sqlite3.html) 和显式合成测试原话。没有发送项目文档、用户开发计划或生产群内容。文档快照、来源 URL 和 SHA-256 见 本地 `.runtime/supplier-validation-20260908/source-document.md`、`source-manifest.json`。

## 验证结果

- 共 7 次供应商请求，均 HTTP 200，无模型重试：历史维护 1 次、工作 5 次、工作压缩 1 次。
- 一次历史维护成功提交摘要及两个来源定位，认识/核对提案为空；再次请求同一来源范围未生成新批次，也没有第二次模型调用。摘要指出给定文档末尾代码未覆盖完整，没有将技术材料升级成人物事实。
- 工作通过实际 InformationJobRunner、AgentLoop、只读观察存储、分页和 WorkCompressor 运行。模型依次读取 0–6000、6000–11000、11000–16000 字符；维护压缩第一个完整 assistant/tool 交换，后两组原生交换保留。随后同一供应商接受续接并真实调用 read_tool_result(offset=0, limit=800)，最后提交 completed。
- 工作账共 6 个模型步骤（5 次 work + 1 次 maintenance）、4 次工具，累计执行约 17.14 秒。原始 59,101 字符资料及 4 个完整工具交换保留，工作为 result_ready；没有 MESSAGE_SENT 事件。
- 压缩前后该请求的本地输入估算从 17,693 降到 14,027 tokens。此数字只说明本地估算窗口缩小，不证明计费下降。
- 人工核对最终答案的版本、连接关闭、事务提交/回滚与线程限制，相关原文位置均在声明的前 16,000 字符内，具体字符位置见 verification.json。

## 证据与限制

- 本地 `.runtime/supplier-validation-20260908/run-report.json`：隔离配置、源范围、摘要、工作结果、调用账与 usage 汇总。
- 同目录 `request-01.json` 至 `request-07.json`、`response-01.json` 至 `response-07.json`：实际请求/响应的脱敏副本，无请求头或凭据。
- 同目录 `isolated.sqlite3`：隔离事实、原始资料、调用账、完整原生续接检查点；不会在运营展示接口公开私有续接字段。
- 同目录 `work-traces.json`：生产 AgentLoop 生成的工作审计轨迹。
- BotCF 此次响应没有返回私有 signature/reasoning continuation 字段；实测只能证明当前桥接返回的原生 tool_calls 在压缩后可继续使用，不能声称验证了未返回的私有签名协议。
- 任务明确指定逐页读取与回读，因此该结果证明链路和供应商续接有效，不证明模型会在普通任务中自行规划同样的阅读顺序。
- 压缩摘要只看经过引用化的旧第一页。其 unresolved 描述了该旧区间视角下的待读页面，而后两页已经保留在新的原生尾部；本次工作正确读取尾部、没有重复抓取。段摘要的未决项不能作为全局工作进度的权威。
- 没有真实群聊、图片、重启后实网恢复或多供应商对照；这些未由本次少量验证覆盖。

初始以项目架构、实施记录和 ADR 为材料的执行，在进程启动前被自动审批拒绝；供应商请求为 0。理由是这些潜在非公开资料的外发授权不够明确。改用公开官方资料后获准执行。原拒绝记录见 approval-rejection.json，属于工具审批边界，不是模型失败。

## 同分支隔离结构与连续输入核对

数据库演练使用运行库的一致性只读副本。离线迁移保留 5,090 条原始事件、3 个场景及 307 个媒体文件；全部既有业务表的原列、行内容和原始事件 rowid 逐项指纹一致，SQLite integrity_check 为 ok。旧未处理的 3 个来源转为 pending_wakes，历史初始边界明确，completed 摘要为 0。另注入扩展建表中断，普通启动被未完成升级标记拒绝，连接正常关闭；生产数据库没有执行本次迁移。

现有 Actor/Gate 与传输夹具的连续场景确认：普通旁听没有 conversation 请求；关键词短时合并不压制明确呼唤；在途回应与真实送达分别建立对应输入机会；引用 B 的原话回复时关注 B；终结候选被晚到取消打断后，在同一 episode 的第 3 次模型调用撤回工作，原确认与任务均未提交。长原文使用实际资料分段，只在范围并集覆盖完整原话后开放整条证据；超出总预算时保留待处理来源。

本次共覆盖 176 项相关检查并逐项通过，旧引用测试夹具补充新配置后已复查受影响链路。稳定人格与人工参考的相同前缀已用两个不同时间/输入的构建快照核对，参考仍是 user 角色，不声称因此获得缓存折扣。

前端在隔离数据库与停用模型接口的实例中实际检查了概览、模型、群聊、工作、设置和动态页面；参数保存、技能正文、原始资料读取正常，浏览器无错误。技能创建—读取—原话纠正—修订—再次读取闭环，以及中断恢复、原生签名保存和图片窗口，由确定性隔离夹具验证，不能冒充真实群聊或真实供应商签名测试。
