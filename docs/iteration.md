## 本批实现与核对

原每场景 Session 已有唯一持久 JSON，却没有上次最终窗口的有序事件身份。本批新增 ConversationSegment 作为其中的可空字段，保存随机 ID／前段 ID、装配格式、开启原因、无凭据模型绑定、知识修订、截点和事件 ID。没有新表，不复制原话、人格、工具正文或完整请求。下一轮同场景回读引用并与原近期候选合并，仍按原 history_limit 截取，再由现有装配和容量规则选择。

普通真实对话在最终裁剪后，通过 SceneActor 的原队列和当前执行租约保存。Actor 核对预期段 ID、事件顺序和归属、截点不能倒退；EventStore 原写锁事务仅更新该 JSON 字段和更新时间，换段 trace 同批保存。内存只在落库成功后更新，返回独立副本；不覆盖 Session 并发输入事实，不改观察截点、pending_wakes、工作、预算或提交回执。

实际 system 与工具内容／声明来源在内存比较，变化、模型绑定／知识修订变化或窗口丢弃旧事件时明确换段；这些比较材料不落库、不做散列。Actor 重启后重新标记 process_restart，并从已知原事件引用建立当前段；没有恢复未保存的原生工具经历。插件专用表达、普通工作和 Shadow 不写主段。记录在额度准入／传输之前，取消或准入失败仍可能留下已装配窗口，不表示请求发出或来源已处理。
