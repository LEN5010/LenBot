## 本批交付与核对

`ModelGateway` 的调用登记与响应／异常结算使用原 call_id；响应解析前已取到的 usage 即使协议解析失败也传给 `end_model_call`，取消或异常缺少可用 usage 时不写成零。`ModelCallStoreMixin` 对工作预占按每个调用自身的输入估算、输出上限和已报告用量结算；原账保留实报与估算两栏，在途仍占用。供应商在客户端取消后是否继续执行或收费不可由本地代码确定，账目明确保留未知而不是声称已停计费。

`RuntimeQueryService.model_usage` 在完整筛选后的账本而非当前页上统计输入、输出、失败／取消／未确认、缓存报告覆盖；缓存命中按有报告输入 token 加权，首次／后续只认网关绑定实例的已登记序号，旧调用归未知。`TraceTimings` 与调用、消息详情分别列出已保存的来源装配、请求准备、模型客户端／步骤、工具、提交、发布、本群串行锁、执行槽位、工作目录和发送排队／适配器时长。阶段彼此可能嵌套、并行或按不同身份归属，缺失不按零，也不合成单条消息总延迟；发送仍查原行动回执。
