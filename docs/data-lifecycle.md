# 数据位置、过期与恢复边界

面向运营者和维护者。本文按当前源码说明需要保存哪些数据、过期与删除的区别，以及丢失后还能恢复什么；不是清理授权或已确定的保留政策。起停、备份命令和升级步骤仍只在[运行手册](operations.md#停机备份与结构切换)。任务状态见[产品路线](plan/README.md)，同版现场记录见[当前任务](iteration.md)。

## 数据清单

下表的“主库”指实际根配置 runtime.db_path。相对路径基于进程工作目录；外置目录按当前配置和原部署核对，不能按文档示例找生产文件。备份整个主库，不按表清单挑选导出；表名用于定位业务，不是可安全删表的白名单。

| 数据 | 当前保存位置／来源 | 丢失或单独恢复的影响 |
|---|---|---|
| 原话、提交、行动与回执 | 主库 events 及 pending_runtime_events；全文查找另有 events_fts | 摘要、Bot 回复和其他派生资料不能还原原始事件或证明当时送达 |
| 会话与待处理事项 | 主库 scene_sessions、open_loops、tasks；活动段在 Session JSON 内 | 丢失读取窗口、待交付或工作关联；恢复旧状态不能重放未知动作 |
| 认识与修订依据 | 主库 memories | 状态、到期时间、修订链和来源各有含义；只保留最新正文不足以解释纠正 |
| 历史摘要 | 主库 history_origins、history_batches | 生成文本不能替代原话；来源缺失会限制继续采用，即使摘要行仍在 |
| 工作与资料 | 主库 agent_jobs、job_exchanges、tool_observations；工作状态、预算和已读范围在原记录 JSON | 不得凭正文重建原申请者、工作修订、页引用或额度；相同文本不代表原结果身份 |
| 方法与人工样例 | 主库 skills、skill_versions、skill_candidates、voice_exemplars | 人工来源、方法版本及采纳结果不是可随意重建的缓存 |
| 模型调用与诊断 | 主库 model_calls、usage_reservations、traces | 原费用、预占和请求材料缺失不能补成零；诊断可能含私人原话和工具内容 |
| 平台与执行记录 | 主库 platform_actions、execution_runs、execution_events、execution_commands；原事件中的消息／文件回执 | 恢复旧行不撤销平台动作、已发生费用或外部执行；主库也不能独自证明网关资源已结束 |
| 媒体 | 主库 media_assets 加主库同目录 media/；来源、路径和用途保存在原行 | 只有库没有文件会失去像素／音视频；只有文件没有登记也不能重造原身份或读取权限 |
| 持久文件 | 主库 file_assets 加主库同目录 file_assets/，文件名为原 asset_id | 资产与工作、申请者、修订及审查关联必须一起保留；本地文件不证明已经上传 |
| 插件数据 | 主库同目录 plugins/<plugin_id>/，由原插件数据入口定位 | 与本地插件代码目录不同；只备份插件代码会漏掉状态与工作空间文件 |
| 语义索引 | 主库 memory_index，记录原来源、修订及模型代次 | 属派生索引；重建需仍有获准来源、绑定、预算与明确操作，可能再次产生嵌入调用，不是免费恢复 |
| 登录与凭据 | 主库 dashboard_users 保存账号信息；业务密钥、初始化信息在唯一 lenbot.config.json | 两者都需纳入受限备份。活跃登录会话在进程内存，不由数据库副本恢复；旧备份可能仍含已替换凭据 |
| 独立网关 | 网关 JSON 指定的 database_path 和 workspaces_root；日志库同目录 controls/；出口日志为配置 log_path 或日志库同目录 egress-<策略>.jsonl | 网关有独立执行和产物登记，不包含在主库备份里；卷、控制输入、日志和部署身份需成套核对 |
| 部署与运维材料 | 对应源码提交、根配置、网关配置、镜像身份、外部插件代码及原有运维日志／备份副本 | 不是运行时额外配置来源；代码、配置、库与文件版本混搭可能无法读取或续接 |

源码入口：[主事件存储](../src/len_bot/events/store.py)、[认识](../src/len_bot/memory/store.py)、[历史摘要](../src/len_bot/memory/history.py)、[工具资料](../src/len_bot/tools/observations.py)、[工作](../src/len_bot/runtime/job_store.py)、[调用账](../src/len_bot/cognition/call_store.py)、[方法](../src/len_bot/skills/store.py)、[媒体](../src/len_bot/media/service.py)、[持久文件](../src/len_bot/media/files.py)、[插件数据路径](../src/len_bot/plugins/base.py)、[网关入口](../src/len_bot/services/worker_gateway/__main__.py)。

## 过期、失效和物理删除不是一件事

- **持久文件**：创建时以当时 file_delivery.retention_seconds 写入 expires_at。类型默认 604800 秒，允许范围 3600—2592000 秒；这是现有实现事实，不是本部署值或新定的保留期限。当前上传校验拒绝过期资产，列表标记 expired；工作下载入口仍按原归属读取已存在字节，不以 expires_at 拒绝下载。该参数不定时删除 file_assets 行或磁盘文件，修改它也不会重算既有资产的 expires_at。
- **认识**：普通有效查询排除到期、被替代和被驳回记录，原修订信息仍可回查。失效不是物理清除；删除原证据后不能用剩余认识正文冒充依据。
- **原话窗口与摘要**：窗口裁剪不等于删除 events。已有来源回读、摘要可用性与已登记资料失效合同见[上下文](context.md)；删除原事件会使这些引用缺失，不自动清空会话段或改用生成摘要充当原话。
- **工作期限、等待与授予到期**：用于停止执行或拒绝后续权限，不是清理调用账、原话、文件或平台记录的期限。
- **索引清理**：语义索引重建会移除已不匹配当前来源的派生条目，不会因此删除原认识或摘要。全文索引也是检索派生物，但本文不提供直接删表／重建脚本；按所选版本的明确维护路径处理。
- **Reset**：是另行授权的破坏性业务清理，不是按日期保留策略，也不是完整擦除承诺。当前未覆盖的预占／执行等数据与保留的人工内容见[Reset 边界](operations.md#reset-与前端构建)。媒体 Reset 只按原保留集合清理，不能把所有媒体都当缓存丢弃。

当前主链没有已确定的群原文、资料、审计和备份统一保留政策；缺少周期清理不能被解释为用户同意永久保留。期限、是否例外保留、备份副本如何清理及审计与删除的取舍均由维护者决定。在决定前，不新增全局定时清理、不执行删除，也不把现有业务有效期扩成隐含政策。

## 备份与恢复必须成套

1. 正常停机并确认原外部执行状态后，按运行手册保存完整主库、根配置、media/、已使用的 file_assets/ 和 plugins/；独立网关按上表另存。保留旧源码／镜像及插件代码，不把运行数据装进发行包。
2. SQLite 使用原普通备份入口；不要把主库文件、另一时刻的 WAL／SHM 和不同版本文件卷拼在一起。普通文件复制仍须核对原路径、UID／GID 和访问权限，OneBot 的只读导出路径也要匹配。
3. 恢复前先保留故障现场并核对备份之后的新增事件、调用费用和平台回执。不能恢复旧整库抹掉新事实，也不能用恢复数据库撤销真实发送或付款。
4. 缺少某个文件时保持原缺失事实；不重新下载或生成相似内容并挂回原 asset_id。若只有派生索引损失，先核对原资料和获准重建条件；不是所有失去的数据都能由模型再生成。
5. 明确离线转换必须保留原事件、业务身份、版本、预算与回执边界；未知旧结构不在线猜补或自动 Reset。新 JSON 字段即使没有表迁移也可能被旧严格类型拒绝，具体限制沿运行手册的会话段、插件与既往版本条款。

备份只是额外副本，不证明恢复可用；也不因源数据删除自动清除历史备份、平台副本或外部供应商记录。本文没有确认这些外部副本的保留期限，也没有授予删除权限。
