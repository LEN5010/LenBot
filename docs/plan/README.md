## 状态定义

`待确认` → `可实施` → `实施中` → `待复核` → `已验收` → `已发布`

阻塞原因归当前任务或对应决策。源码接通、编译构建、同版人工验收和生产部署分别记录；当前没有任务标为已验收或已发布。链接提供合同或实施依据，不代表该任务已经运行通过。

## 当前接续顺序

1. 先完成已有实现的同版现场核对：S2 多轮续接与恢复、面板整理后的操作、S1 诊断、S3 插件、S4 群聊与工作。
2. 沿已选 Linux／SnowLuma 方向补齐报告与文件的独立回执、安装及升级恢复材料，不以双架构构建替代运行。
3. 维护者明确数据期限、分发授权、候选提交与支持承诺后，再推进 S6 发布决定。
4. S7 仍待确认，不把外部使用者或插件作者闭环当作已完成。

具体观察点和遗留问题只维护在[当前任务](../iteration.md)，这里不复制长篇交接。以上是接续建议，不授予启动、模型调用、发送或发布权限。
