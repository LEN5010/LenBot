# 产品路线唯一入口（S0—S7）

本目录是产品化路线唯一的任务状态入口。目标与设计理由在
[路线书](../LenBot_成熟开源项目路线书_20260921.md)，任务分配视图在
[任务卡](../LenBot_分阶段任务卡_20260921.md)。

两份文本都是**待实现合同**，不是当前能力说明。当前行为仍归
[架构](../architecture.md)、[上下文](../context.md)、[运行手册](../operations.md)、
[插件开发](../plugins.md)；实际观察、失败原文与未确认项归
[当前任务](../iteration.md)，已结束批次的明细归[历史记录](../history/README.md)。

## 读取顺序

1. 先读 [AGENTS.md](../../AGENTS.md)：工程约束、禁止事项、提交与交付边界。
2. 再看本文件的阶段表，确认要动的任务当前状态。
3. 然后读该阶段在任务卡中的段落，以及路线书里对应的合同章节。
4. 动手前重读 `docs/iteration.md` 与所属模块的真实源码；计划里的推荐字段不是已有能力。

## 状态定义

沿用路线书第 9.1 节，不新增与运行时业务状态同名的枚举：

`待确认` → `可实施` → `实施中` → `待复核` → `已验收` → `已发布`

阻塞原因写成字段（例如「待维护者决定许可证」），不发明第二套状态机。
「代码写完」不等于「实现完成」，「已验收」也不等于「生产已部署」。
