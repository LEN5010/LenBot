# 产品方向与已确认决策

更新于 2026-09-26，源码核对基线 `66d0225`。本文只保存仍有效的决定和未决问题；任务状态见[路线入口](README.md)，旧论证与静态盘点见[历史回查](../history/retired-plans.md)。

## 产品方向

面向长期多人群聊，提供按需工具调用、可持续推进的后台工作，以及来源、用量、提交和送达的查询入口。通用初始化样例与嘉然个人参考使用同一配置结构；个人预设由运营者选择，不是通用安装前提。具体入口见[运行手册](../operations.md#通用群助手与个人参考入口)。

源码已有上述路径，独立部署、真实体验与公开支持仍待验收，不能把产品目标写成已兑现的稳定承诺。

## 已确认的结构决定

| 日期 | 决定 | 当前落点 |
|---|---|---|
| 2026-09-23 | 会话段由宿主拥有，原话仍以事件存储为权威；场景、段、执行和长期工作身份分开 | 原 Session JSON 内的 `conversation_segment`；详见[段约定](s2-01-conversation-segment.md) |
| 2026-09-23 | 插件接口世代与插件自身版本分开，身份、作用域、预算归宿主 | `PluginSpec.api_version` 必填，当前世代 2；详见[插件合同](../plugins.md#接口世代-2-与迁移) |
| 2026-09-24 | 当前活动段可保存无法从原事件／已存观察还原的必要原生调用片段；已有观察的回复只保存定位 | `ordered_items` 保存完整交换及其重建引用；不复制另一份权威资料正文 |
| 2026-09-25 | 无 `result_id` 的回复只保存宿主最小回执，不保存任意模型或 Hook 正文 | `receipt` 形态；文本重建不承诺逐字相同 |
| 2026-09-23 | 首个验收方向为 Linux 容器群报告与文件交付，本机 SnowLuma，目标 amd64／arm64 | 消息和文件分别核验，详见[支持边界](../support.md#已选验收方向) |

这些决定不修改数据保留期限，也不代表发布、部署或真实发送授权。
