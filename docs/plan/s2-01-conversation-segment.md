# 会话段的持久边界与验收缺口

更新于 2026-09-26，核对基线 `66d0225`。2026-09-25 已接通原生交换、固定材料依据和未完事项交接；旧设计中的拟定字段与“尚未接通”说明已被当前实现取代。详细行为只维护在[上下文装配](../context.md)，任务状态见[路线入口](README.md)。

## 身份与所有权

| 对象 | 当前权威与用途 |
|---|---|
| 场景 | 每个 `scene_id` 对应原 `SceneSession` |
| 会话段 | Session JSON 中的可空 `conversation_segment`；由场景 Actor 在执行租约下保存当前有界窗口，不新增段历史表 |
| 执行 | 原 `episode_id`；等待恢复保留原来源、绑定、预算和期限，换段不重置它们 |
| 长期工作 | 原 `job_id/revision`、检查点与结果；主会话段不代管工作状态 |

实际字段见[类型定义](../../src/len_bot/scenes/models.py)，保存边界见[Actor](../../src/len_bot/scenes/actor.py)。事件 ID、摘要批次引用及 R／J／B／T／L 别名只保存身份；当前阅读与操作资格每轮重新核对。

## 回执定位不等于原生回复可还原

`ordered_items` 保存必要调用片段和 `page`／`message_range`／`job_query`／`receipt` 四种回复定位。2026-09-25 已确认：没有 `result_id` 的工具回复只保存宿主生成的最小回执，包含原调用 ID、暂存句柄、提交真假及拒绝／冲突原因等，不保存任意模型正文或 Hook 改写。

下一轮在同一模型绑定下从权威资料重建交换，重新核对群范围、插件归属、认识版本和页范围；恢复不会再执行原工具，也不把恢复文字当成平台发言。无法重建的组不能用相似文本补全，详见[原生交换合同](../context.md#当前段的原生交换)。

## 已实现的边界

- `materials`／`material_changes` 逐项记录固定材料依据。同进程可比较内容；跨重启只有源码修订依据能证明未变，当前人格等材料缺少这种依据，因此正常重启会换段。
- 段内容离开时，`handoff` 按权威状态保留相关未完事项身份；下次请求重读当前状态，不结案、不清预算。语义延续仍用唯一的历史维护摘要入口。
- 成功终结、参数拒绝、新输入冲突、取消和提交后发布失败分别保存或记录不能保存的原因；段保存失败不撤销已提交业务。
- 原 `SceneSession` 使用严格类型；新字段写入后旧代码可能拒绝读取。升级先停机备份，回退按[运行手册](../operations.md#会话段字段的升级与回退)，不在线清空状态试错。

## 仍需实际核对

多轮续接、供应商续接字段兼容、重建文字对缓存的影响、活动状态体积、正常重启、等待恢复、权限撤销及历史维护并发均未取得本批同版运行证据。旧摘要未登记的依赖与自由表达仍有缺口；离开交换组的资料正文不另作摘要。未列出的重建异常不自动清段重试。
