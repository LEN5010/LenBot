# 运行与验收

面向运营者。当前自然度门槛尚未满足，测试通过不自动开放实发。

## 升级与恢复

运行命令见 [README](../README.md)。升级前停止运行时，备份 len_bot.db 及媒体目录。增量幂等迁移不清空历史、任务、记忆或人工人格；旧版本需配套旧备份，不做破坏性降级迁移。

## 验收顺序

1. 相关边界测试、完整 Python 回归、前端构建及面板验证。
2. 十二类固定多轮场景，每类三次：综合、补充、取消、进度、干扰、媒体、反馈、失败、恢复。固定观察模型对照与真实工具抽测分别记录。
3. 事实依据与显式约束遵守至少 90%，关键无依据结论/取消后执行旧目标必须修复；人工自然度至少 80% 可接受。
4. 真实群 Shadow 至少 100 条人类消息及 20 个可评阅候选，再在唯一批准的 group:126300994 实发至少 20 次有效互动。

Shadow 不产生 MESSAGE_SENT，不把原群友反应算给候选。低活跃、缺视觉或人工评分时标记待验收，不按时间或模拟数据凑数；失败不改成脚本成功。

## 指标与回退

分别记录首条可见回复、完整工作、模型、工具、排队和发送 p50/p95，连同源码/模型版本、Token、来源及失败。回放总耗时不是实发延迟。

全局 Shadow 优先于场景白名单，发送前复查。启用时刻是试运行起点，旧请求只核对，不补发过期回复。关键失败切回 Shadow，停止未发片段并保留证据；代码可停用功能或 revert，数据需回退时用升级前备份。不确定发送不重试。

## 配置前置条件

保留当前文字生产路由，现有 L/Flash 与 L/Pro 仅隔离比较。vision 独立配置并验证真实图片能力，无可用型号不能计图片验收通过。表情由运营上传启用，不自动把群内图片收为全局素材。

## 媒体操作

模型页设置独立看图路由并使用“测试图片读取”；连接成功不代表所有图片理解准确。图片页上传PNG/JPEG/WEBP/GIF，填写描述、标签与范围并启停；global-safe仅用于允许各场景使用的运营素材。缓存目录是数据库同目录下的media，备份需与数据库一起进行。可用JOBS_ENABLED=false或MEDIA_ENABLED=false启动来停用对应能力，保留账目和文件。

## 效果评阅与模型对照

“效果”页选择场景查看真实发送ID及其后续原话；“引用此回复”是结构事实，“窗口内发言”不保证针对机器人。评追问、纠正或态度须关联具体原话；自然度单独标可接受/不可接受/未评，并记录理由。评价只追加，不把沉默算满意。人格页可预览新增四组表达样例再应用，人工编辑和启停保留。

`uv run python scripts/eval_agent_cases.py --provider-db len_bot.db --model deepseek-v4-flash --repeats 3 --output /tmp/flash.json` 只读生产配置，在临时数据库运行，固定时间、场景、工具与样例。对照关闭跨模型fallback；未配置、限流、格式和提交失败全部保留。Pro用已保存目录里的型号替换，不写生产路由。`scripts/summarize_agent_eval.py` 汇总模型/工具耗时和用量；模拟送达的首条可见/工作/排队/发送延迟保持空值，实际发送在事件payload记录event_to_delivery_ms、queue_ms和send_ms。
