# 运行与实群迭代

面向运营者。日常操作是配置、群聊和查看实际问题；不需要导入报告、打分或凑够消息数量。

## 启动与发送

使用 `uv run len-bot` 启动，面板默认地址为 `http://127.0.0.1:11307`。本包没有 `python -m len_bot` 入口。运行日志和当前 PID 位于本地 `.runtime`，备份位于 `.backups`，均不进入 Git。

提供商、模型、OneBot、人格和管理员密码沿用保存值。默认全局 Shadow 开启，初始实发群名单为 `group:126300994`。在设置页核对实发群名单，关闭全局 Shadow 后即可在名单内的群聊天；名单外不实发。名单和开关重启后保留，修改源码、模型或人格不触发重新验收。

需要暂停时开启全局 Shadow；只暂停一个群时将它从实发群名单移除。发送前会重新检查当前配置。Shadow 期间形成的候选不自动补发；发送结果不确定时不重试，也不切换发送通道。失败或未知会停止同组后续片段。

## 发现问题后怎么改

在群里实际聊天，直接观察有没有接住意思、语气是否别扭、是否该结束。遇到问题记下原话、群和时间，从事件、trace、工具结果与发送回执查出发生在哪一步，再改对应逻辑并回到实群确认。

修改只运行相关的现有检查。事务、权限或发送边界确有必要时才增加确定性测试；不预先铺设自然度场景集，不要求完整回归、固定轮数模型比较或人工评分。内部模拟结果不能算实际发送或群友反馈。

工作页查看资料、修订目标、停止或恢复信息工作；任务到期和工具完成都不等于送达，最终以真实 MESSAGE_SENT 为准。已中断待核对的工作通过现有恢复操作继续，不因为代码更新自动重做。

## 模型、人格与媒体

模型页配置文字与独立视觉路由，“测试图片读取”用于确认所选型号能接收图片。现有文字型号的真实图片探测失败，不以文字常识假装已经看图；这不阻止文字群聊。不会自动更换生产提供商或型号。

人格和表达样例在设置页编辑；预设先预览再显式应用，已有人工编辑和启停保留。图片页可上传 PNG/JPEG/WEBP/GIF，填写描述、标签与范围。`global-safe` 只用于允许运营公开提供给各场景的素材，群内图片保持本群范围。

媒体缓存位于数据库同目录的 `media`。`JOBS_ENABLED=false` 或 `MEDIA_ENABLED=false` 可停用对应能力，保留账目和文件。

## 升级与历史记录

升级前停止运行时，备份 `len_bot.db` 和 `media`。不清空原始事件、任务、记忆或人工人格。需要恢复旧版本时使用配套代码和升级前备份。

旧评分、固定案例与模型对照已退出操作流程。已提交的真实失败文件保留为历史证据；本轮原始运行与早期启动记录保存在本地 `.runtime/evaluation-history/`，不进入 Git，也不代表当前发送配置。
