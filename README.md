# LenBot

基于 Python、asyncio 和 SQLite 的 QQ 群聊 Agent，通过 OneBot v11 接入。核心正在重写；以下说明以当前 `len-bot` 启动入口为准，不把旧代码中尚未接入的功能算作已可用。

## 项目状态

核心正在重写，目标是：每个群一个常驻的 Agent 会话、用角色口吻说话的表达器、可以浏览和编辑的文件式记忆、在沙箱里完成长任务的工作 Agent。现有核心已冻结，只修阻断运行的缺陷。下面提供当前开发版的安装和使用路径；不把协议检查或构建当成真实群运行验收。

## 运行

需要 Python 3.13、uv、Node 22，以及一个 OneBot v11 实现。

```sh
# 首次安装依赖并构建面板；不会启动 Bot 或覆盖数据
./scripts/install.sh

# 项目根目录；没有配置时打开终端给出的首次配置链接
uv run --no-sync len-bot
```

- `len-bot` 直接启动当前多场景聊天核心，不按配置猜测版本，也不回退旧运行时。
- `lenbot.config.json` 是唯一的运行配置：OneBot、模型绑定、场景和数据库路径都在里面，不用环境变量、命令行或数据库覆盖。它含密钥，只留在本机，已排除在 Git 之外。开发工作树已有配置时直接沿用，不用初始化样例覆盖。
- 根配置不存在时只启动本机首次配置向导，填写QQ连接、模型、角色、场景及面板账号。保存后重新运行同一个启动命令。已有配置不合法时直接指出具体字段，不覆盖、不回退初始化。
- `delivery: "onebot"` 为真实发送，`"simulated"` 只保存模拟表达。
- `panel` 可选；未配置时只运行聊天宿主，不启动网页。按 Ctrl+C 正常退出。
- 历史初始化样例和旧 Linux 部署配方不用于覆盖当前开发配置；新环境使用首次配置向导。

## 现在能做什么

- 配置场景的常驻聊天、注意力与合并窗口、会话压缩、角色表达或直出，以及实际文本发送回执。
- 聊天原文查询、等待补充、一次性提醒、角色资料查询；搜索、网页读取和看图须配置相应服务或模型。
- 管理面板显示连接、消息、原生会话、工具注册原因、模型调用与费用，并可保存模型、角色、场景和连接设置。保存配置与当前进程生效分别展示。
- 可选文件式记忆：本地 Markdown、全文检索、修改历史，或显式配置 embedding 后的混合检索；OpenViking 接口保留其原生目录与实际后台状态，不宣称两个后端已完全等价。
- 记忆内容管理、每轮召回与默认关闭的后台抽取。本地自动抽取须单独绑定记忆模型，首次启用不自动回填旧消息；失败范围由运营者明确处理，不自动重试。

- 独立任务队列、任务容器、Pi 原生工具循环、追问/确认、取消、文件登记与显式上传；需要配置并自行构建 `docker/next-worker/Dockerfile` 对应镜像。图片/文件生成、复制到宿主和平台接收分开显示。
- 插件接口与按场景启用，MCP stdio/HTTP工具，完整 cron、场景时区、默认关闭的主动话题与表达学习。
- 十入口面板；宿主内试聊复制运行角色和可选历史文字，模型实际调用，出口始终模拟，本地记忆为独立空目录。配置服务并不代表已经执行。
- 公共浏览在任务容器；账号浏览是根主人显式发起的新任务，通过专用浏览器守护进程/扩展，能力页配置、配对、吊销和清理残留会话。不支持远程文件上传下载，不借用日常浏览器配置。
- 已配置ASR时可转写当前场景语音；自动转写、聊天工具和任务工具复用缓存和服务。普通任务不取得账号浏览会话。

工具仍受角色允许列表和实际服务装配约束，能力页说明缺项。个人插件位于独立仓库，不随本仓库默认启用。部分能力目前只有协议/隔离连线证据，真实模型效果、最终任务镜像和实际浏览器扩展连通仍需部署后确认。

## 升级现有开发数据

停止运行并完成数据备份后，在项目根执行：

```sh
uv run --no-sync python -m len_bot.next.migrate
```

当前业务库格式为 29；迁移保留原消息与身份，每个步骤保留原格式副本。当前格式无需再迁移，命令不会自动跳过/覆盖备份。记忆处理库有独立迁移入口，不能用业务库迁移替代。升级代码不自动操作正在运行的实例。

## 日常使用

启动后登录配置中的面板地址。首页看连接与最近错误；群聊查看消息/设置；能力配置插件、MCP与浏览器；模型分别绑定各用途；对话测试可在不向QQ发消息的条件下检查实际模型回复。保存配置与当前进程生效分开，提示需要重启时由运营者自行重启。

账号浏览先在专用机器/浏览器配置安装并运行所选守护进程和扩展，能力页填CLI/home/socket（必须属于同一守护进程）。实例ID可先留空，生成链接后由主人在扩展配对；读取实际连接得到ID，明确保存后重启。配对不等于登录目标站点，链接生成也不等于浏览器已连接。失败不自动换浏览器或重发操作。

本地定向遗忘可排除明确选中的旧消息；OpenViking 的完整遗忘、历史和跨后端完整等价语义仍未完成。旧核心源码保留用于迁移与评测参照，正常启动不再进入旧核心；项目尚未完成开源发布验收。

旧一次性提醒可在停机备份后，用根配置 `reminder_import` 显式给出 `source`、`backup`、`scenes`、`timezone`，执行 `uv run --no-sync python -m len_bot.next.import_reminders`。只移交未到期、未领取、无条件触发的真人提醒；其他项报告原状态，不复活已结束事项，也不自动停旧后台。当前业务库格式为 33，旧格式仍按现有离线迁移入口升级后使用。
