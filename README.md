# LenBot

基于 Python、asyncio 和 SQLite 的 QQ 群聊助手，通过 OneBot v11 接入。新核心已经实现常驻群会话、角色表达、文件式记忆、沙箱任务及管理面板；完整迁移与发布验收尚未完成。源码能力不等于已经启用或运行通过。

## 开始使用

需要 Python 3.13、uv、Node 22，以及一个 OneBot v11 实现。

```sh
# 安装依赖并构建面板，不启动服务或覆盖实例数据
./scripts/install.sh

# 在实例根运行；没有配置时进入首次配置向导
uv run --no-sync len-bot
```

- `len-bot` 直接运行当前多场景核心，不回退旧运行时。
- `lenbot.config.json` 是唯一运行配置，包含凭据，只保存在本机。已有配置不合法时直接报错；不要用样例覆盖。
- `delivery: "onebot"` 为真实发送，`"simulated"` 只记录模拟表达；模型调用仍可能计费。
- 面板可选；配置保存与进程生效分开显示，需要重启时由运营者明确执行。
- 安装、迁移、启动和真实发送是不同操作，不因构建完成而自动执行。

## 当前能力

| 范围 | 已有实现 |
|---|---|
| 聊天 | 多场景持久会话、注意力与消息合并、压缩恢复、角色表达／直出、实际发送回执 |
| 角色 | 四文件设定、知识、样例、表情、头像、ZIP 包管理及未保存草稿独立试聊 |
| 记忆 | 本地 Markdown／全文及可选向量检索，原生远端后端，每轮召回、可选后台抽取、历史与正文迁移 |
| 工作任务 | 独立容器、Pi RPC、追问／确认、取消续接、选定输入、技能、文件登记与显式上传 |
| 工具与浏览 | 搜索、网页读取、看图、QQ 语音转写、公共浏览和独立账号浏览任务 |
| 学习与时间 | 表达／黑话／表情候选、人工采用、回复效果、一次性和周期安排、可选主动话题 |
| 扩展 | 按场景启用的插件、stdio／HTTP MCP、默认关闭的任务 MCP 宿主桥 |
| 管理 | 十入口面板、隔离试聊、权限与预算、调用费用、消息／任务时间线及日志 |

能力受根配置、角色许可和实际服务装配约束，未配置不注册占位成功。个人插件在独立仓库，不随本仓库默认启用。

## 当前限制

- 本地与原生远端记忆未完全语义等价；原生完整遗忘尚未实现。
- 任务存储可查看用量，尚无硬磁盘配额；账号浏览不支持远程文件上传下载。
- ASR 面向本场景 QQ 语音，不接受任意本地音视频上传。
- 最终任务镜像、真实浏览器扩展、平台交付及干净环境安装仍有未验部分，近期新增页面的构建不代表操作验收。
- 旧后台完整移交、全部场景切换和旧核最终删除尚未完成。冻结源码保留，不用于给新核心继续加功能。
- 当前 wheel 只安装新核心及实际共享组件；源码包保留旧源码供迁移，不把源码目录可见等同于 wheel 已支持旧插件。
